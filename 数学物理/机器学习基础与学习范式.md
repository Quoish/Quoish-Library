# 核心图景

机器学习可以先理解成一条反复修正的路线：**给出输入 → 模型产生预测 → 用训练信号评价预测 → 调整模型 → 用未参与调整的数据检查效果**。

以垃圾邮件识别为例，输入是邮件，输出是“垃圾／正常”。手写规则可以规定“含有某些词就拦截”，但措辞、用户习惯和攻击方式会变化。学习方法把部分判断依据交给数据：先提供有标签的邮件，再调整一套可计算的判别函数。

这里有两个独立要求：模型需要学会拟合已有经验，还需要能处理以后到来的邮件。只记住训练样本，并不能完成后一个要求。

# 问题域与发展背景

人工智能从一开始就包含多条路线。1955年的[达特茅斯研究计划书](https://www-formal.stanford.edu/jmc/history/dartmouth/dartmouth.html)为1956年的暑期研究提出语言、抽象、神经网络与自我改进等问题。因此，搜索、符号推理、知识表示和从数据学习，都是理解人工智能时需要考虑的组成部分。

从学习方法的发展看，可以辨认出几种持续存在的困难：

| 困难              | 对应的方法思路          | 新问题             |
| --------------- | ---------------- | --------------- |
| 规则太多、细节难以手工穷举   | 从样本估计参数或判别规则     | 数据是否足够、标签是否可靠   |
| 原始图片、语音不容易直接表示  | 学习多层特征，也就是深度表示   | 网络如何训练、计算成本多大   |
| 每个任务单独标注和训练成本很高 | 大规模预训练，再迁移到具体任务  | 通用训练目标与任务需求是否一致 |
| 参数里的知识难更新、难追溯   | 将模型与检索、工具等外部系统结合 | 各环节的错误如何定位和评价   |

这些方法长期并存。一个规则明确、数据很少的任务，可能用规则和搜索就能解决；表格预测、图像识别、语言生成和交互决策，对数据和模型的要求也不同。

人工智能、机器学习、深度学习之间的关系，可以记成：**人工智能是较大的研究范围；机器学习研究如何从经验改善表现；深度学习使用多层可训练表示，是机器学习中的一类方法**。

# 把一个学习问题拆成五个对象

设任务是根据房屋特征预测价格。先把房屋写成一个特征向量，例如$x=(\text{面积},\text{房龄},\text{距市中心距离})^T$。向量只是将一条样本的多个数排在一起。

| 对象  | 记号               | 具体含义           |
| --- | ---------------- | -------------- |
| 输入  | $x$              | 预测时能够获得的信息     |
| 目标  | $y$              | 希望模型预测的价格或类别   |
| 模型  | $f_\theta$       | 把输入变成预测的计算规则   |
| 参数  | $\theta$         | 训练过程中调整的权重、偏置等 |
| 损失  | $\ell(\hat y,y)$ | 用数值衡量预测与目标的差异  |

模型的预测写成$\hat y=f_\theta(x)$。帽号表示“估计值”。训练集有$N$条样本，模型可以对每条样本算一次误差，再求平均：

$$
\hat R(\theta)=\frac1N\sum_{i=1}^N\ell(f_\theta(x_i),y_i).
$$

阅读这条公式时可以从内向外：对第$i$条输入作预测，拿它与目标比较，对全部样本重复，最后除以样本数。这个平均训练误差叫经验风险。

为了约束过度复杂的解，还可以加入正则项：

$$
\theta^*=\mathop{\arg\min}_\theta
\left[\hat R(\theta)+\lambda\Omega(\theta)\right].
$$

$\Omega$表达希望参数满足的偏好，$\lambda$控制其强度。$\arg\min$表示寻找使括号中目标最小的一组参数；实际训练通常只能近似求解，深层网络的目标也未必容易全局优化。

参数和超参数需要区分：线性模型的权重通过训练估计，学习率、树深或网络宽度则是训练前设定或通过验证选择的超参数。

# 训练信号从哪里来

## 监督学习：输入和目标一起给出

分类预测离散类别，回归预测连续数量。例如“邮件是否垃圾”是分类，“明天用电量是多少”是回归。标签可以来自人工，也可以来自业务记录，不要求每个标签都由人逐条填写。

## 无监督学习：寻找数据自身的结构

没有目标类别时，可以按相似性分组、寻找变化最大的方向，或估计数据密度。聚类形成的编号没有预先规定的语义，需要再结合任务解释，见[[无监督学习与降维]]。

## 自监督学习：从原数据构造预测目标

例如把“春天开花”拆成“春天开”与下一个字“花”，就能得到一条训练样本。也可以遮住图像的一部分，让模型预测缺失内容。目标来自原始数据，仍然可以通过明确损失训练；它并不意味着完全没有监督信号。

## 半监督与强化学习

半监督学习结合少量标注与大量未标注样本。强化学习则让智能体行动、接收奖励并继续行动：当前动作还会影响之后见到的数据，详见[[强化学习基础]]。

# 从训练成绩到泛化能力

泛化指模型在未参与训练、且与目标应用有关的新数据上的表现。为了区分“学会了规律”与“适应了手头样本”，通常使用三部分数据：

1. **训练集**：估计参数，例如拟合权重和标准化均值。
2. **验证集**：选模型、选超参数、选停止时机。
3. **测试集**：选择完成后进行最后评价。

假设有1000条样本，可以示意性地分为700条训练、150条验证、150条测试；实际比例取决于数据量和任务。交叉验证把训练部分再轮流切成几份，以减少一次划分造成的偶然性。

预处理也会学习信息。例如标准化使用训练集均值和标准差：

$$
z_j=\frac{x_j-\mu_j^{\mathrm{train}}}{\sigma_j^{\mathrm{train}}}.
$$

测试样本也使用这同一组数。若先根据全部数据算统计量，再声称测试集完全未参与建模，评价过程就出现了数据泄漏。时间序列还要避免未来信息进入过去；同一人的重复记录也可能需要按人分组划分。

# 一次准确率能说明多少

准确率就是“分对的数量／总数量”。但若100封邮件只有1封垃圾邮件，一律判为正常也有99%准确率，却完全没有拦截垃圾邮件的能力。

把垃圾邮件视为正类：真正拦截的垃圾邮件是 TP，误拦的正常邮件是 FP，漏过的垃圾邮件是 FN。于是

$$
\mathrm{Precision}=\frac{TP}{TP+FP},\quad
\mathrm{Recall}=\frac{TP}{TP+FN}.
$$

例如拦到20封垃圾邮件，同时误拦5封、漏掉10封，精确率为$20/25=0.8$，召回率为$20/30\approx0.667$。业务需要决定哪种错误成本更高，评价指标才有实际含义。

训练好坏、泛化好坏和因果解释也是不同问题。模型发现“某特征与目标有关”，还不能据此判断主动改变该特征会产生什么因果效果。

# 可复原例程

使用内置鸢尾花数据，比较多数类基线与逻辑回归，并通过交叉验证选择正则化强度。依赖 NumPy、scikit-learn；无需下载。

## 环境与文件

先按[[机器学习与人工智能#统一运行环境|统一运行环境]]建立 `ml-ai-notes` 环境。以下每个代码块均为所标文件的完整内容，文件名和大小写应与目录一致。

### `main.py`

```python
"""比较多数类基线与逻辑回归，演示无数据泄漏的交叉验证流程。"""

# 标准库
from pathlib import Path
import json

# 第三方库（由统一环境提供）
from sklearn.datasets import load_iris
from sklearn.dummy import DummyClassifier
from sklearn.linear_model import LogisticRegression
from sklearn.metrics import accuracy_score, confusion_matrix
from sklearn.model_selection import train_test_split, GridSearchCV, StratifiedKFold
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler


def main():
    """比较多数类基线与逻辑回归，演示无数据泄漏的交叉验证流程。

    按分段注释依次准备数据、执行计算并保存结果。
    """

    # 1. 建立输出目录：始终以脚本位置为基准，不受终端当前目录影响。
    out = Path(__file__).resolve().parent / "outputs"
    out.mkdir(exist_ok=True)

    # 2. 读取数据：x 为 (150, 4) 的特征矩阵，y 为150个整数类别。
    x, y = load_iris(return_X_y=True)

    # 按类别比例划分训练／测试集；测试集不参与下面的超参数选择。
    x_train, x_test, y_train, y_test = train_test_split(
        x, y, test_size=0.3, random_state=7, stratify=y
    )

    # 3. 先拟合简单基线：始终预测训练集中的多数类别。
    baseline = DummyClassifier(strategy="most_frequent").fit(x_train, y_train)

    # 标准化与分类器绑定成流水线，确保每一折只用该折训练数据拟合缩放参数。
    pipeline = make_pipeline(StandardScaler(), LogisticRegression(max_iter=500))

    # 分层五折保留类别比例；shuffle 与固定种子使划分便于复现。
    cv = StratifiedKFold(5, shuffle=True, random_state=7)

    # 4. 用训练部分选 C：C 越小，逻辑回归的正则化约束通常越强。
    search = GridSearchCV(pipeline, {"logisticregression__C": [0.1, 1, 10]}, cv=cv)

    # 执行交叉验证，并用选出的最佳参数在完整训练集上重新拟合。
    search.fit(x_train, y_train)

    # 5. 最后才访问测试集，避免根据测试成绩反复挑选模型。
    prediction = search.predict(x_test)

    # 混淆矩阵的行是真实类别、列是预测类别；对角线表示预测正确。
    report = {
        "baseline_accuracy": accuracy_score(y_test, baseline.predict(x_test)),
        "test_accuracy": accuracy_score(y_test, prediction),
        "best_C": search.best_params_["logisticregression__C"],
        "confusion_matrix": confusion_matrix(y_test, prediction).tolist(),
    }

    # 6. 同时在终端显示指标并写入 JSON，便于留存实验记录。
    print(json.dumps(report, indent=2))
    (out / "metrics.json").write_text(json.dumps(report, indent=2), encoding="utf-8")


if __name__ == "__main__":
    main()
```

基线约为三分之一；逻辑回归通常显著优于基线。标准化放进 Pipeline 后，每一折都仅使用该折的训练部分拟合缩放参数。测试集不参与选择 `C`。`metrics.json` 保存实际指标，单次划分的高分仅说明本实验中的表现。
