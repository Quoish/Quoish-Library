# 从人工智能到机器学习

人工智能研究使系统完成感知、推理、规划、语言处理和决策等任务的方法。规则系统、搜索算法和知识表示也属于人工智能。机器学习研究如何根据数据调整模型，使其在某种任务上的表现得到改善。深度学习使用多层可训练表示，是机器学习中的重要方法族。

例如，识别一张图片中的数字，可以手写规则，也可以让模型从标注图片学习。机器学习方法需要明确三个对象：任务是什么、能够获得什么经验、用什么指标评价。对图片分类，经验可以是带标签的训练集，指标可以是未见图片上的准确率。

# 学习问题由什么组成

设数据集为$D=\{(x_i,y_i)\}_{i=1}^N$，模型为$f_\theta$。$x_i$是输入，$y_i$是目标，$\theta$是通过训练调整的参数。监督学习常最小化经验风险：

$$
\hat R(\theta)=\frac1N\sum_{i=1}^N\ell(f_\theta(x_i),y_i),\quad
\theta^*=\mathop{\arg\min}_\theta\bigl[\hat R(\theta)+\lambda\Omega(\theta)\bigr].
$$

$\ell$衡量单个预测的误差，$\Omega$是正则项，$\lambda$控制约束强度。训练集上的误差可以直接计算，未来数据上的期望风险通常未知。训练的实际目的，是获得能够泛化到目标数据分布的模型。

参数与超参数承担不同角色。线性模型的权重由训练得到；学习率、树深、网络宽度等超参数通常由验证过程选择。模型架构也包含人为设定的归纳偏好，例如卷积倾向利用局部结构。

# 主要学习范式

| 范式 | 训练信号 | 典型任务 |
|---|---|---|
| 监督学习 | 人工或业务过程提供的目标 | 分类、回归 |
| 无监督学习 | 数据自身的分布和结构 | 聚类、降维、密度建模 |
| 自监督学习 | 从数据构造目标 | 遮盖词预测、下一词元预测、对比学习 |
| 半监督学习 | 少量标注和大量未标注数据 | 伪标签、一致性训练 |
| 强化学习 | 与环境交互获得的奖励 | 控制、游戏、资源调度 |

自监督学习往往也优化类似监督学习的损失，只是目标由数据构造。例如，把“今天下雨了”拆成前缀和下一个字，便能得到预测任务。强化学习中的动作会影响后续观测，因此需要处理延迟奖励与探索。

# 一次可靠的机器学习实验

先定义任务和指标，再划分数据，然后仅在训练数据上拟合预处理器和模型。验证集用于选超参数，测试集用于最后评估。交叉验证可以反复利用训练部分估计不同选择的表现。

分类准确率为

$$
\mathrm{Accuracy}=\frac1N\sum_i\mathbf1[\hat y_i=y_i].
$$

它对类别不平衡可能不敏感。例如99%的样本都是阴性时，总预测阴性也有99%的准确率。需要结合混淆矩阵、精确率、召回率或任务成本。

数据泄漏会使评估虚高。常见来源包括：划分之前对全部数据标准化、同一对象的重复样本跨集合、使用预测时尚不可获得的字段。时间序列通常按时间划分；同一个人的多条记录应考虑按人分组。

# 能力边界

测试表现依赖数据划分和目标分布，单次高分无法保证部署后长期有效。输入分布、标注规则或用户行为变化，都可能造成性能漂移。统计预测也不自动提供因果解释。

### `main.py`

```python
from pathlib import Path
import json
from sklearn.datasets import load_iris
from sklearn.dummy import DummyClassifier
from sklearn.linear_model import LogisticRegression
from sklearn.metrics import accuracy_score, confusion_matrix
from sklearn.model_selection import train_test_split, GridSearchCV, StratifiedKFold
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler

def main():
    out = Path(__file__).resolve().parent / "outputs"
    out.mkdir(exist_ok=True)
    x, y = load_iris(return_X_y=True)
    x_train, x_test, y_train, y_test = train_test_split(
        x, y, test_size=0.3, random_state=7, stratify=y)
    baseline = DummyClassifier(strategy="most_frequent").fit(x_train, y_train)
    pipeline = make_pipeline(StandardScaler(), LogisticRegression(max_iter=500))
    cv = StratifiedKFold(5, shuffle=True, random_state=7)
    search = GridSearchCV(pipeline, {"logisticregression__C": [0.1, 1, 10]}, cv=cv)
    search.fit(x_train, y_train)
    prediction = search.predict(x_test)
    report = {
        "baseline_accuracy": accuracy_score(y_test, baseline.predict(x_test)),
        "test_accuracy": accuracy_score(y_test, prediction),
        "best_C": search.best_params_["logisticregression__C"],
        "confusion_matrix": confusion_matrix(y_test, prediction).tolist(),
    }
    print(json.dumps(report, indent=2))
    (out / "metrics.json").write_text(json.dumps(report, indent=2), encoding="utf-8")

if __name__ == "__main__":
    main()
```

## 结果与解释

基线约为三分之一；逻辑回归通常显著优于基线。标准化放进 Pipeline 后，每一折都仅使用该折的训练部分拟合缩放参数。测试集不参与选择 `C`。`metrics.json` 保存实际指标，单次划分的高分仅说明本实验中的表现。
