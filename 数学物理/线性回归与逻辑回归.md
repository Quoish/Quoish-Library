# 从连续预测到类别概率

回归任务预测连续量，例如温度、价格或长度；分类任务预测离散类别。线性回归和逻辑回归都从输入特征的线性组合出发，但输出含义和损失函数不同。逻辑回归虽然名称包含“回归”，通常用于分类。

# 线性回归

令$x\in\mathbb R^d$为列向量，权重$w\in\mathbb R^d$，偏置$b\in\mathbb R$。预测为

$$
\hat y=w^Tx+b,\quad L=\frac1N\sum_i(\hat y_i-y_i)^2.
$$

若$x=2$、$w=3$、$b=1$，则预测为7。训练是调整$w,b$，使所有样本的平方误差尽量小。平方误差使大残差受到更大惩罚，因此容易受到异常值影响。

将每个样本转置后按行堆成设计矩阵$X\in\mathbb R^{N\times(d+1)}$，最后一列全为1，将偏置合并进参数向量$\beta$。若$X^TX$可逆，最小二乘解满足

$$
X^TX\beta=X^Ty,\quad \hat\beta=(X^TX)^{-1}X^Ty.
$$

实际数值计算通常使用 QR 分解、SVD 或最小二乘求解器，避免显式求逆。高度相关的特征会使解不稳定；Ridge 加入$\lambda\|w\|_2^2$以约束权重。

# 逻辑回归

二分类标签为$y\in\{0,1\}$，先计算分数$z=w^Tx+b$，再通过 Sigmoid 得到概率：

$$
p(y=1\mid x)=\sigma(z)=\frac1{1+e^{-z}}.
$$

$z=0$时概率为0.5；$z=\log3$时概率为0.75。对应的对数几率满足$\log\frac p{1-p}=z$，因此模型对对数几率作线性建模。

对独立伯努利标签进行最大似然估计，等价于最小化二元交叉熵：

$$
L=-\frac1N\sum_i[y_i\log p_i+(1-y_i)\log(1-p_i)].
$$

对单个样本，$\frac{\partial\ell}{\partial z}=p-y$，因此$\nabla_wL=\frac1N\sum_i(p_i-y_i)x_i$。该梯度使过高的正类概率降低，使过低的概率提高。

# 决策边界与非线性特征

使用0.5阈值时，决策边界是$w^Tx+b=0$。输入特征固定后，边界为超平面；若加入$x_1^2$、$x_1x_2$等非线性特征，则可以在原始坐标中得到曲线边界。

阈值与模型训练是不同环节。提高阈值通常减少判为正类的样本，可能提高精确率并降低召回率，具体取决于数据。多分类常使用 Softmax 回归，为各类分数产生归一化概率。

# 评价与局限

回归可使用 MSE、MAE 和$R^2$，分类可使用准确率、ROC-AUC 和对数损失。概率输出仍可能需要校准。特征遗漏、非线性关系和分布变化都会影响结果；回归系数的统计相关性不能直接解释为因果效应。

### `main.py`

```python
from pathlib import Path
import json
import numpy as np
import matplotlib
matplotlib.use("Agg")
import matplotlib.pyplot as plt
from sklearn.datasets import make_classification
from sklearn.linear_model import LinearRegression, LogisticRegression
from sklearn.model_selection import train_test_split
from sklearn.metrics import mean_squared_error, accuracy_score, log_loss
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler

def main():
    out = Path(__file__).resolve().parent / "outputs"
    out.mkdir(exist_ok=True)
    rng = np.random.default_rng(7)
    x = rng.uniform(-2, 2, (200, 1))
    y = 3 * x[:, 0] + 1 + rng.normal(0, 0.4, 200)
    a, b, c, d = train_test_split(x, y, test_size=0.25, random_state=7)
    regression = LinearRegression().fit(a, c)
    mse = mean_squared_error(d, regression.predict(b))
    features, labels = make_classification(n_samples=400, n_features=2,
        n_redundant=0, n_informative=2, n_clusters_per_class=1,
        class_sep=1.2, random_state=7)
    a, b, c, d = train_test_split(features, labels, test_size=0.25,
                                 stratify=labels, random_state=7)
    classifier = make_pipeline(StandardScaler(), LogisticRegression())
    classifier.fit(a, c)
    probability = classifier.predict_proba(b)[:, 1]
    report = {"slope": regression.coef_[0], "intercept": regression.intercept_,
              "test_mse": mse, "test_accuracy": accuracy_score(d, probability >= 0.5),
              "test_log_loss": log_loss(d, probability)}
    print(json.dumps(report, indent=2))
    (out / "metrics.json").write_text(json.dumps(report, indent=2), encoding="utf-8")
    fig, axes = plt.subplots(1, 2, figsize=(9, 3))
    axes[0].scatter(x[:, 0], y, s=8)
    grid = np.linspace(-2, 2, 100).reshape(-1, 1)
    axes[0].plot(grid[:, 0], regression.predict(grid), color="red")
    axes[0].set_title("Linear regression")
    axes[1].scatter(b[:, 0], b[:, 1], c=probability, vmin=0, vmax=1)
    axes[1].set_title("Logistic probability")
    fig.tight_layout()
    fig.savefig(out / "prediction.png", dpi=140)
    plt.close(fig)

if __name__ == "__main__":
    main()
```
