# 核心图景：先算分数，再解释分数

线性模型把各项特征乘以权重后加起来。**线性回归把这个结果当作连续预测；逻辑回归把它转换为类别概率**。两者共享“加权求和”这一骨架，任务含义和训练目标各有安排。

例如，预测房价需要输出一个连续数值；判断邮件是否垃圾，则需要输出类别或正类概率。先明确输出代表什么，才能决定模型最后一步和损失函数。

# 问题域与发展背景

线性回归承接了观测拟合与最小二乘的统计传统：测量有噪声，同一规律对应多组不完全一致的数据，需要从整体上估计趋势。它把“每条观测都精确通过”的要求，改为“对整体误差作合理折中”。

分类问题又提出了另一种需求：加权和可以是任意实数，类别概率却应落在0与1之间。逻辑回归把线性结构保留在**对数几率**上，再通过一个有界变换得到概率。这使模型既能做分类，也有明确的概率建模目标。两类方法的具体形式可参见[线性模型文档](https://scikit-learn.org/1.3/modules/linear_model.html)。

后来的 MLP、CNN 和 Transformer 都大量使用线性层。回顾这两种模型，也是在回顾深层网络中反复出现的基本构件。

# 线性回归：每个权重怎样影响预测

设$x\in\mathbb R^d$是列向量，包含$d$项特征；$w\in\mathbb R^d$是权重，$b$是偏置：

$$
\hat y=w^Tx+b=\sum_{j=1}^dw_jx_j+b.
$$

只预测一个变量时，这就是一条直线。若$\hat y=2x+1$，则$x$每增加1，预测增加2；偏置1负责把整条线向上平移。

这里“线性”主要指对参数的线性。把$x^2$预先作为一个特征，再拟合$a x^2+b x+c$，在原始输入上是一条曲线，但对待估参数$a,b,c$仍是线性模型。特征工程因此可以显著改变线性模型能表达的关系。

## 从残差到目标函数

单条样本的残差为$\hat y_i-y_i$。正负残差直接相加可能互相抵消，平方后再平均得到

$$
L(w,b)=\frac1N\sum_{i=1}^N(w^Tx_i+b-y_i)^2.
$$

对于样本$(x,y)=(1,3),(2,5)$，候选直线$\hat y=x+1$预测为2和3，残差为$-1,-2$，MSE为$(1+4)/2=2.5$；直线$\hat y=2x+1$恰好通过两点，MSE为0。真实数据通常有噪声，不必存在零误差的合理解。

平方项使大残差受到更重惩罚，所以少量异常值可能显著拉动拟合线。若需要降低这种影响，可以考虑绝对误差或 Huber 等其他目标。

## 为什么能写成一个矩阵问题

每行放一条样本，组成$X\in\mathbb R^{N\times d}$。再追加全1列，把偏置合并进参数$\beta$，便有$\hat y=X\beta$。令平方误差对参数的导数为零，得到正规方程：

$$
X^TX\beta=X^Ty.
$$

只有在$X^TX$可逆时，才可直接写成$(X^TX)^{-1}X^Ty$。特征重复、相关性很高或特征数过多，都可能造成奇异或数值不稳定。实际程序通常使用 QR、SVD 等最小二乘方法，避免显式求逆；加入 Ridge 正则也能约束不稳定的权重。

# 逻辑回归：把线性分数变成概率

二分类标签取$y\in\{0,1\}$。先计算一个未归一化分数$z=w^Tx+b$，常叫 logit，再作 Sigmoid 变换：

$$
p=P(y=1\mid x)=\sigma(z)=\frac1{1+e^{-z}}.
$$

可以记住三个位置：$z=0$时$p=0.5$；$z=\log3$时$p=0.75$；$z=-\log3$时$p=0.25$。大的正分数偏向正类，大的负分数偏向负类。

将公式反过来整理：

$$
\log\frac p{1-p}=w^Tx+b.
$$

$p/(1-p)$是正类对负类的几率，取对数后可遍历整个实数轴。因此权重是在对数几率空间中线性叠加，不能直接解释为“某特征增加1，概率就增加固定百分比”。

## 训练为什么使用交叉熵

对一条真实正类样本，模型给它概率0.9，应当比给0.1受到更小惩罚。伯努利模型的负对数似然给出

$$
\ell=-[y\log p+(1-y)\log(1-p)].
$$

当$y=1$，只剩$-\log p$：概率0.9的损失约0.105，概率0.1的损失约2.303。模型越自信地答错，损失越大。

它对 logit 的导数恰为

$$
\frac{\partial\ell}{\partial z}=p-y,\quad
\nabla_wL=\frac1N\sum_i(p_i-y_i)x_i.
$$

例如正类样本只预测到0.2，$p-y=-0.8$。梯度下降会沿着增大该样本分数的方向调整参数。梯度的完整计算过程见[[损失函数与反向传播]]。

# 决策边界、阈值与多分类

若规定$p\geq0.5$判为正类，那么边界就是$w^Tx+b=0$。在二维特征平面里它是一条直线；在更高维里是超平面。使用固定特征时，这也是逻辑回归表达能力的主要限制。

阈值不一定要取0.5。提高阈值会让更少的样本被判为正类，通常需要在精确率与召回率之间权衡。训练概率模型和选择业务阈值是两个环节。

多分类的 Softmax 回归为每类计算分数$z_k$，再归一化：

$$
p_k=\frac{e^{z_k}}{\sum_je^{z_j}}.
$$

所有类别概率之和为1。这里一个样本只属于一个类别；可同时属于多个标签的任务，输出建模方式需要另外安排。

# 从局限走向后续技术

| 当前困难 | 可考虑的方向 |
|---|---|
| 输入与目标关系有明确的弯曲趋势 | 非线性特征、核方法 |
| 需要自动组合复杂特征 | [[感知机与多层感知机]] |
| 高维特征相关、参数不稳定 | 正则化、降维、更多可靠数据 |
| 分类概率与真实频率不匹配 | 概率校准及独立评价 |

线性系数便于检查，但仍会受特征量纲、相关性和遗漏变量影响。一个系数为正，只表示在当前模型与特征条件下的统计关系，不能自动推出因果作用。

### `main.py`

```python
"""先拟合一条带噪声直线，再训练二维二分类模型并保存图像。"""

# 标准库
from pathlib import Path
import json

# 第三方库（由统一环境提供）
import numpy as np
import matplotlib

# 采用不弹出窗口的绘图后端；必须在导入 pyplot 之前设置。
matplotlib.use("Agg")
import matplotlib.pyplot as plt
from sklearn.datasets import make_classification
from sklearn.linear_model import LinearRegression, LogisticRegression
from sklearn.model_selection import train_test_split
from sklearn.metrics import mean_squared_error, accuracy_score, log_loss
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler


def main():
    """先拟合一条带噪声直线，再训练二维二分类模型并保存图像。

    按分段注释依次准备数据、执行计算并保存结果。
    """

    # 1. 建立输出目录，图像和指标统一写入 outputs/。
    out = Path(__file__).resolve().parent / "outputs"
    out.mkdir(exist_ok=True)

    # 2. 生成回归数据：随机生成器独立保存状态，固定种子便于对照。
    rng = np.random.default_rng(7)

    # x 为 (200, 1)，每行一个标量输入；标签 y 由真实直线加高斯噪声得到。
    x = rng.uniform(-2, 2, (200, 1))
    y = 3 * x[:, 0] + 1 + rng.normal(0, 0.4, 200)

    # 仅用训练集估计斜率与截距，在留出的测试集上计算误差。
    train_x, test_x, train_y, test_y = train_test_split(
        x, y, test_size=0.25, random_state=7
    )

    # 3. LinearRegression 内部求解最小二乘，无须手写训练循环。
    regression = LinearRegression().fit(train_x, train_y)

    # MSE 是测试残差平方的平均值，预期与噪声方差 0.4² 同量级。
    mse = mean_squared_error(test_y, regression.predict(test_x))

    # 4. 另外生成分类数据：400个二维样本，标签为0或1。
    features, labels = make_classification(
        n_samples=400,
        n_features=2,
        n_redundant=0,
        n_informative=2,
        n_clusters_per_class=1,
        class_sep=1.2,
        random_state=7,
    )

    # 分类按标签分层划分；下方更换为当前分类任务的训练／测试变量。
    train_x, test_x, train_y, test_y = train_test_split(
        features, labels, test_size=0.25, stratify=labels, random_state=7
    )

    # 先标准化，再拟合逻辑回归；预处理器只读取训练集。
    classifier = make_pipeline(StandardScaler(), LogisticRegression())
    classifier.fit(train_x, train_y)

    # predict_proba 返回两类概率；[:, 1] 取正类概率，0.5是本例决策阈值。
    probability = classifier.predict_proba(test_x)[:, 1]

    # 5. 分别记录回归误差、分类准确率与概率质量，避免只看单一指标。
    report = {
        "slope": regression.coef_[0],
        "intercept": regression.intercept_,
        "test_mse": mse,
        "test_accuracy": accuracy_score(test_y, probability >= 0.5),
        "test_log_loss": log_loss(test_y, probability),
    }
    print(json.dumps(report, indent=2))
    (out / "metrics.json").write_text(json.dumps(report, indent=2), encoding="utf-8")

    # 6. 左图画回归散点与拟合直线，右图用颜色表示测试样本的正类概率。
    fig, axes = plt.subplots(1, 2, figsize=(9, 3))
    axes[0].scatter(x[:, 0], y, s=8)

    # 将等间距输入整理为 (100, 1)，保持与训练特征相同的二维接口。
    grid = np.linspace(-2, 2, 100).reshape(-1, 1)
    axes[0].plot(grid[:, 0], regression.predict(grid), color="red")
    axes[0].set_title("Linear regression")
    axes[1].scatter(test_x[:, 0], test_x[:, 1], c=probability, vmin=0, vmax=1)
    axes[1].set_title("Logistic probability")

    # 自动调整子图间距，避免标题和坐标标签被裁切。
    fig.tight_layout()
    fig.savefig(out / "prediction.png", dpi=140)

    # 关闭已保存的图对象，避免反复运行时积累绘图资源。
    plt.close(fig)


if __name__ == "__main__":
    main()
```
