# 从“预测错误”到可优化的量

损失函数将预测与训练目标之间的差异转成标量。优化器依据这个标量的梯度更新参数，因此损失需要与任务及输出的含义对应。分类准确率包含离散比较，通常不能直接提供有用梯度；训练常采用交叉熵，评价时再计算准确率。

# 常见损失与输出形式

回归的均方误差为$L=\frac1N\sum_i(\hat y_i-y_i)^2$，对离群误差敏感。MAE 使用绝对值，对大误差的梯度幅度较稳定；Huber 在小误差附近用平方、大误差处用近似线性形式。

二分类可使用二元交叉熵。实现中的 `BCEWithLogitsLoss` 接收未经过 Sigmoid 的分数，利用稳定的组合公式计算，避免先得到极接近0或1的概率再取对数。

多分类模型为每个类别输出一个 logit，记为$z_k$：

$$
p_k=\frac{e^{z_k}}{\sum_je^{z_j}},\quad
\ell=-\sum_ky_k\log p_k.
$$

若$y$是 one-hot，损失就是正确类别的负对数概率。交叉熵对 logits 的导数为$p_k-y_k$。数值实现使用减去最大 logit 的 log-sum-exp 技巧。PyTorch 的 `CrossEntropyLoss` 直接接收 logits 和整数类别编号，无需提前调用 Softmax。

# 链式法则如何成为反向传播

计算图记录中间量之间的依赖。设$z=wx+b$，$\ell=\frac12(z-y)^2$，则

$$
\frac{\partial\ell}{\partial z}=z-y,\quad
\frac{\partial\ell}{\partial w}=(z-y)x,\quad
\frac{\partial\ell}{\partial b}=z-y.
$$

当$x=2,y=5,w=1,b=0$时，$z=2$，损失为4.5，两个参数的梯度分别为$-6,-3$。学习率0.1的一步更新得到$w=1.6,b=0.3$，新预测为3.5，损失降到1.125。

多层网络也是依次计算各节点的局部导数，并从输出向输入累积。一个量影响多个后续分支时，其梯度是各分支贡献之和。反向传播是高效计算梯度的算法；梯度下降、Adam 等优化器使用这些梯度更新参数，两者分工不同。

# 自动微分与实现细节

反向模式自动微分对计算图中的基本操作使用已知导数，并不靠逐个参数扰动估计导数。有限差分适合检查小规模实现：

$$
\frac{\partial L}{\partial\theta_j}\approx
\frac{L(\theta+\varepsilon e_j)-L(\theta-\varepsilon e_j)}{2\varepsilon}.
$$

$\varepsilon$过大带来截断误差，过小则有浮点消减误差。检查通常使用双精度并避开 ReLU 在零点等不可导位置。

PyTorch 的 `.backward()` 会将梯度累加到叶子参数的 `.grad`，每轮更新前通常要清零。`model.eval()` 改变 Dropout、BatchNorm 的行为；`torch.no_grad()` 关闭梯度记录，两者用途不同。反向传播计算出的梯度还可能消失或爆炸，不保证优化一定成功。

### `runtime.py`

```python
from pathlib import Path
import argparse
import random
import numpy as np
import torch

ROOT = Path(__file__).resolve().parent
OUT = ROOT / "outputs"
OUT.mkdir(exist_ok=True)

def setup():
    parser = argparse.ArgumentParser()
    parser.add_argument("--cpu", action="store_true")
    args = parser.parse_args()
    random.seed(7)
    np.random.seed(7)
    torch.manual_seed(7)
    torch.set_num_threads(2)
    device = torch.device("cuda" if torch.cuda.is_available() and not args.cpu else "cpu")
    print("device:", device)
    return device
```

### `main.py`

```python
import json
import torch
from runtime import setup, OUT

def objective(w, b):
    return 0.5 * (2 * w + b - 5) ** 2

def main():
    device = setup()
    w = torch.tensor(1., dtype=torch.float64, device=device, requires_grad=True)
    b = torch.tensor(0., dtype=torch.float64, device=device, requires_grad=True)
    loss = objective(w, b)
    loss.backward()
    manual = torch.tensor([-6., -3.], dtype=torch.float64, device=device)
    auto = torch.stack([w.grad, b.grad])
    eps = 1e-5
    with torch.no_grad():
        finite = torch.stack([
            (objective(w + eps, b) - objective(w - eps, b)) / (2 * eps),
            (objective(w, b + eps) - objective(w, b - eps)) / (2 * eps)])
        assert torch.allclose(auto, manual)
        assert torch.allclose(auto, finite, atol=1e-8)
        old = loss.item()
        w -= 0.1 * w.grad
        b -= 0.1 * b.grad
        new = objective(w, b).item()
    report = {"manual": manual.cpu().tolist(), "autograd": auto.cpu().tolist(),
              "finite_difference": finite.cpu().tolist(), "old_loss": old,
              "new_loss": new, "new_w": w.item(), "new_b": b.item()}
    print(report)
    (OUT / "gradients.json").write_text(json.dumps(report, indent=2), encoding="utf-8")

if __name__ == "__main__":
    main()
```

## 结果与解释

三个梯度结果应接近 `[-6, -3]`，更新前后损失分别为4.5和1.125。两个断言直接验证梯度一致性。这里的结果是解析可核对的确定性数值，不依赖模型是否学到某种语义。
