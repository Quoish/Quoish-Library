# 语言模型在预测什么

语言模型给词元序列分配概率。自回归分解将联合概率写成条件概率的乘积：

$$
P(x_1,\ldots,x_T)=\prod_{t=1}^TP(x_t\mid x_{<t}).
$$

训练常最小化下一词元负对数似然：

$$
L=-\frac1M\sum_{t\in\mathcal I}\log P_\theta(x_t\mid x_{<t}),
$$

$\mathcal I$是参与损失的有效位置集合，$M$为其大小。输入和标签相差一个位置；因果掩码防止提前看见答案。模型通过大量预测任务学习词法、知识关联和一定的任务模式，但输出概率不直接等于事实正确性。

# 从预训练到对话

预训练在大量语料上学习通用分布。指令微调使用任务、对话和参考回答，使模型学会按照提示完成任务；对话训练常只对助手回答位置计损失。偏好对齐利用回答比较或奖励信号调整输出倾向，例如 RLHF 或直接偏好优化。这些阶段可以改善行为，但仍依赖数据质量、评价目标与任务范围。

大语言模型中的“大”涉及参数、数据和计算规模。微型网络可以演示目标与生成流程，无法复现大规模训练带来的语言能力。模型规模、架构与上下文长度也不能单独决定某个具体任务的可靠性。

# 生成是怎样逐步发生的

给定前缀，模型输出词表 logits，经 Softmax 得到下一个词元的分布。选出一个词元后，将它接到前缀末尾并重复，直到结束词元或长度上限。

贪心策略每步选最大概率词元，不保证整个序列概率最大。温度采样使用

$$
p_i(T)=\frac{\exp(z_i/T)}{\sum_j\exp(z_j/T)},\quad T>0.
$$

低温度通常使分布更尖锐，高温度增加随机性。Top-k 限制候选词元数，Top-p 保留累计概率达到阈值的一组高概率候选。不同采样方式影响多样性，无法单靠参数消除幻觉。

# 推理中的工程概念

上下文窗口限制一次可处理的词元位置。长对话还需考虑提示、历史和输出的总长度。KV cache 复用先前注意力键值，减少逐步生成的重复工作；量化降低权重存储精度，可能减少内存并影响速度或效果。它们与通过梯度更新权重的训练是不同操作。

聊天模型通常需要专用对话模板，不能把任意字符串拼接方式当作等价输入。tokenizer 的 `apply_chat_template` 按模型约定组织角色与结束标记。

# 怎样评价

困惑度$\mathrm{PPL}=\exp(L)$依赖 tokenizer、数据和损失计量方式，跨分词器比较需谨慎。训练语料的低损失可能来自记忆；应使用独立数据与具体任务评价。事实性、指令遵循、稳定性和运行成本也需要分别测量。

from pathlib import Path
import argparse
import random
import numpy as np
import torch

ROOT = Path(__file__).resolve().parent
OUT = ROOT / "outputs"
OUT.mkdir(exist_ok=True)

def setup():
    parser = argparse.ArgumentParser()
    parser.add_argument("--cpu", action="store_true")
    args = parser.parse_args()
    random.seed(7)
    np.random.seed(7)
    torch.manual_seed(7)
    torch.set_num_threads(2)
    device = torch.device("cuda" if torch.cuda.is_available() and not args.cpu else "cpu")
    print("device:", device)
    return device

### `model.py`

```python
import torch
from torch import nn

class CharLM(nn.Module):
    def __init__(self, vocab, context=32):
        super().__init__()
        self.token = nn.Embedding(vocab, 48)
        self.position = nn.Embedding(context, 48)
        block = nn.TransformerEncoderLayer(48, 4, dim_feedforward=96,
            dropout=0, batch_first=True, norm_first=True)
        self.blocks = nn.TransformerEncoder(block, 2, enable_nested_tensor=False)
        self.norm = nn.LayerNorm(48)
        self.head = nn.Linear(48, vocab)

    def forward(self, ids):
        t = ids.shape[1]
        x = self.token(ids) + self.position(torch.arange(t, device=ids.device))
        mask = torch.ones(t, t, dtype=torch.bool, device=ids.device).triu(1)
        return self.head(self.norm(self.blocks(x, mask=mask)))
```

### `train.py`

```python
import json
import torch
from torch import nn
from runtime import setup, OUT
from model import CharLM

def main():
    device = setup()
    text = ("春天开花。夏天听雨。秋天落叶。冬天看雪。\n" * 40)
    chars = sorted(set(text))
    stoi = {c: i for i, c in enumerate(chars)}
    data = torch.tensor([stoi[c] for c in text], device=device)
    model = CharLM(len(chars)).to(device)
    optimizer = torch.optim.Adam(model.parameters(), lr=0.003)
    initial = None
    for step in range(250):
        starts = torch.randint(0, len(data)-25, (16,), device=device)
        indices = starts[:, None] + torch.arange(24, device=device)
        x, y = data[indices], data[indices + 1]
        optimizer.zero_grad()
        logits = model(x)
        loss = nn.functional.cross_entropy(logits.reshape(-1, len(chars)), y.reshape(-1))
        if initial is None:
            initial = loss.item()
        loss.backward()
        torch.nn.utils.clip_grad_norm_(model.parameters(), 1)
        optimizer.step()
    model.eval()
    generated = torch.tensor([[stoi["春"]]], device=device)
    with torch.no_grad():
        for _ in range(60):
            next_id = model(generated[:, -32:])[:, -1].argmax(-1, keepdim=True)
            generated = torch.cat([generated, next_id], dim=1)
    sample = "".join(chars[i] for i in generated[0].tolist())
    print("initial loss:", initial, "final loss:", loss.item())
    print(sample)
    (OUT / "sample.txt").write_text(sample, encoding="utf-8")
    (OUT / "metrics.json").write_text(json.dumps({"initial_loss": initial,
        "final_loss": loss.item()}, indent=2), encoding="utf-8")
    torch.save({"state": model.state_dict(), "chars": chars}, OUT / "char_lm.pt")

if __name__ == "__main__":
    main()
```

### `pretrained.py`

```python
import torch
from transformers import AutoTokenizer, AutoModelForCausalLM
from runtime import setup, OUT

def main():
    device = setup()
    model_id = "Qwen/Qwen2.5-0.5B-Instruct"
    tokenizer = AutoTokenizer.from_pretrained(model_id)
    dtype = torch.float16 if device.type == "cuda" else torch.float32
    model = AutoModelForCausalLM.from_pretrained(model_id, torch_dtype=dtype,
        use_safetensors=True, attn_implementation="eager").to(device).eval()
    messages = [{"role": "system", "content": "你是一位简明的中文教学助手。"},
                {"role": "user", "content": "用两句话解释什么是神经网络中的权重。"}]
    text = tokenizer.apply_chat_template(messages, tokenize=False, add_generation_prompt=True)
    inputs = tokenizer(text, return_tensors="pt").to(device)
    with torch.inference_mode():
        ids = model.generate(**inputs, max_new_tokens=96, do_sample=False,
            temperature=None, top_p=None, top_k=None, pad_token_id=tokenizer.eos_token_id)
    answer = tokenizer.decode(ids[0, inputs.input_ids.shape[1]:], skip_special_tokens=True)
    print(answer)
    (OUT / "pretrained_answer.txt").write_text(answer, encoding="utf-8")

if __name__ == "__main__":
    main()
```

## 结果与解释

微型训练的最终损失应显著低于初始值，生成通常复现四季句式。重复语料使记忆很容易，项目没有独立泛化测试，也不应把它解释为模型学会了常识。预训练入口输出实际中文回答，内容仍需核对；权重下载和 CPU 推理耗时取决于网络与硬件。
