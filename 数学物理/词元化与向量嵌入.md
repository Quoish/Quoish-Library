# 文本如何成为模型输入

神经网络处理数值张量。文本通常先由 tokenizer 拆成词元，再映射为整数编号，最后查表得到稠密向量。词元可能是字、词、子词或字节片段；一个汉字、一个单词和一个 token 之间没有固定的一一对应。

BPE 逐步合并常见符号对，WordPiece 和 Unigram 采用不同的词表构造原则。分词方式影响词表大小、序列长度、罕见词处理和计算成本。预训练模型必须搭配其原有 tokenizer，任意重排词表会使编号与权重失配。

# One-hot 与嵌入矩阵

词表大小为$V$时，第$i$个词元可以表示为$e_i\in\mathbb R^V$的 one-hot 向量。嵌入矩阵$E\in\mathbb R^{V\times d}$把编号映射为

$$
v_i=E^Te_i.
$$

实际实现直接查第$i$行，避免构造巨大 one-hot。参数量是$Vd$。`nn.Embedding` 初始化时只是随机表；只有在训练目标推动下，向量之间才可能形成对任务有用的结构。向量每一维通常没有固定的可命名语义。

# Word2Vec 如何学习分布式表示

分布假设认为出现在相似上下文中的词往往具有某种相似性。Skip-gram 用中心词预测附近上下文；CBOW 反过来用上下文预测中心词。

对中心$c$和上下文$o$，完整 Softmax 的概率为

$$
P(o\mid c)=\frac{\exp(u_o^Tv_c)}{\sum_{j=1}^V\exp(u_j^Tv_c)},\quad
L=-\sum_{(c,o)}\log P(o\mid c).
$$

$v$与$u$通常来自两套参数表。大词表下，完整归一化代价较高，负采样用正样本和抽取的负词构成另一训练目标。本例采用完整 Softmax，便于逐项理解，不声称实现了全部 Word2Vec 工程技巧。

# 静态词向量、上下文表示与句向量

静态嵌入给同一个词元同一个初始向量；Transformer 等上下文模型使后续表示依赖整段上下文，从而能区分“苹果公司”和“吃苹果”。句向量则把文本编码为固定长度向量，常用池化并通过检索或对比目标训练。

把任意语言模型隐藏状态简单平均，不保证能得到高质量检索向量；使用专门训练的嵌入模型通常更合适。输入嵌入层、上下文隐藏状态与检索句向量需要分别理解。

# 相似度与意义

余弦相似度为

$$
\cos(a,b)=\frac{a^Tb}{\|a\|\|b\|}.
$$

对单位化向量，它等于内积，欧氏距离平方为$2-2a^Tb$。相似度依赖模型、任务和训练数据，不是通用的语义真值。词类比也只是部分模型中的经验现象，无法保证一般代数运算等同于可靠推理。

### `runtime.py`

```python
from pathlib import Path
import argparse
import random
import numpy as np
import torch

ROOT = Path(__file__).resolve().parent
OUT = ROOT / "outputs"
OUT.mkdir(exist_ok=True)

def setup():
    parser = argparse.ArgumentParser()
    parser.add_argument("--cpu", action="store_true")
    args = parser.parse_args()
    random.seed(7)
    np.random.seed(7)
    torch.manual_seed(7)
    torch.set_num_threads(2)
    device = torch.device("cuda" if torch.cuda.is_available() and not args.cpu else "cpu")
    print("device:", device)
    return device
```

### `main.py`

```python
import json
import torch
from torch import nn
from runtime import setup, OUT

def main():
    device = setup()
    sentences = ["猫 喜欢 鱼", "小猫 喜欢 鱼", "狗 喜欢 骨头", "小狗 喜欢 骨头",
        "猫 是 动物", "狗 是 动物", "小猫 是 动物", "小狗 是 动物",
        "苹果 是 水果", "香蕉 是 水果", "苹果 可以 食用", "香蕉 可以 食用"]
    corpus = [s.split() for s in sentences]
    words = sorted({word for row in corpus for word in row})
    stoi = {word: i for i, word in enumerate(words)}
    pairs = [(stoi[row[i]], stoi[row[j]]) for row in corpus for i in range(len(row))
             for j in range(len(row)) if i != j and abs(i-j) <= 1]
    pairs = torch.tensor(pairs, device=device)
    embedding = nn.Embedding(len(words), 12).to(device)
    output = nn.Linear(12, len(words)).to(device)
    optimizer = torch.optim.Adam(list(embedding.parameters()) + list(output.parameters()), lr=0.03)
    for step in range(500):
        optimizer.zero_grad()
        logits = output(embedding(pairs[:, 0]))
        loss = nn.functional.cross_entropy(logits, pairs[:, 1])
        loss.backward()
        optimizer.step()
    vectors = nn.functional.normalize(embedding.weight.detach(), dim=1)
    query = stoi["猫"]
    similarity = vectors @ vectors[query]
    neighbors = [(words[i], float(similarity[i])) for i in similarity.argsort(descending=True)[1:6]]
    print("loss:", loss.item(), "neighbors:", neighbors)
    torch.save({"words": words, "embedding": embedding.weight.detach().cpu()}, OUT / "embedding.pt")
    (OUT / "neighbors.json").write_text(json.dumps(neighbors, ensure_ascii=False, indent=2), encoding="utf-8")

if __name__ == "__main__":
    main()
```

### `semantic.py`

```python
import json
from sentence_transformers import SentenceTransformer
from runtime import setup, OUT

def main():
    device = setup()
    model = SentenceTransformer("BAAI/bge-small-zh-v1.5", device=str(device))
    documents = ["猫喜欢吃鱼。", "苹果和香蕉属于水果。", "卷积神经网络可以处理图像。"]
    query = "小猫爱吃什么？"
    vectors = model.encode(documents, normalize_embeddings=True)
    q = model.encode(["为这个句子生成表示以用于检索相关文章：" + query], normalize_embeddings=True)[0]
    scores = vectors @ q
    ranking = sorted(zip(documents, scores.tolist()), key=lambda item: item[1], reverse=True)
    print(ranking)
    (OUT / "semantic.json").write_text(json.dumps(ranking, ensure_ascii=False, indent=2), encoding="utf-8")

if __name__ == "__main__":
    main()
```

## 结果与解释

小语料 Skip-gram 的损失应下降，但邻居关系可能不稳定：语料极小，共享上下文也很有限。它展示可训练查表与预测目标，不足以验证语言语义。句向量项目应把关于猫吃鱼的句子排在前面；余弦分数不能直接解释为答案正确概率。
