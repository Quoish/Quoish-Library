# 核心图景：没有答案标签时，先问数据有什么结构

给出一批顾客记录，却没有“应该分成哪类”的标签；或者每条测量有几百个相关读数，希望压成几个坐标。这些问题很难直接套用监督分类的输入—标签配对。

聚类讨论哪些样本彼此接近，降维讨论哪些表示可以用更少坐标保留某种信息。它们优化的目标不同，也未必得到同一种“真实结构”。

# 问题域与发展背景

PCA 承接多变量统计的思路：多个测量常常随同一因素一起变化，可以换一组坐标轴来表达主要变化。它适合回顾“相关特征怎样变成少数综合方向”这一问题。

K-means 承接无标签分组与量化的思路：若要用少数代表点描述很多样本，怎样安排这些代表点，才能减少整体平方距离？因此它也与压缩、原型表示和矢量量化有关。

后来出现的非线性降维、密度聚类和深层潜变量模型，分别继续处理弯曲结构、非球形簇和复杂分布。PCA 与 K-means 仍保留了目标明确、便于手算和检查的优势。

# K-means：用几个中心代表一群点

先规定簇数$K$。每条样本$x_i$分到一个簇，编号为$c_i$；每个簇有中心$\mu_k$。目标是让样本到所属中心的平方距离之和尽量小：

$$
J=\sum_{i=1}^N\|x_i-\mu_{c_i}\|_2^2.
$$

中心和归属都未知。常用算法交替处理两个容易的子问题：

1. 中心先不动，把每个样本分给最近的中心。
2. 归属先不动，把每个中心移到组内样本均值。
3. 重复，直到分配稳定或达到停止条件。

均值在这里很自然：对固定分组，平方误差关于中心求导为零，解就是组内均值。两步分别不增加目标值，但整体目标不是凸问题，初始中心不同仍可能走到不同的局部解。

## 一维手算

样本为$0,1,9,10$，取两个中心，初值为0、10。最近分配得到$\{0,1\}$与$\{9,10\}$，更新中心为0.5、9.5。四个点分别离中心0.5，故总平方误差为$4\times0.5^2=1$。

若只取一个中心5，平方误差变成$25+16+16+25=82$。增加中心可以降低训练目标，却会增加复杂度；不能只按误差越来越小就把$K$无限增大。

K-means++ 与多次初始化有助于减少不良初值的影响。它偏好紧凑、近似球状、尺度相近的簇。双月形数据可能被直线式分界切错，离群点也会拉动均值中心。

# PCA：给同一批点重新选择坐标轴

假设二维点云沿一条斜线拉得很长，而垂直斜线方向只有很小扰动。只保留原来的横坐标会丢失一部分主要变化；把坐标轴旋转到斜线方向，再保留这一个坐标，通常更能描述点的位置。

PCA 先中心化，让每个特征减去样本均值。设中心化矩阵$X\in\mathbb R^{N\times d}$，每行一条样本；沿单位列向量$v$投影后的坐标是$Xv$。

投影方差为

$$
\operatorname{Var}(Xv)=\frac1{N-1}\|Xv\|^2
=v^T\Sigma v,\quad \Sigma=\frac1{N-1}X^TX.
$$

$\Sigma$是协方差矩阵：对角项是单个特征的方差，非对角项描述两个特征如何一起偏离均值。第一主成分找使投影方差最大的单位方向；它是最大特征值对应的特征向量。

第二主成分在与第一方向正交的条件下继续保留最多方差，后续依次类推。正交使这些方向不会重复描述同一个线性变化方向。

## 一个能完全看清的例子

取三个已中心化的点$(-1,-1),(0,0),(1,1)$，有

$$
\Sigma=\begin{bmatrix}1&1\\1&1\end{bmatrix}.
$$

沿横轴投影得到$-1,0,1$，方差为1；沿$v=(1,1)^T/\sqrt2$投影得到$-\sqrt2,0,\sqrt2$，方差为2。与它正交的方向没有变化，方差为0。

因此这批二维数据用一个斜向坐标就能无损表示。真实数据通常只近似靠近低维子空间，保留一个方向就会舍弃其余方向上的细节。

# 降维之后如何重建

把前$k$个单位方向作为列放进$V_k$，低维坐标与重建为

$$
Z=XV_k,\quad \hat X=ZV_k^T.
$$

$Z$有$k$列，记录每条样本沿各主方向走了多远；乘回$V_k^T$，就把这些坐标放回原空间。若之前减去了均值，恢复实际数据时还要加回均值。

对中心化数据，PCA 选出的子空间也使平方重建误差最小。这里限定的是**线性、正交子空间与平方误差**，并不表示所有降维目标都会得到 PCA。

# 量纲、方差与任务信息

若一个特征用米、另一个用毫米，数值方差的比较会受到单位影响。标准化后再做 PCA，实际改变了对各特征变化的重视程度；是否标准化需要结合问题含义。

解释方差比表示保留了多少原数据方差。假如决定类别的是一个幅度很小的特征，而大方差方向主要是无关扰动，PCA 可能舍弃最有用的分类信息。高解释方差因此不等同于高任务准确率。

# 怎样评价没有标签的结果

聚类可以用轮廓系数检查几何分离。设$a_i$是样本到同簇其他样本的平均距离，$b_i$是它到最近另一个簇的平均距离，则在非退化情形下

$$
s_i=\frac{b_i-a_i}{\max(a_i,b_i)}.
$$

接近1通常表示“自己簇内近、其他簇远”，接近0表示位于簇间，负值可能说明更接近其他簇。这个指标也有几何偏好，不能代替业务语义。

下方例程的真实簇标签只用于最后对照，不参与 PCA 或 K-means 拟合。PCA 图形、轮廓系数与调整兰德指数回答的是不同问题，应一起看。若把降维接到监督预测前面，则必须只用训练数据拟合降维器，避免泄漏。

### `main.py`

```python
"""先用 PCA 压缩三维数据，再用 K-means 分组并评价几何结构。"""

# 标准库
from pathlib import Path
import json

# 第三方库（由统一环境提供）
import matplotlib

# 采用不弹出窗口的绘图后端；必须在导入 pyplot 之前设置。
matplotlib.use("Agg")
import matplotlib.pyplot as plt
from sklearn.datasets import make_blobs
from sklearn.preprocessing import StandardScaler
from sklearn.decomposition import PCA
from sklearn.cluster import KMeans
from sklearn.metrics import silhouette_score, adjusted_rand_score


def main():
    """先用 PCA 压缩三维数据，再用 K-means 分组并评价几何结构。

    按分段注释依次准备数据、执行计算并保存结果。
    """

    # 1. 准备结果目录。
    out = Path(__file__).resolve().parent / "outputs"
    out.mkdir(exist_ok=True)

    # 2. 生成450个三维样本；truth 仅作合成实验的评价标签，不参与聚类。
    x, truth = make_blobs(
        n_samples=450, n_features=3, centers=3, cluster_std=0.8, random_state=7
    )

    # 将各特征缩放到可比较的尺度，避免大数值量纲支配方差与距离。
    scaled = StandardScaler().fit_transform(x)

    # 3. 保留两个主成分：三维输入将变成二维表示。
    pca = PCA(n_components=2)

    # 先拟合主方向，再投影；z 的形状为 (450, 2)。
    z = pca.fit_transform(scaled)

    # 4. 在二维表示中聚成3组；多次初始化降低偶然初始中心的影响。
    predicted = KMeans(n_clusters=3, n_init=10, random_state=7).fit_predict(z)

    # 轮廓系数仅使用特征和预测簇；调整兰德指数额外使用已知合成标签。
    report = {
        "explained_variance_ratio": pca.explained_variance_ratio_.tolist(),
        "silhouette": silhouette_score(z, predicted),
        "adjusted_rand": adjusted_rand_score(truth, predicted),
    }
    print(json.dumps(report, indent=2))
    (out / "metrics.json").write_text(json.dumps(report, indent=2), encoding="utf-8")

    # 5. 同一投影下对照真实分组和预测分组；簇编号及颜色可以任意置换。
    fig, axes = plt.subplots(1, 2, figsize=(8, 3))

    # 两张图使用同一坐标，便于观察分组差别。
    for ax, labels, title in zip(axes, [truth, predicted], ["True groups", "K-means"]):
        ax.scatter(z[:, 0], z[:, 1], c=labels, s=10)
        ax.set_title(title)

    # 自动调整子图间距，避免标题和坐标标签被裁切。
    fig.tight_layout()
    fig.savefig(out / "clusters.png", dpi=140)

    # 关闭已保存的图对象，避免反复运行时积累绘图资源。
    plt.close(fig)


if __name__ == "__main__":
    main()
```
