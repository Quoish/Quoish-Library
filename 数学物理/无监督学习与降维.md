# 没有标签时能学习什么

无监督学习利用输入数据自身的结构。聚类寻找相似对象形成的群组；降维以较少坐标保留某种信息；密度建模描述数据分布。算法产生的结构需要结合任务解释，聚类编号本身没有预先规定的语义。

# K-means 聚类

给定$K$个中心$\mu_1,\ldots,\mu_K$，K-means 最小化样本到所属中心的平方距离：

$$
J=\sum_{i=1}^N\|x_i-\mu_{c_i}\|_2^2.
$$

算法交替执行两步：固定中心，为每个样本分配最近中心；固定分配，将每个中心更新为组内均值。两步都不增加目标，但整体问题非凸，不保证达到全局最优。K-means++ 和多次初始化可以改善稳定性。

例如一维样本$0,1,9,10$，取两个群组时，划为$\{0,1\}$和$\{9,10\}$的中心为0.5、9.5，平方误差和为1。若将四点都归于同一中心5，平方误差和为82。

欧氏距离使尺度大的特征影响更大。K-means 更适合紧凑、近似球状的簇；弯月形、不同密度或离群点较多的数据可能需要 DBSCAN、混合模型等方法。$K$需结合轮廓系数、稳定性和实际任务选择。

# PCA：寻找最大方差的方向

设中心化后的样本矩阵为$X\in\mathbb R^{N\times d}$，每行一个样本。沿单位方向$v$投影后的样本方差为

$$
\frac1{N-1}\|Xv\|^2=v^T\Sigma v,\quad
\Sigma=\frac1{N-1}X^TX.
$$

第一主成分求解$\max_{\|v\|=1}v^T\Sigma v$，解为最大特征值对应的特征向量。后续主成分在与已有方向正交的条件下继续最大化方差。取前$k$个方向组成$V_k$，低维表示为$Z=XV_k$，重建为$\hat X=ZV_k^T$。

中心化 PCA 同时给出最小化平方重建误差的秩$k$线性子空间。标准化不是 PCA 定义中的强制步骤，但特征量纲差异很大时通常需要考虑。若某个大方差方向主要是噪声，最大方差不等于最大任务价值。

# 评价与常见误解

PCA 的解释方差比描述保留了多少样本方差，不等同于保留了相同比例的语义。二维可视化会丢失信息，投影重叠的点在原空间仍可能可分。聚类也不会自动发现唯一“正确分类”。如果用降维结果辅助后续监督学习，应只在训练集拟合降维器。

### `main.py`

```python
from pathlib import Path
import json
import matplotlib
matplotlib.use("Agg")
import matplotlib.pyplot as plt
from sklearn.datasets import make_blobs
from sklearn.preprocessing import StandardScaler
from sklearn.decomposition import PCA
from sklearn.cluster import KMeans
from sklearn.metrics import silhouette_score, adjusted_rand_score

def main():
    out = Path(__file__).resolve().parent / "outputs"
    out.mkdir(exist_ok=True)
    x, truth = make_blobs(n_samples=450, n_features=3, centers=3,
                          cluster_std=0.8, random_state=7)
    scaled = StandardScaler().fit_transform(x)
    pca = PCA(n_components=2)
    z = pca.fit_transform(scaled)
    predicted = KMeans(n_clusters=3, n_init=10, random_state=7).fit_predict(z)
    report = {"explained_variance_ratio": pca.explained_variance_ratio_.tolist(),
              "silhouette": silhouette_score(z, predicted),
              "adjusted_rand": adjusted_rand_score(truth, predicted)}
    print(json.dumps(report, indent=2))
    (out / "metrics.json").write_text(json.dumps(report, indent=2), encoding="utf-8")
    fig, axes = plt.subplots(1, 2, figsize=(8, 3))
    for ax, labels, title in zip(axes, [truth, predicted], ["True groups", "K-means"]):
        ax.scatter(z[:, 0], z[:, 1], c=labels, s=10)
        ax.set_title(title)
    fig.tight_layout()
    fig.savefig(out / "clusters.png", dpi=140)
    plt.close(fig)

if __name__ == "__main__":
    main()
```

## 结果与解释

两个主成分的解释方差比之和描述投影保留的方差。轮廓系数接近1通常表示簇内更紧凑、簇间更分离，但它偏好特定几何形状。调整兰德指数用于与已知合成标签对照，能忽略簇编号的任意置换。
