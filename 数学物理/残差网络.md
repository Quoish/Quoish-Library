# 深度增加为何可能更难训练

更深的网络通常拥有更大的表达空间，但优化不一定更容易。原始 ResNet 工作关注“退化问题”：某些更深普通网络连训练误差也比浅层高，不能仅归因于过拟合。即便较深模型理论上可通过恒等映射包含浅层解，优化器也未必容易找到它。

# 残差块的表达

残差块将输入沿捷径相加：

$$
y=x+F(x;\theta).
$$

若期望映射为$H(x)$，残差支路学习$F(x)=H(x)-x$。当需要接近恒等映射时，让残差接近零便能实现。这里的“残差”是相对于输入的映射增量，不是监督回归中的标签预测误差。

例如标量映射希望从$x$得到$1.1x$，残差只需表示$0.1x$。这说明参数化方式改变了优化问题的组织，但不意味着所有训练情况下残差数值都很小。

# 梯度为何有额外通路

令$g=\nabla_yL$为列梯度，则

$$
\nabla_xL=(I+J_F(x))^Tg.
$$

恒等路径提供了直接传递梯度的项。多块叠加可以形成较短的信息与梯度路径，通常有利于深层优化；$J_F$仍可能引起抵消、放大或其他不稳定，不能据此保证梯度永不消失。

# 形状不同时怎么办

逐元素相加要求形状匹配。若空间尺寸或通道数改变，使用投影捷径$P(x)$：

$$
y=P(x)+F(x).
$$

常用1×1卷积调整通道，步长2同时下采样。投影路径的导数也不再是恒等矩阵。本例由$(B,8,16,16)$变为$(B,16,8,8)$时，两条支路都执行对应变换。

# BasicBlock、瓶颈与归一化位置

BasicBlock 常使用两个3×3卷积。瓶颈块通过1×1降维、3×3处理、1×1升维控制计算成本。原始后激活形式在相加后使用激活；预激活变体把归一化和激活移入支路之前，以改善恒等路径。

残差连接是一种可复用结构，CNN、Transformer 和扩散模型都可使用。完整 ResNet 还包括具体层数、下采样安排、归一化与训练配方；包含一次相加的网络不等同于标准 ResNet-18。

# 实验应怎样解释

比较残差与普通网络时，应控制数据、深度和优化设置。小任务与浅网络可能看不到明显优势；模型参数量、投影和归一化也会影响结果。本例用于检验形状匹配、梯度和训练闭环，不据单次结果宣称残差网络普遍更优。

# 可复原例程

### `runtime.py`

```python
from pathlib import Path
import argparse
import random
import numpy as np
import torch

ROOT = Path(__file__).resolve().parent
OUT = ROOT / "outputs"
OUT.mkdir(exist_ok=True)

def setup():
    parser = argparse.ArgumentParser()
    parser.add_argument("--cpu", action="store_true")
    args = parser.parse_args()
    random.seed(7)
    np.random.seed(7)
    torch.manual_seed(7)
    torch.set_num_threads(2)
    device = torch.device("cuda" if torch.cuda.is_available() and not args.cpu else "cpu")
    print("device:", device)
    return device
```

### `data.py`

```python
import torch

def make_data(n, seed):
    generator = torch.Generator().manual_seed(seed)
    x = 0.12 * torch.randn(n, 1, 16, 16, generator=generator)
    y = torch.randint(0, 2, (n,), generator=generator)
    positions = torch.randint(3, 12, (n,), generator=generator)
    for i in range(n):
        p = positions[i].item()
        if y[i] == 0:
            x[i, 0, p:p + 2, 2:14] += 1
        else:
            x[i, 0, 2:14, p:p + 2] += 1
    return x, y
```

### `model.py`

```python
import torch
from torch import nn

class Block(nn.Module):
    def __init__(self, cin, cout, stride=1, residual=True):
        super().__init__()
        self.residual = residual
        self.branch = nn.Sequential(nn.Conv2d(cin, cout, 3, stride, 1, bias=False),
            nn.BatchNorm2d(cout), nn.ReLU(),
            nn.Conv2d(cout, cout, 3, padding=1, bias=False), nn.BatchNorm2d(cout))
        self.shortcut = nn.Conv2d(cin, cout, 1, stride, bias=False) if residual and (cin != cout or stride != 1) else nn.Identity()

    def forward(self, x):
        y = self.branch(x)
        if self.residual:
            y = y + self.shortcut(x)
        return torch.relu(y)

class SmallNet(nn.Module):
    def __init__(self, residual=True):
        super().__init__()
        self.layers = nn.Sequential(nn.Conv2d(1, 8, 3, padding=1), nn.ReLU(),
            Block(8, 8, residual=residual), Block(8, 16, 2, residual),
            Block(16, 16, residual=residual), nn.AdaptiveAvgPool2d(1),
            nn.Flatten(), nn.Linear(16, 2))

    def forward(self, x):
        return self.layers(x)
```

### `main.py`

```python
import json
import torch
from torch import nn
from runtime import setup, OUT
from data import make_data
from model import Block, SmallNet

def main():
    device = setup()
    dummy = torch.randn(2, 8, 16, 16, device=device, requires_grad=True)
    changed = Block(8, 16, 2).to(device)(dummy)
    changed.mean().backward()
    print("projection shape:", tuple(changed.shape), "input grad norm:", dummy.grad.norm().item())
    assert changed.shape == (2, 16, 8, 8)
    x, y = [t.to(device) for t in make_data(256, 7)]
    tx, ty = [t.to(device) for t in make_data(128, 8)]
    report = {}
    for residual in [False, True]:
        torch.manual_seed(10)
        model = SmallNet(residual).to(device)
        optimizer = torch.optim.Adam(model.parameters(), lr=0.005)
        for epoch in range(30):
            model.train()
            for ids in torch.randperm(len(x), device=device).split(64):
                optimizer.zero_grad()
                loss = nn.functional.cross_entropy(model(x[ids]), y[ids])
                loss.backward()
                optimizer.step()
        model.eval()
        with torch.no_grad():
            accuracy = (model(tx).argmax(1) == ty).float().mean().item()
        name = "residual" if residual else "plain"
        report[name] = {"test_accuracy": accuracy, "last_batch_loss": loss.item()}
        torch.save(model.state_dict(), OUT / (name + ".pt"))
    print(report)
    (OUT / "metrics.json").write_text(json.dumps(report, indent=2), encoding="utf-8")

if __name__ == "__main__":
    main()
```

## 结果与解释

投影块应输出 `(2, 16, 8, 8)`，输入梯度范数应为有限非零值。两个模型都应能训练完成，指标保存在 `metrics.json`。残差版本包含额外投影，两者参数量略有差异；单次训练排名不能证明残差连接的普遍优势。

## 小实验

- 增加同通道 Block 的数量，比较训练难度。
- 去掉投影并保留相加，理解形状错误的来源，再恢复正确实现。
- 将残差支路最后的归一化权重初始化为零，观察起始行为。
