# 损失函数
*损失函数*（Loss Function）是用来衡量模型预测值与真实值之间差异的函数。
训练模型时，需要把“预测得好不好”转化成可以计算和优化的目标。损失函数完成这一步：它根据模型预测与标签计算一个数值，又通过导数把误差信息送入反向传播。
1. 度量预测误差。 一组预测结果与标签之间可能存在许多差异。损失函数按照明确的规则，把这些差异汇总成一个标量，供训练过程使用。
2. 提供反向传播的起点。 网络输出变化时，损失怎样变化，由损失对输出的导数描述。沿着计算图继续求导，就能得到损失对各层参数的梯度。
3. 把任务转化为优化目标。 “预测房价准确”或“识别正确类别”需要进一步明确为数学目标。选择损失函数，也是在规定哪些错误受到怎样的惩罚。

用参数 $\theta$、模型输出 $f_\theta(x)$ 和标签 $y$ 表示，训练中的一条计算链是：
$$
\theta\longrightarrow f_\theta(x)
\longrightarrow L\big(f_\theta(x),y\big)
\longrightarrow\nabla_\theta L.
$$

损失函数决定评价与优化的目标，优化器根据梯度决定参数如何更新。即使使用同一种优化器，换一种损失，也可能改变模型学习的重点。
## 均方差损失
均方差损失（Mean Square Error, MSE）是早在统计学与回归分析中就已经广泛使用的一种衡量预测结果与实际情况之间差距的函数。
设第 $i$ 个预测为 $\hat y_i$，标签为 $y_i$，共有 $N$ 个待比较的标量。均方误差为：

$$
L_{\mathrm{MSE}}
=\frac1N\sum_{i=1}^{N}(\hat y_i-y_i)^2.
$$
令 $e_i=\hat y_i-y_i$，就能看出各步的作用：误差反映预测相对标签的偏移；平方把正负误差都变成非负贡献；平均使损失表达每个元素的平均平方偏差。
有些公式会再乘 $\dfrac12$。这个常数使求导时的系数 2 被抵消，最小值的位置保持不变；梯度的大小则随之改变，因此固定学习率下的更新幅度也会改变。
之所以会选择对误差求平方，一方面是因为这样可以消除符号，另一方面这样相比绝对值来说更便于求导，统计学中我们认识到了这样的好处，而在深度学习中这里的平方还意味着**模型对误差的反应要更加敏感**（平方比线性增长要快）。
MSE还带来了**梯度自适应机制**。因为$$\frac{ \partial  L_{\text{MSE}} }{ \partial  \hat{y}} =2(\hat{y}-y)$$因此误差绝对值越大，MSE 对预测值的导数绝对值越大，就越会加速滑向最优点；越接近标签，导数越小，在最优点附近就会慢下脚步。
MSE背后蕴含着一条概率假设，即：真实值等于“模型预测值加上高斯噪声”，小误差常见，大误差较少。
可以对连续标签建立以下模型：，误差在零两侧大致对称。更具体地，
$$
y_i=f_\theta(x_i)+\varepsilon_i,
\qquad\varepsilon_i\sim\mathcal N(0,\sigma^2).
$$
若各观测的噪声独立、方差相同且固定，负对数似然可写成：

$$
-\log p(\{y_i\}\mid\{x_i\},\theta)
=\mathrm{const}
+\frac{1}{2\sigma^2}\sum_i\big(y_i-f_\theta(x_i)\big)^2.
$$

在这些条件下，对$\theta$的[[参数估计#最大似然估计]]等价于最小化平方误差。这为 MSE 提供了概率建模依据。
但MSE也存在以下局限：
1. 对离群点过分敏感：平方放大是把双刃剑，它也会导致对于错误样本过度敏感，异常样本可能在平均损失和梯度中占据很大比重，使模型花费大量更新去追逐它。、
2. MSE假设目标连续可比：MSE默认”差2比差1严重4倍"。对房价、温度成立，对类别标签完全不成立——把猫预测成狗和把猫预测成飞机，从分类正误看是一样错的。
3. 配合Sigmoid会梯度消失：若输出层采用Sigmoid层$p=\sigma(z)$，$L_{\text{MSE}}=\dfrac{1}{2}(p-y)^2$。由链式法则：

$$
\frac{\partial L}{\partial z}
=\frac{\partial L}{\partial p}\frac{dp}{dz}
=(p-y)p(1-p).
$$

假设标签 $y=1$，模型却给出接近零的正类概率。此时误差 $p-y$ 接近 $-1$，但 Sigmoid 的导数 $p(1-p)$ 也接近零，最终传到 $z$ 的梯度反而很小。这就是因为Sigmoid函数的边缘太过平缓导致的梯度消失现象。
## 交叉熵损失
回归使用MSE，是因为它和"残差越小越好”完美对齐。换到分类，目标变成“模型给真实类别打的概率$p$有多高”。在挑公式之前，先列清楚这个损失应当满足哪些性质：
1. 使用类别概率作为评价依据，摆脱类别编号的数值距离。
2. 真实类别概率越高，损失越低。
3. 对真实类别给出极低概率时，施加显著惩罚。
4. 多个样本的贡献便于汇总，并与概率建模相联系。

这里有两个候选名额：$1-p$和$-\log p$。
对 $p\in(0,1]$，两个函数都随 $p$ 增大而减小，在 $p=1$ 时为零。它们的主要区别是低概率区间的惩罚尺度，当模型给真实结果分配接近于0的概率时，负对数会制造非常大的损失。
![[负对数惩罚.png]]
这就引出了信息论中的概念[[信息熵#交叉熵与相对熵]]：令 $P$ 表示目标分布，$Q$ 表示模型预测分布，交叉熵为：

$$
H(P,Q)=-\sum_xP(x)\log Q(x).
$$

它用目标分布 $P$ 作权重，计算模型分布 $Q$ 给真实结果分配的平均负对数概率。
Shannon辅助定理指出了，若要使预测分布$Q$与目标分布$P$一致，就应当使交叉熵最小。模型把目标支持的结果预测得越不可能，相应交叉熵就越大。
- 二分类的情况（BCE+Sigmoid）：二元交叉熵（BCE）为$$L_{\mathrm{BCE}}
=-\big[y\log p+(1-y)\log(1-p)\big].$$若以Sigmoid为输出$p=\sigma(z)$，则能得到$$\frac{\partial L_{\mathrm{BCE}}}{\partial z}=p-y.$$这与MSE殊途同归。
- 多分类的情况（CE+Softmax）：Softmax是Sigmoid函数在多分类情况下的变种，$$p_k=\frac{e^{z_k}}{\sum_{j=1}^{C}e^{z_j}}.$$可以得到梯度还是由相同的形式$$\frac{\partial L}{\partial z_k}=p_k-y_k.$$
可以通过此表对比三种损失函数：

| 损失函数          | 任务与组合  | 概率解释           | Pytorch接口              |
| ------------- | ------ | -------------- | ---------------------- |
| MSE           | 连续值回归  | 同方差高斯噪声下的负对数似然 | `nn.MSELoss`           |
| Sigmoid + BCE | 二分类    | 伯努利分布的负对数似然    | `nn.BCEWithLogitsLoss` |
| Softmax + CE  | 单标签多分类 | 类别分布的负对数似然     | `nn.CrossEntropyLoss`  |
# 梯度下降
损失函数提供了优化的标准，而梯度下降则是关于优化的方法。
损失函数把训练问题转换成了一个让损失函数最小化的问题。但面对包含大量参数、层层非线性组合的模型，通常很难通过一次求解直接得到合适的能使之最小化的参数。
因此，梯度下降提供了一条可执行的迭代路线：每一步利用当前位置的信息，让损失朝较低的方向变化。
梯度下降的过程可以被比喻为**蒙眼下山**，所在位置对应参数，海拔对应损失，脚下坡度对应梯度。每次走到新位置，都要重新判断坡度。训练开始时并不知道整个损失曲面的形状，因此通过许多次局部决策逐渐改善参数。
这个比喻引出了两个核心量：**梯度决定局部变化趋势，学习率调节沿这一趋势移动的尺度**。
在神经网络中，对每一层权重和偏置都能写出同样的更新。
例如第 $\ell$ 层需要有：
$$
W_{t+1}^{(\ell)}=W_t^{(\ell)}-\eta\frac{\partial L}{\partial W^{(\ell)}},
\qquad
b_{t+1}^{(\ell)}=b_t^{(\ell)}-\eta\frac{\partial L}{\partial b^{(\ell)}}.
$$
反向传播负责高效计算这些偏导数。
上面的公式看起来很简洁，但是在大规模训练时立刻复现出3个问题：
1. 用多少样本？一次更新要不要用全部样本。
2. 怎么走步？在窄长的山谷里反复横跳怎么办。
3. 学习率怎么设置？不同参数对学习率的敏感度差异巨大，需不需要自适应机制。

围绕这些问题，人们设计了不同的优化器。
## Batch-GD
1847年，Cauchy在研究彗星轨道时，提出人类历史上最早的梯度下降思想——面对六个未知数和一组高度非线性的方程，找不到解析解，只能沿着目标函数下降最快的方向一步步逼近。
设训练集有 $N$ 个样本，第 $i$ 个样本的损失为 $\ell_i(\theta)$。平均训练损失为：
$$
L(\theta)=\frac1N\sum_{i=1}^{N}\ell_i(\theta).
$$
每次更新都采用遍历全部$N$个样本计算梯度：
$$
\theta_{t+1}=\theta_t-\eta\frac1N\sum_{i=1}^{N}\nabla\ell_i(\theta_t).
$$
这就是*Batch-GD*（Batch-Gradient Descent，批次梯度下降）这里的"Batch”指的就是每次参数更新前都先把整个训练集完整遍历一遍。
这种方法的代价是：
- 一次更新必须等全部样本处理完，数据集越大，更新间隔和计算开销越显著。
- 优化器容易陷在鞍点、平坦区域与局部极小，无法达到全局最小值。
## SGD
*SGD*（Stochastic Gradient Descent，随机梯度下降）的方法则是随机取一个样本，立即更新。
取 $i_t$ 为随机样本下标：
$$
\theta_{t+1}=\theta_t-\eta\nabla\ell_{i_t}(\theta_t).
$$
在均匀采样下，固定当前参数，单样本梯度的期望等于训练集平均梯度：
$$
\mathbb E_{i_t}\big[\nabla\ell_{i_t}(\theta)\big]=\nabla L(\theta).
$$
这个补充关系说明了单样本更新的统计依据：某一步可能偏离平均方向，但它仍携带关于整体目标的信息。
优势：
- 计算成本骤降：每步从 O(N) 降到 O(1)，效率提升几个数量级。
- 跳出局部最优：单样本梯度天然带噪声，反而能帮模型跳出鞍点和浅层极小值。
- 支持在线学习：数据可一条条流入，边接收边更新。
代价：
- 剧烈震荡：单样本方差大，参数在最优点附近来回摆动，难以稳定收敛。
- 学习率需衰减：固定可能永远震荡；衰减过快又过早停在次优位置。
- 对离群样本敏感：一个异常样本就可能把参数拉向奇怪方向。
今天很少用纯单样本 SGD，但“用随机子样本近似全样本梯度”这一核心思想，已经是现代深度学习优化方法的基石。
## Mini-batch SGD
Mini-batch SGD（小批次随机梯度下降）是一种折中方案，每次取一小批样本然后平均。
取一个包含 $B$ 个样本的小批量 $\mathcal B_t$，计算：
$$
g_t=\frac1B\sum_{i\in\mathcal B_t}\nabla\ell_i(\theta_t),
\qquad
\theta_{t+1}=\theta_t-\eta g_t.
$$
这样把单样本的低成本与批量平均的稳定性结合起来。
小批量平均通常能削弱单样本的偶然影响，同时保留一定随机性；批量矩阵计算也能较好利用 G多PU。因此，实际训练中说到 SGD，常常包含使用 mini-batch 的情形。
大 batch 每步使用更多数据、占用更多显存；过小 batch 可能难以充分利用硬件。在固定遍历数据次数时，batch 变大还会减少参数更新次数，实际效果需要结合学习率、训练时长、模型和数据一起判断。

# 核心图景：把错误变成参数的调整方向

训练网络需要依次回答三个问题：预测偏差多大，哪些参数对偏差有影响，以及参数应该向什么方向改变。**损失函数定义目标，反向传播计算导数，优化器执行参数更新**。

一个网络可以同时包含很多层，却通常只有最终任务给出明确标签。反向传播的作用，就是沿中间计算关系，把最终误差对各参数的影响逐层算回来。

# 问题域与发展背景

单层感知机可以根据最终分错情况直接更新；隐藏层多起来后，“哪一个中间权重该为这次错误负责”就不能只靠输出标签直接回答。

把整个表达式逐项展开求导会重复计算很多公共部分，逐个参数扰动又要反复运行网络。反向模式自动微分通过保存中间量、复用局部导数，适合“参数很多、最终标量目标很少”的训练问题。1986年的[反向传播表示学习论文](https://www.cs.toronto.edu/~hinton/absps/naturebp.pdf)是这一路线的代表性工作。

它解决的是高效求梯度的问题。得到正确梯度之后，仍可能遇到学习率不合适、梯度消失、数据不足或过拟合，不能把所有训练困难都归入求导过程。

# 损失为什么要与输出含义对应

## 连续数值：平方误差与绝对误差

预测温度、长度等连续数时，平方误差$\ell=(\hat y-y)^2$会使大残差受到更重惩罚。绝对误差$|\hat y-y|$对大残差的增长较缓；Huber 在小误差附近用平方，大误差时接近线性。

公式是否带$1/2$、是否除以样本数，都会改变梯度的尺度。阅读推导时应先核对约定，不能只比较符号名称。

## 分类概率：交叉熵

二分类标签$y\in\{0,1\}$，正类概率为$p$，损失为

$$
\ell=-y\log p-(1-y)\log(1-p).
$$

若真实类别为1，模型给0.9的损失约0.105，给0.1的损失约2.303。它特别惩罚自信的错误。

多分类中，先给各类分数$z_k$，再通过 Softmax 得概率：

$$
p_k=\frac{e^{z_k}}{\sum_je^{z_j}},\quad
\ell=-\log p_{\mathrm{正确类}}.
$$

例如 logits 为$[2,1,0]$，概率约为$[0.665,0.245,0.090]$；若正确类是第一类，损失约0.408。logits 本身不是概率，可以为任意实数。

PyTorch 的 `BCEWithLogitsLoss` 与 `CrossEntropyLoss` 接收原始 logits，内部采用稳定的联合计算。先手工做 Sigmoid／Softmax 再传给这些函数，会改变预期接口。

# 链式法则怎样分配影响

先看只有一条样本的模型：

$$
z=wx+b,\quad L=\frac12(z-y)^2.
$$

计算顺序是“参数与输入 → 预测$z$ → 损失$L$”。反向时先问预测变化怎样影响损失：

$$
\frac{\partial L}{\partial z}=z-y.
$$

再问每个参数怎样影响预测。由于$\partial z/\partial w=x$、$\partial z/\partial b=1$，链式法则给出

$$
\frac{\partial L}{\partial w}=(z-y)x,\quad
\frac{\partial L}{\partial b}=z-y.
$$

可以把它读成：**某参数对最终目标的影响，等于它对中间量的影响，乘中间量对最终目标的影响**。

# 一次完整的手算更新

令$x=2,y=5,w=1,b=0$。

1. 前向得到$z=2$，残差为$-3$，损失为$\frac12\times9=4.5$。
2. 输出处导数为$-3$，对权重的导数为$-3\times2=-6$，对偏置为$-3$。
3. 用学习率0.1作梯度下降，得到$w'=1-0.1(-6)=1.6$、$b'=0.3$。
4. 新预测为$1.6\times2+0.3=3.5$，新损失为$\frac12(3.5-5)^2=1.125$。

负梯度在这里让权重增加，原因是当前预测低于目标。梯度的正负表达的是局部变化方向，不能简单理解成“正梯度好、负梯度坏”。

# 多加一层之后会发生什么

设$a=wx$，$h=\operatorname{ReLU}(a)$，$\hat y=vh$，仍采用半平方误差。当$a>0$时，ReLU 导数为1：

$$
\frac{\partial L}{\partial v}=(\hat y-y)h,\quad
\frac{\partial L}{\partial w}=(\hat y-y)v x.
$$

较早的权重$w$需要经过输出误差、后层权重$v$和输入$x$三个因素。更深网络只是增加了更多局部导数；如果某个中间量影响多个分支，各分支贡献需要相加。

例如同一个权重在多个 RNN 时间步反复使用，其最终梯度会累积这些使用位置的贡献。参数共享不会取消某些时间步的责任。

# 为什么反向计算更省

前向过程保存激活值等中间量。反向过程从标量损失开始，沿计算图反向访问节点，每个局部操作只需要知道“上游传来的导数”与“自身的局部导数”。这样多个参数可以共享已经算出的中间结果。

自动微分按实际执行的操作应用导数规则，既不同于先展开一个巨大符号表达式，也不同于把每个参数都微小扰动一次。反向传播属于反向模式自动微分在网络训练中的典型应用。

# 如何用有限差分检查梯度

对第$j$个参数，可以近似计算

$$
\frac{\partial L}{\partial\theta_j}\approx
\frac{L(\theta+\varepsilon e_j)-L(\theta-\varepsilon e_j)}{2\varepsilon}.
$$

$e_j$只在第$j$项为1。其他参数不变，分别算一次略增和略减后的损失。它适合小模型校验，不适合给大型模型逐参数训练：一次检查就需要很多前向运算。

$\varepsilon$过大会偏离局部导数，过小会出现浮点消减误差。检查时常用双精度，并避开 ReLU 零点等不可导位置。

| 清空梯度 | 准备独立的一次更新 | `.backward()`默认会累加梯度 |
| `.backward()` | 计算梯度 | 不直接改变参数值 |
| `.step()` | 优化器调整参数 | 调整方式可以是 SGD、Adam 等 |
| `eval()` | 切换 Dropout／BatchNorm 等层的行为 | 不等同于关闭自动微分 |
| `no_grad()` | 不建立反向求导图 | 不自动切换模型的训练／评价模式 |

下方例程把手算、自动微分和中央差分放在一起核对，适合检查这些概念是否真正连起来。

# 可复原例程

### `main.py`

```python
"""用手算、自动微分和有限差分核对同一模型的梯度。"""

# 标准库
import json

# 第三方库（由统一环境提供）
import torch

# 本项目模块
from runtime import setup, OUT


def objective(w, b):
    """给定标量 w、b，返回 0.5 * (2*w + b - 5)²。"""

    # x=2、y=5；只让 w、b 变化，定义半平方误差便于手算导数。
    return 0.5 * (2 * w + b - 5) ** 2


def main():
    """用手算、自动微分和有限差分核对同一模型的梯度。

    按分段注释依次准备数据、执行计算并保存结果。
    """

    # 1. 选择设备；所有梯度检查使用 float64，减小有限差分的舍入误差。
    device = setup()

    # 2. 将两个标量声明为需要梯度的叶子张量。
    w = torch.tensor(1.0, dtype=torch.float64, device=device, requires_grad=True)
    b = torch.tensor(0.0, dtype=torch.float64, device=device, requires_grad=True)

    # 前向计算 z=2w+b 与损失；backward 随后将导数写入 w.grad、b.grad。
    loss = objective(w, b)

    # 沿计算图计算参数梯度；此时参数数值尚未更新。
    loss.backward()

    # 3. 解析梯度应为 [-6, -3]，与下方自动微分结果按同一顺序比较。
    manual = torch.tensor([-6.0, -3.0], dtype=torch.float64, device=device)
    auto = torch.stack([w.grad, b.grad])

    # 4. 使用中央差分：分别扰动一个参数，其他参数保持原值。
    eps = 1e-5

    # 不记录这一段的求导图；适用于评价、参数初始化或手动更新。
    with torch.no_grad():
        # 两个差商分别近似对 w 和 b 的偏导；差分运算本身不建立求导图。
        finite = torch.stack(
            [
                (objective(w + eps, b) - objective(w - eps, b)) / (2 * eps),
                (objective(w, b + eps) - objective(w, b - eps)) / (2 * eps),
            ]
        )

        # 断言检查两种结果是否足够接近；梯度错误会在这里直接暴露。
        assert torch.allclose(auto, manual)

        # 断言检查两种结果是否足够接近；梯度错误会在这里直接暴露。
        assert torch.allclose(auto, finite, atol=1e-8)

        # 5. 手动执行学习率0.1的一步梯度下降，随后重新计算损失。
        old = loss.item()
        w -= 0.1 * w.grad
        b -= 0.1 * b.grad
        new = objective(w, b).item()

    # 6. 同时记录三种梯度与更新前后损失，便于逐项复算。
    report = {
        "manual": manual.cpu().tolist(),
        "autograd": auto.cpu().tolist(),
        "finite_difference": finite.cpu().tolist(),
        "old_loss": old,
        "new_loss": new,
        "new_w": w.item(),
        "new_b": b.item(),
    }
    print(report)
    (OUT / "gradients.json").write_text(json.dumps(report, indent=2), encoding="utf-8")


if __name__ == "__main__":
    main()
```
