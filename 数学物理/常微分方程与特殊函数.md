# 特殊函数从哪里来
数学物理中的特殊函数大多是某类二阶线性常微分方程的标准解。分离变量法把偏微分方程化成常微分方程后，坐标系、区域端点和边界条件共同决定应当使用哪一族函数。

理解特殊函数时，最值得关注的是：

- **方程的奇点和定义域**决定解在什么位置可能发散。
- **端点正则性**常常从两支解中筛掉一支。
- **参数取整数时级数截断**，会产生正交多项式。
- **边界条件**进一步把参数离散化成本征值。
- **权函数与正交性**决定怎样用这些函数展开一般函数。

局部级数的构造方法、Frobenius法以及本征函数正交性的来源见[[常微分方程的幂级数解]]。

# 函数族之间的关系
常见特殊函数可以粗略整理为以下几条支系：

- **Gauss超几何函数**${}_2F_1$是三个正则奇点问题的母函数。
  - 参数取负整数时得到Jacobi多项式。
  - Gegenbauer、Legendre和两类Chebyshev多项式都是Jacobi多项式的特例。
- **合流超几何函数**${}_1F_1$由Gauss超几何方程的两个奇点合并而来。
  - 参数取负整数时得到Laguerre多项式。
  - Hermite函数和抛物柱函数也可以用合流超几何函数表示。
- **Bessel函数族**对应圆柱和球坐标中的径向问题，包括普通、修正、球Bessel和Hankel函数。
- **Airy函数**描述经典转折点附近由振荡解过渡到指数解的过程。

这张族谱比孤立记忆每个函数的全部公式更有用：遇到新方程时，先通过变量代换和参数比较辨认它属于哪一支，再查该函数的局部性质。

# Legendre函数族
## Legendre与连带Legendre方程
连带Legendre方程为
$$\left(1-x^2\right)y''-2xy'+\left[l(l+1)-\frac{m^2}{1-x^2}\right]y=0$$
其两支标准解为$P_l^m(x)$和$Q_l^m(x)$。当$m=0$时退化为Legendre方程。

- 它主要来自球坐标系中的角向分离。
- 要求解在$x=\pm1$正则时，会筛选出第一类Legendre函数；$l$取非负整数时得到Legendre多项式。
- $m$控制方位角变化，$l$控制总的角向本征值$l(l+1)$。

具体的Rodrigues公式、递推关系、特殊点取值与正交性见[[Legendre函数]]，此处不再重复。

# Chebyshev与Gegenbauer函数族
## 第一类Chebyshev多项式
第一类Chebyshev方程为
$$\left(1-x^2\right)y''-xy'+n^2y=0$$
在$[-1,1]$上的多项式解为$T_n(x)$。令$x=\cos\theta$后，方程化为简谐方程，因此
$$\boxed{T_n(\cos\theta)=\cos(n\theta)}$$

- $T_n$在$[-1,1]$内等幅振荡，具有$n$个零点。
- 奇偶性为$T_n(-x)=(-1)^nT_n(x)$。
- 它关于权函数$(1-x^2)^{-1/2}$正交。
- 等幅振荡使Chebyshev节点适合多项式插值和数值逼近，可以减弱区间端点附近的剧烈振荡。

## 第二类Chebyshev多项式
第二类Chebyshev方程为
$$\left(1-x^2\right)y''-3xy'+n(n+2)y=0$$
相应多项式为$U_n(x)$，并有
$$\boxed{U_n(\cos\theta)=\frac{\sin[(n+1)\theta]}{\sin\theta}}$$

- $U_n$关于权函数$(1-x^2)^{1/2}$正交。
- 它与第一类多项式通过求导联系：
  $$\frac{\mathrm{d}T_n}{\mathrm{d}x}=nU_{n-1}(x)$$

## Gegenbauer多项式
Gegenbauer方程为
$$\left(1-x^2\right)y''-(2\alpha+1)xy'+n(n+2\alpha)y=0$$
其多项式解记为$C_n^{(\alpha)}(x)$。

- $alpha=1/2$时退化为Legendre多项式。
- $alpha=1$时有$C_n^{(1)}(x)=U_n(x)$。
- 对Chebyshev多项式反复求导会得到相应的Gegenbauer多项式，因此图中所谓连带Chebyshev函数可以放在这一族内理解。
- Gegenbauer多项式常出现在高维球面上的角向分离问题中。

# Hermite与Weber函数族
## Hermite多项式
Hermite方程写成
$$y''-2xy'+2ny=0$$
当$n=0,1,2,\ldots$时，一支级数截断为Hermite多项式
$$H_n(x)=n!\sum_{k=0}^{\lfloor n/2\rfloor}\frac{(-1)^k(2x)^{n-2k}}{k!(n-2k)!}$$

- $n$为偶数时$H_n$是偶函数，$n$为奇数时$H_n$是奇函数。
- 它关于Gaussian权函数$e^{-x^2}$在整个实轴上正交。
- 另一支线性无关解通常在无穷远发散，因此束缚态问题中会被舍去。
- 乘上Gaussian包络后得到Hermite–Gaussian函数，它们是量子谐振子和近轴光学中最常见的模态。

## Weber方程与抛物柱函数
Weber方程常写成
$$y''+\left(\nu+\frac{1}{2}-\frac{x^2}{4}\right)y=0$$
其标准解称为*抛物柱函数*，常记为$D_\nu(x)$。

- 方程同时含有二次势$x^2$和常数参数，描述抛物型势附近的波函数或扩散模态。
- 当$\nu=n$为非负整数时，抛物柱函数退化为Hermite–Gaussian函数：
  $$\boxed{D_n(x)=2^{-n/2}e^{-x^2/4}H_n\left(\frac{x}{\sqrt{2}}\right)}$$
- 图中的第一类、含参和第三类Weber方程可以通过缩放自变量、调整常数项化到这一标准形式。

# Bessel函数族
## 普通Bessel方程
$$x^2y''+xy'+\left(x^2-\nu^2\right)y=0$$
标准解为$J_\nu(x)$和$Y_\nu(x)$，Hankel函数$H_\nu^{(1)},H_\nu^{(2)}$是二者的复线性组合，用于表示圆柱形传入波和传出波。

## 修正Bessel方程
$$x^2y''+xy'-\left(x^2+\nu^2\right)y=0$$
标准解为$I_\nu(x)$和$K_\nu(x)$，分别表现为指数增长和指数衰减，常见于无振荡的径向边值问题。

## 球Bessel方程
$$x^2y''+2xy'+\left[x^2-l(l+1)\right]y=0$$
标准解为$j_l(x)$和$y_l(x)$。乘以$x$后可以化成Riccati–Bessel函数，从而消去球坐标径向方程中的一阶导数项。

普通、含参、修正、球Bessel与Riccati–Bessel方程之间都可以通过缩放自变量或乘幂代换联系起来。详细的级数、递推式、生成函数、渐近行为和正交性见[[Bassel函数|Bessel函数]]。

# Airy函数
Airy方程为
$$y''-xy=0$$
两支标准解记为$\operatorname{Ai}(x)$和$\operatorname{Bi}(x)$。

- 当$x>0$时，$\operatorname{Ai}(x)$指数衰减，$\operatorname{Bi}(x)$指数增长。
- 当$x<0$时，两者都呈振荡行为。
- 因此Airy函数自然描述从振荡区跨过$x=0$转入指数区的过程；在WKB近似中，$x=0$就是典型的经典转折点。
- 第一类Airy函数具有振荡积分表示
  $$\operatorname{Ai}(x)=\frac{1}{\pi}\int_0^\infty\cos\left(xt+\frac{t^3}{3}\right)\mathrm{d}t$$

# 合流超几何函数与Laguerre函数族
## Kummer合流超几何方程
Kummer方程为
$$xy''+(b-x)y'-ay=0$$
在$x=0$正则的标准解为
$$M(a,b,x)={}_1F_1(a;b;x)=\sum_{k=0}^{\infty}\frac{(a)_k}{(b)_k}\frac{x^k}{k!}$$
其中
$$\left(a\right)_k=\frac{\Gamma(a+k)}{\Gamma(a)}$$
称为Pochhammer符号。另一支常用标准解记为$U(a,b,x)$。

- 当$a=-n$且$n$为非负整数时，$(a)_k$在有限项后变为零，级数截断成$n$次多项式。
- $M$在原点正则；$U$通常更适合描述无穷远处的衰减行为。
- Laguerre函数、Hermite函数以及许多径向束缚态方程都可以化为Kummer方程。

## Laguerre多项式
Laguerre方程为
$$xy''+(1-x)y'+ny=0$$
其多项式解为
$$L_n(x)=\sum_{k=0}^n(-1)^k\binom{n}{k}\frac{x^k}{k!}$$
它与合流超几何函数的关系为
$$L_n(x)={}_1F_1(-n;1;x)$$

## 连带Laguerre多项式
连带Laguerre方程为
$$xy''+(\alpha+1-x)y'+ny=0$$
其多项式解记为$L_n^{(\alpha)}(x)$，并有Rodrigues公式
$$L_n^{(\alpha)}(x)=\frac{x^{-\alpha}e^x}{n!}\frac{\mathrm{d}^n}{\mathrm{d}x^n}\left(e^{-x}x^{n+\alpha}\right)$$

- 它关于权函数$x^\alpha e^{-x}$在$[0,\infty)$上正交。
- 普通Laguerre多项式对应$\alpha=0$。
- 它常出现在含指数衰减包络的径向束缚态问题中，例如氢原子和各向同性谐振子的径向方程。
- 一些旧文献把相关的广义Laguerre多项式称为Sonine多项式。

# Gauss超几何函数与Jacobi多项式
## Gauss超几何方程
Gauss超几何方程为
$$x(1-x)y''+[c-(a+b+1)x]y'-aby=0$$
在$x=0$正则的一支解为
$$\boxed{{}_2F_1(a,b;c;x)=\sum_{k=0}^{\infty}\frac{(a)_k(b)_k}{(c)_k}\frac{x^k}{k!}}$$

- 方程在$x=0,1,\infty$具有三个正则奇点。
- 当$a=-n$或$b=-n$时，级数在第$n$次后截断成多项式。
- 许多定义在有限区间上的正交多项式都来自这种截断。

## Jacobi多项式
Jacobi方程为
$$\left(1-x^2\right)y''+[\beta-\alpha-(\alpha+\beta+2)x]y'+n(n+\alpha+\beta+1)y=0$$
其多项式解记为$P_n^{(\alpha,\beta)}(x)$，并可写成
$$P_n^{(\alpha,\beta)}(x)=\frac{(\alpha+1)_n}{n!}{}_2F_1\left(-n,n+\alpha+\beta+1;\alpha+1;\frac{1-x}{2}\right)$$

- 它关于权函数$(1-x)^\alpha(1+x)^\beta$在$[-1,1]$上正交。
- $\alpha=\beta=0$时得到Legendre多项式。
- $\alpha=\beta=-1/2$时得到第一类Chebyshev多项式，只差归一化常数。
- $\alpha=\beta=1/2$时得到第二类Chebyshev多项式，只差归一化常数。
- $\alpha=\beta=\lambda-1/2$时得到Gegenbauer多项式，只差归一化常数。

# 怎样辨认一个特殊函数方程
遇到陌生的二阶常微分方程时，可以依次观察：

1. **定义域和奇点**：有限区间上的两个端点奇点常指向Jacobi、Legendre或Chebyshev；原点的径向奇点常指向Bessel或Laguerre。
2. **最高次势项**：线性势在转折点附近指向Airy，二次势指向Weber或Hermite。
3. **一阶导数系数**：通过乘积分因子或变量代换，把方程化到自伴形式，再与标准方程比较。
4. **无穷远行为**：先提取$e^{-x}$、$e^{-x^2/2}$或幂函数等主导包络，剩余部分往往满足Laguerre、Hermite或合流超几何方程。
5. **级数能否截断**：要求解在端点正则或无穷远可积时，参数常被迫取整数，从而产生正交多项式和离散本征值。
