# 方程与定解问题
## 从能量守恒导出热传导方程
设$u(\vec{r},t)$表示温度，$\vec{q}$表示热流密度。各向同性介质中的Fourier热传导定律为
$$\vec{q}=-\kappa\nabla u$$
其中$\kappa$为热导率。若介质的质量密度为$\rho$、比热容为$c$，单位体积、单位时间内的热源为$Q$，能量守恒给出
$$\rho c\frac{\partial u}{\partial t}=-\nabla\cdot\vec{q}+Q$$
因此非均匀各向同性介质中的一般形式为
$$\rho c\frac{\partial u}{\partial t}=\nabla\cdot\left(\kappa\nabla u\right)+Q$$
当$\rho,c,\kappa$均为常数时，得到
$$\boxed{\frac{\partial u}{\partial t}=D\nabla^2u+s(\vec{r},t)}$$
其中
$$D=\frac{\kappa}{\rho c},\quad s=\frac{Q}{\rho c}$$
$D$称为*热扩散率*，量纲为长度平方除以时间。无热源时方程为
$$\frac{\partial u}{\partial t}=D\nabla^2u$$
同一数学形式也描述物质扩散、动量扩散和[[静态电磁场#导体中的涡流和磁扩散|磁扩散]]，因此也称为扩散方程。

## 与位势方程的关系
达到稳态后有$\partial u/\partial t=0$，因此温度分布满足
$$\nabla^2u=-\frac{s}{D}=-\frac{Q}{\kappa}$$
这就是[[位势方程#Poisson方程|Poisson方程]]；无热源区域进一步退化为Laplace方程。热传导方程描述温度怎样趋向稳态，位势方程描述稳态温度最终满足的空间分布。

## 初始条件与边界条件
热传导方程关于时间是一阶方程，因此只需给定一个初始温度分布
$$u(\vec{r},0)=\varphi(\vec{r})$$
常见边界条件包括：

- **Dirichlet边界条件**：给定边界温度
  $$u|_{\partial\Omega}=g(\vec{r},t)$$
- **Neumann边界条件**：给定向外热流
  $$-\kappa\frac{\partial u}{\partial n}=q_n(\vec{r},t)$$
- **Robin边界条件**：边界通过对流与环境换热
  $$-\kappa\frac{\partial u}{\partial n}=h\left(u-u_\infty\right)$$

初始条件与边界条件还必须在$t=0$的边界处彼此相容。例如Dirichlet条件要求$\varphi|_{\partial\Omega}=g(\vec{r},0)$。

## 解的基本性质
- **扩散时间尺度**：温度变化传过尺度$L$所需的典型时间为
  $$\tau_D\sim\frac{L^2}{D}$$
- **平滑作用**：初始分布中的短波成分比长波成分衰减得更快，因此尖锐温度变化会逐渐变平滑。
- **最大值原理**：无热源时，内部不会凭空产生超过初始值和边界值的新极大值或新极小值。
- **不可逆性**：正向演化会抹去高频细节；由稍有误差的终态反推初态通常极不稳定。
- **经典模型的无限传播速度**：只要$t>0$，局域初始扰动对应的热核在任意有限距离处都非零。这个结论是Fourier热传导模型的理想化结果。

# 分离变量法
分离变量法适用于边界与正交坐标面吻合、材料参数不随空间变化的区域。对齐次方程令
$$u(\vec{r},t)=\Phi(\vec{r})T(t)$$
代入后得到
$$\frac{T'}{DT}=\frac{\nabla^2\Phi}{\Phi}=-\lambda$$
于是空间部分与时间部分分别满足
$$-\nabla^2\Phi=\lambda\Phi,\quad T'+D\lambda T=0$$
从而
$$\boxed{T(t)=T(0)e^{-D\lambda t}}$$
在通常的齐次Dirichlet、Neumann或Robin边界条件下，空间本征值$\lambda\geq0$。因此每个空间本征模态都对应一个时间因子$e^{-D\lambda t}$，空间变化越快、$\lambda$越大，衰减越快。

## 直角坐标系
### 齐次热传导方程
令
$$u(x,y,z,t)=X(x)Y(y)Z(z)T(t)$$

- **$x$分量$X(x)$**：满足
  $$X''+k_x^2X=0$$
  因而取$\sin(k_x x)$、$\cos(k_x x)$或$e^{\pm ik_x x}$。区间$0<x<L_x$上，两端齐次Dirichlet条件给出$k_x=n\pi/L_x$；两端齐次Neumann条件也给出$k_x=n\pi/L_x$，但允许$n=0$的常数模态。
- **$y$分量$Y(y)$**：满足$Y''+k_y^2Y=0$，函数形式及波数的离散化由$y$方向的边界条件确定。
- **$z$分量$Z(z)$**：满足$Z''+k_z^2Z=0$，函数形式及波数的离散化由$z$方向的边界条件确定。
- **空间本征值**：
  $$\boxed{\lambda=k_x^2+k_y^2+k_z^2}$$
- **时间分量$T(t)$**：
  $$\boxed{T(t)=e^{-D(k_x^2+k_y^2+k_z^2)t}}$$
  三个方向的空间波数共同决定该模态的衰减率。
- **一维有限杆的典型展开**：若$u(0,t)=u(L,t)=0$，则
  $$u(x,t)=\sum_{n=1}^{\infty}A_n\sin\left(\frac{n\pi x}{L}\right)e^{-D(n\pi/L)^2t}$$
  其中$A_n$由初始温度$\varphi(x)$的Fourier正弦级数确定。

## 柱坐标系
### 齐次热传导方程
令
$$u(r,\theta,z,t)=R(r)\Theta(\theta)Z(z)T(t)$$

- **角向分量$\Theta(\theta)$**：满足
  $$\Theta''+m^2\Theta=0$$
  因而取$\cos(m\theta)$、$\sin(m\theta)$或$e^{im\theta}$。绕轴一周后的单值性要求$m\in\mathbb{Z}$。
- **轴向分量$Z(z)$**：满足
  $$Z''+k_z^2Z=0$$
  因而取正弦、余弦或$e^{\pm ik_z z}$；$k_z$由轴向边界条件确定。
- **径向分量$R(r)$**：定义径向波数$k_r$后满足
  $$r^2R''+rR'+\left(k_r^2r^2-m^2\right)R=0$$
  因而由普通[[Bassel函数|Bessel函数]]$J_m(k_r r)$和$Y_m(k_r r)$组成。包含$r=0$的区域要求在轴上有限，通常只保留$J_m$。
- **径向波数的离散化**：若圆柱外壁$r=a$保持零温度，则
  $$J_m(k_r a)=0$$
  所以$k_r$等于$J_m$零点除以$a$；若外壁绝热，则条件改为$J_m'(k_r a)=0$。
- **空间本征值**：
  $$\boxed{\lambda=k_r^2+k_z^2}$$
  $m$是径向Bessel函数的阶数，但不会单独作为一个加法项出现在$\lambda$中；它通过径向边界条件影响允许的$k_r$。
- **时间分量$T(t)$**：
  $$\boxed{T(t)=e^{-D(k_r^2+k_z^2)t}}$$

## 球坐标系
### 齐次热传导方程
令
$$u(r,\theta,\varphi,t)=R(r)\Theta(\theta)\Phi(\varphi)T(t)$$

- **方位角分量$\Phi(\varphi)$**：满足
  $$\Phi''+m^2\Phi=0$$
  因而取$\cos(m\varphi)$、$\sin(m\varphi)$或$e^{im\varphi}$。
- **极角分量$\Theta(\theta)$**：满足连带Legendre方程，正则解为
  $$\Theta(\theta)=P_l^m(\cos\theta)$$
  方位角与极角合并为球谐函数$Y_l^m(\theta,\varphi)$。
- **角向参数的依赖关系**：要求解在完整球面上单值且正则时，
  $$\boxed{l=0,1,2,\ldots,\quad m=-l,-l+1,\ldots,l}$$
  $m$同时控制方位角函数和连带Legendre函数，$l$决定角向本征值$l(l+1)$以及径向函数的阶数。
- **径向分量$R(r)$**：满足
  $$r^2R''+2rR'+\left(k_r^2r^2-l(l+1)\right)R=0$$
  因而由球Bessel函数$j_l(k_r r)$和$y_l(k_r r)$组成。包含原点的区域通常只保留$j_l$。
- **径向波数的离散化**：若球面$r=a$保持零温度，则$j_l(k_r a)=0$；若球面绝热，则$j_l'(k_r a)=0$。
- **空间本征值**：
  $$\boxed{\lambda=k_r^2}$$
  $l,m$通过角向函数和径向边界条件影响允许的$k_r$。
- **时间分量$T(t)$**：
  $$\boxed{T(t)=e^{-Dk_r^2t}}$$

## 非齐次热源与非齐次边界
设空间本征函数满足
$$-\nabla^2\Phi_n=\lambda_n\Phi_n$$
把温度与热源展开为
$$u(\vec{r},t)=\sum_na_n(t)\Phi_n(\vec{r}),\quad s(\vec{r},t)=\sum_ns_n(t)\Phi_n(\vec{r})$$
则每个模态分别满足
$$a_n'(t)+D\lambda_na_n(t)=s_n(t)$$
其解为
$$a_n(t)=a_n(0)e^{-D\lambda_nt}+\int_0^te^{-D\lambda_n(t-\tau)}s_n(\tau)\,\mathrm{d}\tau$$

- **第一项**表示初始温度中第$n$个空间模态的自由衰减。
- **第二项**表示不同时刻产生的热量经过相应时间间隔后的剩余贡献。
- **非齐次边界**通常先写成$u=v+w$，选择$w$满足原来的非齐次边界条件，使$v$满足齐次边界条件，再对$v$作本征函数展开。
- **齐次Neumann边界的零模态**满足$\lambda_0=0$，其时间因子为常数。无热源时，这对应封闭绝热系统的平均温度保持不变。

# Green函数法
热传导方程的[[Green函数法|Green函数]]也称为*热核*。它表示在$t'$时刻、$\vec{r}'$处瞬时加入单位热量后，在以后时刻产生的温度响应。

## 全空间热核
定义因果Green函数
$$\left(\frac{\partial}{\partial t}-D\nabla^2\right)G(\vec{r},t;\vec{r}',t')=\delta^n(\vec{r}-\vec{r}')\delta(t-t')$$
并要求$t<t'$时$G=0$。$n$维全空间中的热核为
$$\boxed{G(\vec{r},t;\vec{r}',t')=\frac{H(t-t')}{[4\pi D(t-t')]^{n/2}}\exp\left[-\frac{|\vec{r}-\vec{r}'|^2}{4D(t-t')}\right]}$$
其中$H$为阶跃函数。对于初始条件$u(\vec{r},0)=\varphi(\vec{r})$和体热源$s$，解为
$$u(\vec{r},t)=\int_{\mathbb{R}^n}G(\vec{r},t;\vec{r}',0)\varphi(\vec{r}')\,\mathrm{d}^n\vec{r}'+\int_0^t\int_{\mathbb{R}^n}G(\vec{r},t;\vec{r}',\tau)s(\vec{r}',\tau)\,\mathrm{d}^n\vec{r}'\mathrm{d}\tau$$

- **归一化**：对$\vec{r}$积分有$\int G\,\mathrm{d}^n\vec{r}=1$，对应总热量守恒。
- **扩散宽度**：每个直角坐标分量的方差为$2D(t-t')$，因此扰动的典型扩散距离为$\sqrt{D(t-t')}$。
- **平滑作用**：热核是Gaussian函数，与初始分布卷积会快速压低高空间频率成分。

## 半空间与镜像热源
在半直线$x>0$上，记全空间一维热核为$G_0(x,t;x',0)$。

- **零温度边界$u(0,t)=0$**：取反号镜像，得到
  $$G_D(x,t;x',0)=G_0(x,t;x',0)-G_0(x,t;-x',0)$$
- **绝热边界$u_x(0,t)=0$**：取同号镜像，得到
  $$G_N(x,t;x',0)=G_0(x,t;x',0)+G_0(x,t;-x',0)$$

这种构造与[[静态电磁场#镜像法|静电镜像法]]具有相同的线性叠加结构，但热核还包含时间变量和因果条件。

## 半无限体的阶跃加热
设$x>0$区域初始温度为$u_0$，从$t=0$起表面$x=0$保持温度$u_s$，并要求$x\to\infty$时仍趋于$u_0$。解为
$$u(x,t)=u_0+(u_s-u_0)\operatorname{erfc}\left(\frac{x}{2\sqrt{Dt}}\right)$$
温度显著变化的深度随$\sqrt{Dt}$增长，体现了扩散过程的平方根时间尺度。

# Fourier变换法
[[Fourier变换]]法特别适合全空间、半空间以及具有平移对称性的区域。它把空间微分化为波数乘子，使不同空间频率彼此独立地衰减。

## 空间Fourier变换
采用
$$u(\vec{r},t)=\int\hat{u}(\vec{k},t)e^{-i\vec{k}\cdot\vec{r}}\frac{\mathrm{d}^n\vec{k}}{(2\pi)^n}$$
则
$$\mathcal{F}[\nabla^2u]=-|\vec{k}|^2\hat{u}$$
热传导方程变为
$$\frac{\partial\hat{u}}{\partial t}+D|\vec{k}|^2\hat{u}=\hat{s}(\vec{k},t)$$

- **无热源时**：
  $$\boxed{\hat{u}(\vec{k},t)=\hat{\varphi}(\vec{k})e^{-D|\vec{k}|^2t}}$$
- **有热源时**：
  $$\hat{u}(\vec{k},t)=\hat{\varphi}(\vec{k})e^{-D|\vec{k}|^2t}+\int_0^te^{-D|\vec{k}|^2(t-\tau)}\hat{s}(\vec{k},\tau)\,\mathrm{d}\tau$$
- **波数与衰减率的关系**：波数为$|\vec{k}|$的模态以$D|\vec{k}|^2$为衰减率。空间尺度越小，波数越大，衰减越快。
- **与热核的关系**：对$e^{-D|\vec{k}|^2t}$作空间逆Fourier变换便得到Gaussian热核，因此Fourier变换法与全空间Green函数法是同一解的频域表示和时空表示。

## 对时间作Fourier变换
采用时间因子$e^{i\omega t}$，令
$$u(\vec{r},t)=\int\tilde{u}(\vec{r},\omega)e^{i\omega t}\frac{\mathrm{d}\omega}{2\pi}$$
则每个频率分量满足
$$\left(\nabla^2-\gamma^2\right)\tilde{u}=-\frac{\tilde{s}}{D},\quad \gamma^2=\frac{i\omega}{D}$$
这是带有复参数的修正Helmholtz方程。取$\operatorname{Re}\gamma>0$的平方根可以保证温度振荡向介质内部衰减。

- **直角坐标分量**：在一维均匀介质中取$e^{-\gamma x}$作为向$x>0$内部衰减的解。
- **柱坐标径向分量**：对应复参数的修正Bessel函数$I_m(\gamma r)$、$K_m(\gamma r)$。
- **球坐标径向分量**：对应复参数的修正球Bessel函数。
- **参数依赖关系**：令
  $$\delta_T=\sqrt{\frac{2D}{\omega}},\quad \gamma=\frac{1+i}{\delta_T}$$
  则$\delta_T$称为热扩散深度。对于表面作简谐温度振荡的半无限体，温度振幅按$e^{-x/\delta_T}$衰减，相位滞后为$x/\delta_T$。

# 特征线法与热传导方程
一维齐次热传导方程写成
$$D u_{xx}-u_t=0$$
若把$x,t$共同视为二阶偏微分方程的自变量，其二阶主部只有$D u_{xx}$，判别式为零，因此属于抛物型。按照[[特征线法#特征线条件]]，特征条件为
$$D(\mathrm{d}t)^2=0$$
所以只有一族重合的特征曲线
$$t=\mathrm{Const}$$

这些曲线是等时面，不能像波动方程的两族实特征线那样把解化成沿传播轨迹的常微分方程。热传导方程中的二阶空间导数会持续耦合相邻位置，初始扰动通过热核向整个空间扩散，因此一般不采用行波法求解。

热传导方程虽然在二阶方程分类中以$t=\mathrm{Const}$为特征曲线，但它关于时间只有一阶。给定$t=0$时的温度$u(\vec{r},0)$后，方程直接由当时的空间曲率确定$u_t$，所以自然的初值问题仍然是适定的，不需要再给定$u_t(\vec{r},0)$。

# 方法选择
| 问题特征 | 常用方法 |
| --- | --- |
| 有限杆、矩形体、圆柱体、球体等规则区域 | 分离变量法与本征函数展开 |
| 瞬时点热源、分布初温或随时间变化的体热源 | Green函数法或Duhamel积分 |
| 全空间、半空间或具有平移对称性的区域 | 空间Fourier变换法 |
| 周期加热、简谐热源与热扩散深度 | 时间Fourier变换法 |
| 非齐次边界条件 | 先齐次化边界，再使用分离变量法或Green函数法 |
