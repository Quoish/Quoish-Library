# 核心图景：学得动与学得对是两件事

训练误差很高，可能说明模型尚未找到合适参数；训练误差很低、测试误差很高，则可能说明模型过度适应了训练样本。优化讨论怎样降低训练目标，泛化讨论这种改进是否能带到新数据上。

因此，优化器、正则化、归一化和评价划分需要放在同一条训练流程中理解，不能把某个单独技巧当作全部问题的解法。

# 问题域与技术发展

深层网络训练逐渐形成了几条相互配合的路线：

| 旧困难                  | 发展出的思路            | 代表性节点                                                                                                 |
| -------------------- | ----------------- | ----------------------------------------------------------------------------------------------------- |
| 全量数据每次更新太昂贵          | 随机／小批量梯度估计        | 随机优化传统                                                                                                |
| 梯度有噪声、方向反复摆动         | 累积历史方向，使用动量       | 动量优化方法                                                                                                |
| 各参数的梯度尺度不一致          | 按历史统计调整步长         | [Adam，2014预印本／2015会议论文](https://arxiv.org/abs/1412.6980)                                              |
| 大模型容易过拟合             | 约束参数、随机扰动、验证集选检查点 | [Dropout，2014](https://jmlr.org/papers/v15/srivastava14a.html)等                                       |
| 深层中信号尺度与优化不稳定        | 在适当维度归一化          | [BatchNorm，2015](https://arxiv.org/abs/1502.03167)、[LayerNorm，2016](https://arxiv.org/abs/1607.06450) |
| 自适应更新中的 L2 与权重衰减混在一起 | 将权重衰减独立处理         | [AdamW，2017预印本／2019会议论文](https://arxiv.org/abs/1711.05101)                                            |

这些工作有各自的实验条件与适用范围。年份表示代表性论文节点，不表示该方法从此替代其他所有方法。

# 梯度下降：沿局部下降方向迈一步

梯度$\nabla L(\theta)$汇集了损失对各参数的偏导，指出局部增长较快的方向。基本更新为

$$
\theta_{t+1}=\theta_t-\eta_t\nabla L(\theta_t).
$$

学习率$\eta_t$决定迈多远。用$L(\theta)=(\theta-3)^2$演示：从0出发，梯度为$-6$。学习率0.1得到新参数0.6，损失从9降为5.76；若学习率1.1，参数跳到6.6，损失反而增至12.96。

梯度只描述局部变化，所以步长太大可能跨过合适区域。调度器在训练不同阶段改变学习率；预热常让初期从较小步长开始，减少突然的大更新。

# 小批量为什么能减少计算

全批量梯度要遍历所有训练样本才能更新一次。小批量只抽取部分样本估计梯度，例如每次64条。若抽样方式合适，这个估计能提供有用方向，但会有随机波动。

一个 **step** 是一次参数更新，一个 **epoch** 是遍历训练集一轮。1024个样本、批量64时，一轮有16次更新。更大的批量不自动更好，还会改变内存、估计噪声和更新频率。

# 动量与 Adam 怎样利用历史

动量可以写为$v_t=\beta v_{t-1}+g_t$，再令$\theta\leftarrow\theta-\eta v_t$。持续一致的梯度方向会积累，来回变化的部分有机会相互抵消；仍需合适步长。

Adam 同时维护梯度的一阶矩和二阶矩的指数移动平均：

$$
m_t=\beta_1m_{t-1}+(1-\beta_1)g_t,\quad
v_t=\beta_2v_{t-1}+(1-\beta_2)g_t^2.
$$

这里平方按元素进行。$m_t$近似表示近期方向，$v_t$反映近期梯度幅度。因初值为0，早期估计偏小，所以除以相应的$1-\beta^t$作偏差修正：

$$
\hat m_t=\frac{m_t}{1-\beta_1^t},\quad
\hat v_t=\frac{v_t}{1-\beta_2^t},\quad
\theta_{t+1}=\theta_t-\eta\frac{\hat m_t}{\sqrt{\hat v_t}+\epsilon}.
$$

例如某个参数第一步梯度为2，取$\beta_1=0.9,\beta_2=0.999$，则$m_1=0.2,v_1=0.004$；修正后恢复为2与4。分母还加一个小量$\epsilon$来避免除零。Adam 是一种实用策略，不能据此推断它一定胜过精心配置的 SGD。

# 正则化怎样改变模型偏好

## L2 与 AdamW

若训练目标加入$\lambda\|\theta\|^2/2$，普通 SGD 的更新可以整理成

$$
\theta_{t+1}=(1-\eta\lambda)\theta_t-\eta\nabla L(\theta_t).
$$

它一边根据数据调整，一边收缩权重。在自适应优化器中，若把$\lambda\theta$直接混入梯度，还会影响动量和逐参数缩放，因此一般不再等价于简单收缩。AdamW 将衰减解耦，概念上保留“独立收缩＋自适应数据梯度更新”两部分。

## Dropout

训练时，Dropout 随机将部分激活置零。常见实现把保留值除以$1-p$，使期望尺度保持一致。例如丢弃概率0.25时，每个保留值放大为原来的$4/3$。

它使网络不能过度依赖某几个总是同时出现的激活；权重并未被永久删除。评价时关闭随机丢弃，使用完整网络。并非所有层和任务都适合采用相同丢弃强度。

## 数据增强与早停

数据增强通过合理变换增加训练变化，前提是变换没有破坏标签含义。早停或回选检查点则根据验证集决定何时保留参数。保存最佳状态需要复制权重快照，否则后续训练可能继续改写同一份张量。

# BatchNorm 与 LayerNorm 在哪里算统计量

归一化常先减均值、除标准差，再使用可训练的缩放与平移：

$$
\tilde x=\gamma\frac{x-\mu}{\sqrt{\sigma^2+\epsilon}}+\beta.
$$

如果一组值为$[1,3]$，均值2、总体方差1，忽略$\epsilon$且取$\gamma=1,\beta=0$，便得到$[-1,1]$。区别主要在于**对哪些轴计算均值与方差**。

| 方法 | 典型统计范围 | 评价行为 |
|---|---|---|
| CNN 中的 BatchNorm | 同一通道在批次及空间位置上的值 | 通常使用训练中积累的运行统计 |
| Transformer 中的 LayerNorm | 单个样本、单个位置的隐藏特征维 | 仍按当前位置的特征计算统计 |

BatchNorm 原论文以内部协变量偏移作为动机，但这并非其全部优化效果的最终解释。小批量、序列长度变化等条件，会影响具体方法的适用性。

# 初始化、梯度裁剪与学习曲线

初始化影响信号与梯度的初始尺度。梯度裁剪限制总范数，常用于缓解爆炸；已经消失的信号不会因此重新出现。混合精度可减少某些资源开销，但需要数值稳定措施，下方基础例程仍使用 float32。

| 观察 | 可能原因与下一步 |
|---|---|
| 训练、验证损失都较高 | 检查实现、容量、学习率和训练时间 |
| 训练下降，验证逐渐上升 | 考虑过拟合，回选检查点并检查正则化 |
| 两者都异常地好 | 除了模型有效，也要排查重复样本与泄漏 |
| 损失出现 NaN | 检查数据、学习率、除法／指数等数值操作 |

下方项目保持数据划分，比较三组配置并恢复各自最佳验证检查点。它展示如何读训练过程，不构成对所有任务的优化器排名。

```python
"""统一处理项目路径、随机种子、CPU线程与计算设备。"""

# 标准库
from pathlib import Path
import argparse
import random

# 第三方库（由统一环境提供）
import numpy as np
import torch

# 1. 路径统一从 runtime.py 所在目录出发，复制项目后无须改绝对路径。
ROOT = Path(__file__).resolve().parent

# outputs/ 存放本项目的图像、指标与模型权重；不存在时自动创建。
OUT = ROOT / "outputs"
OUT.mkdir(exist_ok=True)


def setup():
    """初始化运行环境并返回 torch.device。

    命令行参数只有 --cpu；ROOT、OUT 是导入时建立的项目路径。
    """

    # 2. 读取命令行选项：--cpu 允许在有显卡的机器上仍强制使用 CPU。
    parser = argparse.ArgumentParser()
    parser.add_argument("--cpu", action="store_true")
    args = parser.parse_args()

    # 3. 固定 Python、NumPy 和 PyTorch 的随机种子；跨设备仍不保证逐位相同。
    random.seed(7)
    np.random.seed(7)
    torch.manual_seed(7)

    # 小型教学网络限制 CPU 线程数，避免线程调度开销过大。
    torch.set_num_threads(2)

    # 4. 仅当 CUDA 可用且没有指定 --cpu 时使用 GPU；调用方负责移动模型和数据。
    device = torch.device(
        "cuda" if torch.cuda.is_available() and not args.cpu else "cpu"
    )
    print("device:", device)

    # 返回 torch.device；各入口脚本共用相同的设备选择规则。
    return device
```

### `model.py`

```python
"""创建用于正弦回归的 MLP，可选择是否启用 Dropout。"""

# 第三方库（由统一环境提供）
from torch import nn


def build(dropout=0.0):
    """返回一维回归网络；dropout 为隐藏层随机丢弃概率，取0表示关闭。"""

    # 输入和输出均为每样本1个实数；两个64维隐藏层提供非线性表达。
    # Dropout 仅在 train 模式随机丢弃激活，eval 模式关闭。
    return nn.Sequential(
        nn.Linear(1, 64),
        nn.Tanh(),
        nn.Dropout(dropout),
        nn.Linear(64, 64),
        nn.Tanh(),
        nn.Linear(64, 1),
    )
```

### `main.py`

```python
"""比较三种优化配置，并按验证损失恢复各自的最佳检查点。"""

# 标准库
import copy
import json

# 第三方库（由统一环境提供）
import torch
import matplotlib

# 采用不弹出窗口的绘图后端；必须在导入 pyplot 之前设置。
matplotlib.use("Agg")
import matplotlib.pyplot as plt

# 本项目模块
from model import build
from runtime import setup, OUT


def main():
    """比较三种优化配置，并按验证损失恢复各自的最佳检查点。

    按分段注释依次准备数据、执行计算并保存结果。
    """

    # 1. 初始化设备与随机状态，建立互不混用的训练／验证／测试数据。
    device = setup()

    def data(n):
        """返回 n 个带噪声正弦回归样本；输入、标签形状均为 (n, 1)。"""

        # 生成 [-3, 3] 上的 (n, 1) 输入，标签为 sin(2x) 加小幅高斯噪声。
        x = torch.rand(n, 1) * 6 - 3
        return x.to(device), (torch.sin(2 * x) + 0.15 * torch.randn(n, 1)).to(device)

    # 训练样本刻意较少，以便观察训练与验证误差的差距。
    train_x, train_y = data(32)
    val_x, val_y = data(160)
    test_x, test_y = data(160)

    # 2. 准备指标和学习曲线；每一种配置都重新建立网络。
    report = {}
    fig, ax = plt.subplots(figsize=(7, 4))

    # 3. 顺序训练 SGD、Adam、AdamW+Dropout 三个配置。
    for name in ["SGD", "Adam", "AdamW+Dropout"]:
        # 相同初始种子便于对照，但不同 Dropout 行为仍会消耗不同随机数。
        torch.manual_seed(10)
        model = build(0.15 if "Dropout" in name else 0).to(device)

        # 按配置选择优化器；AdamW 将权重衰减与梯度自适应缩放解耦。
        if name == "SGD":
            optimizer = torch.optim.SGD(model.parameters(), lr=0.03, momentum=0.9)
        elif name == "Adam":
            optimizer = torch.optim.Adam(model.parameters(), lr=0.01)
        else:
            optimizer = torch.optim.AdamW(
                model.parameters(), lr=0.01, weight_decay=0.01
            )

        # 4. 保存最佳验证损失及其参数快照；最终模型不直接取最后一轮。
        best_loss, best_step, best_state = float("inf"), 0, None
        train_curve, val_curve = [], []

        # 固定600次更新；本例回选最佳检查点，不提前终止循环。
        for step in range(600):
            # 训练模式启用 Dropout；损失仅使用训练数据。
            model.train()

            # 清除上一轮梯度；PyTorch 的 backward 默认会累加到 .grad。
            optimizer.zero_grad()

            # 构造当前批次的标量训练目标，反向传播将从这里开始。
            loss = (model(train_x) - train_y).square().mean()

            # 沿计算图计算参数梯度；此时参数数值尚未更新。
            loss.backward()

            # 优化器根据当前梯度真正更新可训练参数。
            optimizer.step()

            # 切换到评价模式；若含 Dropout／BatchNorm，其行为随之切换。
            model.eval()

            # 不记录这一段的求导图；适用于评价、参数初始化或手动更新。
            with torch.no_grad():
                # 评价态重新计算训练损失，使训练／验证曲线都不含 Dropout 的随机丢弃。
                train_value = (model(train_x) - train_y).square().mean().item()
                val_value = (model(val_x) - val_y).square().mean().item()
            train_curve.append(train_value)
            val_curve.append(val_value)

            # 仅根据验证集决定检查点，测试集不参与此选择。
            if val_value < best_loss:
                # 4. 保存最佳验证损失及其参数快照；最终模型不直接取最后一轮。
                best_loss, best_step = val_value, step

                # 深拷贝参数字典，防止后续训练把已保存的最佳参数一同改写。
                best_state = copy.deepcopy(model.state_dict())

        # 5. 恢复该配置的最佳检查点，然后才计算测试误差。
        model.load_state_dict(best_state)

        # 切换到评价模式；若含 Dropout／BatchNorm，其行为随之切换。
        model.eval()

        # 不记录这一段的求导图；适用于评价、参数初始化或手动更新。
        with torch.no_grad():
            test_mse = (model(test_x) - test_y).square().mean().item()
        report[name] = {
            "best_step": best_step,
            "validation_mse": best_loss,
            "test_mse": test_mse,
        }
        ax.plot(train_curve, linestyle="--", alpha=0.5, label=name + " train")
        ax.plot(val_curve, label=name + " validation")
        torch.save(best_state, OUT / (name.replace("+", "_") + ".pt"))

    # 6. 对数纵轴便于对照不同量级的 MSE；虚线表示训练、实线表示验证。
    ax.set(yscale="log", xlabel="step", ylabel="MSE")
    ax.legend(fontsize=7)

    # 自动调整子图间距，避免标题和坐标标签被裁切。
    fig.tight_layout()
    fig.savefig(OUT / "learning_curves.png", dpi=140)

    # 关闭已保存的图对象，避免反复运行时积累绘图资源。
    plt.close(fig)
    print(json.dumps(report, indent=2))
    (OUT / "metrics.json").write_text(json.dumps(report, indent=2), encoding="utf-8")


if __name__ == "__main__":
    main()
```
