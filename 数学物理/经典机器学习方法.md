# 为什么需要多种模型

表格数据中的任务可能只有几百个样本，却包含数值、类别、缺失值和复杂交互。深度网络并非每个任务的默认最优选择。比较简单基线与具有不同归纳偏好的模型，可以帮助判断数据需要何种表达能力。

# 基于邻近与概率的方法

## KNN

KNN 保存训练样本，对查询点寻找最近的$k$个邻居。分类采用投票，回归采用均值或距离加权均值。距离决定了“相似”的意义，故数值尺度、无关特征和高维距离集中现象都很重要。标准化参数应仅从训练数据计算，并同样应用于查询点。

## 朴素贝叶斯

贝叶斯公式给出$P(y\mid x)\propto P(y)P(x\mid y)$。朴素贝叶斯进一步假设各特征在给定类别后条件独立：

$$
\hat y=\mathop{\arg\max}_c\left[\log P(c)+\sum_j\log P(x_j\mid c)\right].
$$

GaussianNB 为每个类别的每个特征拟合高斯分布，MultinomialNB 常用于非负计数。独立性假设在实际中经常不严格成立，但模型仍可能提供有效基线。

# 最大间隔与核方法

对于$y_i\in\{-1,1\}$，软间隔线性支持向量机的常见目标为

$$
\min_{w,b}\frac12\|w\|^2+C\sum_i\max(0,1-y_i(w^Tx_i+b)).
$$

第一项倾向于更大间隔，第二项惩罚间隔内或分错的样本。$C$越大通常越强调训练误差。支持向量是决定边界的关键样本；核函数通过内积形式引入非线性特征空间。RBF核$K(x,z)=\exp(-\gamma\|x-z\|^2)$中的$\gamma$控制局部影响范围。核 SVM 在大样本上可能有较高训练与存储成本。

# 树与集成

决策树递归选择特征阈值，将空间划分为区域。分类常用 Gini 不纯度$G=1-\sum_kp_k^2$或信息熵；分裂使子节点加权不纯度降低。树能处理非线性和特征交互，深树也容易拟合噪声。

随机森林使用自助采样训练多棵树，并在分裂时随机选择候选特征，通过投票或平均降低方差。增加树数通常改善稳定性，但无法消除数据偏差。

梯度提升按顺序增加弱学习器：

$$
F_m(x)=F_{m-1}(x)+\eta h_m(x).
$$

$h_m$拟合当前损失对预测的负梯度。平方损失下，该目标与残差成比例；其他损失下不能一概视为直接拟合标签残差。学习率、树深和迭代轮数共同影响拟合程度。

# 选择与解释

| 方法 | 主要特点 | 需留意 |
|---|---|---|
| KNN | 局部相似性，无显式参数拟合 | 缩放、高维、查询成本 |
| 朴素贝叶斯 | 概率建模，训练简单 | 条件独立与分布假设 |
| SVM | 间隔与核方法 | 缩放、核参数、样本规模 |
| 决策树 | 分段规则，易表达交互 | 深度、方差、规则稳定性 |
| 随机森林 | 多树平均，适合非线性基线 | 模型体积、外推能力 |
| 梯度提升 | 顺序改进，常用于表格任务 | 学习率、早停、调参 |

特征重要性依赖模型与评价方式；相关特征可能互相替代。树的重要性不能直接解释因果贡献。公平比较应使用相同数据划分、适合各模型的预处理和相同测试指标。

### `main.py`

```python
from pathlib import Path
import json
import numpy as np
import matplotlib
matplotlib.use("Agg")
import matplotlib.pyplot as plt
from sklearn.datasets import make_moons
from sklearn.model_selection import train_test_split
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.neighbors import KNeighborsClassifier
from sklearn.naive_bayes import GaussianNB
from sklearn.svm import SVC
from sklearn.tree import DecisionTreeClassifier
from sklearn.ensemble import RandomForestClassifier, GradientBoostingClassifier
from sklearn.metrics import accuracy_score

def main():
    out = Path(__file__).resolve().parent / "outputs"
    out.mkdir(exist_ok=True)
    x, y = make_moons(600, noise=0.23, random_state=7)
    a, b, c, d = train_test_split(x, y, test_size=0.3, stratify=y, random_state=7)
    models = {"KNN": make_pipeline(StandardScaler(), KNeighborsClassifier(9)),
        "Naive Bayes": GaussianNB(),
        "RBF SVM": make_pipeline(StandardScaler(), SVC(C=3, gamma="scale")),
        "Tree": DecisionTreeClassifier(max_depth=5, random_state=7),
        "Forest": RandomForestClassifier(n_estimators=80, max_depth=6, random_state=7),
        "Boosting": GradientBoostingClassifier(n_estimators=80, max_depth=2, random_state=7)}
    gx, gy = np.meshgrid(np.linspace(-1.6, 2.6, 150), np.linspace(-1.1, 1.7, 150))
    grid = np.c_[gx.ravel(), gy.ravel()]
    fig, axes = plt.subplots(2, 3, figsize=(10, 6))
    scores = {}
    for ax, (name, model) in zip(axes.ravel(), models.items()):
        model.fit(a, c)
        scores[name] = accuracy_score(d, model.predict(b))
        ax.contourf(gx, gy, model.predict(grid).reshape(gx.shape), alpha=0.3)
        ax.scatter(b[:, 0], b[:, 1], c=d, s=8)
        ax.set_title(f"{name}: {scores[name]:.3f}")
    fig.tight_layout()
    fig.savefig(out / "boundaries.png", dpi=140)
    plt.close(fig)
    print(json.dumps(scores, indent=2))
    (out / "metrics.json").write_text(json.dumps(scores, indent=2), encoding="utf-8")

if __name__ == "__main__":
    main()
```

## 结果与解释

双月数据需要非线性边界。GaussianNB 的分布假设较强，树的区域呈阶梯状，RBF SVM 的边界通常更平滑。观察图形比仅比较几个百分点更能揭示模型差异；数据量和噪声改变后，排序也可能改变。
