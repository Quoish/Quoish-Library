# 核心图景：用不同方式定义“怎样作出判断”

同一批样本可以产生不同的模型。KNN 根据附近样本投票，朴素贝叶斯比较各类别生成这些特征的可能性，SVM 寻找留出较大间隔的边界，决策树按问题逐层分组，集成方法再组合多个模型。

它们之间的差别，首先来自对数据结构的假设。理解这些假设，比只记算法名称更有助于判断适用的问题域。

# 问题域与发展脉络

早期及经典统计学习长期面对几类任务：带噪声的表格预测、模式分类、文档识别和有限样本下的可靠估计。不同路线分别处理局部相似性、概率估计、复杂边界和模型不稳定等困难。

| 路线 | 旧困难 | 代表性改动 |
|---|---|---|
| 邻近方法 | 不容易预先写出统一的函数形式 | 将训练样本本身作为局部参照 |
| 朴素贝叶斯 | 高维联合概率很难直接估计 | 引入给定类别后的条件独立假设 |
| 支持向量机 | 只分对训练点，可能仍缺少稳健边界 | 用间隔与复杂度约束组织分类目标 |
| 决策树 | 线性边界难表达条件分支和特征交互 | 递归切分特征空间 |
| 随机森林 | 单棵深树对训练样本变化敏感 | 多树随机化并平均 |
| 梯度提升 | 一个弱模型仍残留系统性错误 | 逐步加入针对当前不足的新模型 |

可核对的历史节点包括1995年的[Cortes–Vapnik 支持向量网络](https://link.springer.com/article/10.1007/BF00994018)，以及2001年的[Breiman 随机森林](https://link.springer.com/article/10.1023/A:1010933404324)。它们属于相互关联而长期并存的研究路线，不能据年份直接给任务中的效果排序。

# KNN：把判断交给附近的已知样本

假设一张二维散点图上，蓝点与红点各代表一类。新点到来后，KNN 找出距离最近的$k$个已知点，让它们投票。例如最近3点的标签为蓝、蓝、红，就预测为蓝。

训练阶段主要保留数据，预测阶段才执行查找。这使局部弯曲边界比较容易表达，也把计算成本转移到查询阶段。

$k$很小，边界容易跟随噪声；$k$很大，局部细节可能被多数类覆盖。回归时可以把投票换成邻居目标值的均值或距离加权平均。

距离还需要有意义。若一个特征变化几十，另一个变化几万，欧氏距离很容易被后者主导。因此缩放应仅从训练集拟合，并用同一规则处理查询点。高维空间中，距离可能越来越难区分，很多无关特征也会干扰邻居判断。

# 朴素贝叶斯：哪一类更容易出现这些特征

贝叶斯分类从两个因素出发：类别本来有多常见，以及该类别下当前特征有多常见。以垃圾邮件为例，若先验垃圾比例为0.2，“中奖”出现于垃圾邮件的概率为0.8，出现于正常邮件的概率为0.05，则观察到该词后：

$$
P(\mathrm{垃圾}\mid\mathrm{中奖})
=\frac{0.2\times0.8}{0.2\times0.8+0.8\times0.05}=0.8.
$$

特征一多，直接估计$P(x_1,\ldots,x_d\mid y)$需要很多组合数据。朴素贝叶斯假设：**在给定类别后，各特征条件独立**，从而用各项概率相乘近似联合概率。

$$
\hat y=\mathop{\arg\max}_c
\left[\log P(c)+\sum_j\log P(x_j\mid c)\right].
$$

取对数将许多小概率的乘积变为求和，减轻数值下溢。这里的独立性有“给定类别”这一前提，并不声称所有原始特征在总体上互不相关。

GaussianNB 对连续特征拟合类别内高斯分布；MultinomialNB 常用于非负词计数。模型训练简单，但分布假设和条件独立近似都可能不符合实际数据。

# SVM：除了分对，还要求离边界留出空间

二维中有很多条直线都能分开同一批点。一条几乎擦过样本的线，可能对小扰动很敏感。SVM 引入间隔，倾向于让关键训练点与边界保持较大的几何距离。

将标签写为$y_i\in\{-1,+1\}$，常见软间隔目标为

$$
\min_{w,b}\frac12\|w\|^2
+C\sum_i\max(0,1-y_i(w^Tx_i+b)).
$$

第二项称 hinge 损失。正类样本的分数为0.4时，已经判为正类，但损失仍有0.6；分数为2时，满足间隔要求，损失为0。第一项约束权重，在这一缩放约定下对应扩大间隔。$C$控制对违反间隔的惩罚。

核方法用$K(x,z)$替代某个特征空间中的内积，从而获得非线性边界。RBF核

$$
K(x,z)=\exp(-\gamma\|x-z\|^2)
$$

让附近点的相似性较高。$\gamma$越大，单个点的影响通常越局部。核参数、尺度和样本数都会影响训练成本与泛化。

# 决策树：逐次问问题，把空间切成小区域

一棵树可能先问“面积是否大于80”，再对某一分支问“房龄是否小于10”。沿分支走到叶子后，输出类别分布或回归均值。由此可以表达条件依赖与特征交互。

分类分裂常使子节点更加“纯”。Gini 不纯度为

$$
G=1-\sum_kp_k^2.
$$

一组样本有6个A、4个B，不纯度为$1-0.6^2-0.4^2=0.48$。若切出4个纯A，其余为2个A和4个B，分裂后加权不纯度约为$0.4\times0+0.6\times4/9=0.267$，比原来更低。

若不断细分，树甚至可以给每条训练样本单独建立叶子。这会减少训练误差，却使规则对噪声敏感，所以需要控制深度、最小叶子样本数或剪枝。

# 集成：如何弥补单个模型的不足

## 随机森林侧重让多个不同的树共同判断

不同自助采样数据训练多棵树，分裂时再随机限制候选特征。最后对分类投票、对回归平均。若多棵树犯错的方式不完全一致，平均可以降低某些随机波动。

“更多树”与“每棵树更深”不是同一个参数。增加树数通常改善平均的稳定性，却不能修正错误标签或系统性的分布偏差。

## 梯度提升侧重逐步修补当前预测

模型按顺序累加：

$$
F_m(x)=F_{m-1}(x)+\eta h_m(x).
$$

新模型$h_m$拟合当前损失对预测的负梯度。平方损失时，它与残差成比例。例如真实值13、当前预测10，残差为3；若新模型给出3、学习率0.1，则新预测为10.3。

其他损失对应的负梯度未必等于标签减预测。树深、学习率和迭代轮数需要一起考虑；持续叠加模型也可能过拟合。

# 一次比较应观察什么

下方例程让六个模型共用双月数据。双月的弯曲结构会暴露线性或分布假设的局限，决策区域图还能显示局部投票、核边界和树切分的区别。

比较时保持相同划分与评价指标，但允许模型使用适合自身的预处理。不能因某个固定配置在一个小数据集上获胜，就推断它适合所有表格或视觉任务。有关优化、模型选择和泄漏的进一步讨论见[[神经网络优化与泛化]]。

# 可复原例程

在同一个非线性二分类数据集上比较六种算法，保存各自的测试准确率和决策区域图。固定配置用于机制比较，不作为完整调参竞赛。

### `main.py`

```python
"""在同一双月数据上比较六类分类器，观察准确率与决策区域。"""

# 标准库
from pathlib import Path
import json

# 第三方库（由统一环境提供）
import numpy as np
import matplotlib

# 采用不弹出窗口的绘图后端；必须在导入 pyplot 之前设置。
matplotlib.use("Agg")
import matplotlib.pyplot as plt
from sklearn.datasets import make_moons
from sklearn.model_selection import train_test_split
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.neighbors import KNeighborsClassifier
from sklearn.naive_bayes import GaussianNB
from sklearn.svm import SVC
from sklearn.tree import DecisionTreeClassifier
from sklearn.ensemble import RandomForestClassifier, GradientBoostingClassifier
from sklearn.metrics import accuracy_score


def main():
    """在同一双月数据上比较六类分类器，观察准确率与决策区域。

    按分段注释依次准备数据、执行计算并保存结果。
    """

    # 1. 建立输出目录，避免将结果散落到不同工作目录。
    out = Path(__file__).resolve().parent / "outputs"
    out.mkdir(exist_ok=True)

    # 2. 生成600个二维双月样本；noise 控制两类交叠和分类难度。
    x, y = make_moons(600, noise=0.23, random_state=7)

    # 按类别分层划分数据，所有模型共用同一训练集和测试集。
    train_x, test_x, train_y, test_y = train_test_split(
        x, y, test_size=0.3, stratify=y, random_state=7
    )

    # 3. 定义六个对照模型；KNN、SVM 依赖距离尺度，因此使用标准化流水线。
    # 树模型不需要同样的缩放；固定深度、树数和随机种子，便于比较机制。
    models = {
        "KNN": make_pipeline(StandardScaler(), KNeighborsClassifier(9)),
        "Naive Bayes": GaussianNB(),
        "RBF SVM": make_pipeline(StandardScaler(), SVC(C=3, gamma="scale")),
        "Tree": DecisionTreeClassifier(max_depth=5, random_state=7),
        "Forest": RandomForestClassifier(n_estimators=80, max_depth=6, random_state=7),
        "Boosting": GradientBoostingClassifier(
            n_estimators=80, max_depth=2, random_state=7
        ),
    }

    # 4. 建立覆盖整个二维平面的150×150网格，用来显示各模型的预测区域。
    gx, gy = np.meshgrid(np.linspace(-1.6, 2.6, 150), np.linspace(-1.1, 1.7, 150))

    # 将网格摊为 (22500, 2) 后批量预测，画图时再恢复为150×150。
    grid = np.c_[gx.ravel(), gy.ravel()]

    # 六个模型各占一幅子图，散点颜色显示真实类别。
    fig, axes = plt.subplots(2, 3, figsize=(10, 6))
    scores = {}

    # 5. 逐个模型训练和评价；测试样本不会参与 fit。
    for ax, (name, model) in zip(axes.ravel(), models.items()):
        # 在共同训练集上拟合当前模型。
        model.fit(train_x, train_y)

        # 保存真实测试准确率，而非绘图网格上的预测比例。
        scores[name] = accuracy_score(test_y, model.predict(test_x))

        # 背景区域是模型在网格上的离散类别预测，可直接比较边界形状。
        ax.contourf(gx, gy, model.predict(grid).reshape(gx.shape), alpha=0.3)
        ax.scatter(test_x[:, 0], test_x[:, 1], c=test_y, s=8)
        ax.set_title(f"{name}: {scores[name]:.3f}")

    # 自动调整子图间距，避免标题和坐标标签被裁切。
    fig.tight_layout()
    fig.savefig(out / "boundaries.png", dpi=140)

    # 关闭已保存的图对象，避免反复运行时积累绘图资源。
    plt.close(fig)

    # 6. 将六个测试分数写入 JSON，与决策边界图一起保留。
    print(json.dumps(scores, indent=2))
    (out / "metrics.json").write_text(json.dumps(scores, indent=2), encoding="utf-8")


if __name__ == "__main__":
    main()
```

## 结果与解释

双月数据需要非线性边界。GaussianNB 的分布假设较强，树的区域呈阶梯状，RBF SVM 的边界通常更平滑。观察图形比仅比较几个百分点更能揭示模型差异；数据量和噪声改变后，排序也可能改变。
