# 激活函数在神经网络中的用处
*激活函数*（Activation function）是在神经网络和机器学习领域指用于引入非线性、决定神经元是否被“激活”的函数。
在[[人工神经网络#人工神经元]]中我们已经介绍过神经网络的结构，每一个人工神经元经过一次线性变换之后，都需要加上一个激活函数，才能在运算中提供非线性的成分。
如果没有激活函数，那线性运算无论叠上多少层，那都还是线性运算，叠得再多也只能成为一个线性的感知机。加入激活函数以后，我们才可以拟合世界中种种非线性的现象。
但为什么常用的神经网络采取的都是“线性运算”与“非线性激活”的结构？为什么不直接使用非线性的运算？这里主要有两点原因：
1. 线性运算有成熟的硬件架构，可以通过GPU加速实现，有着巨大的成本优势。
2. 非线性的叠加会给数值控制、梯度计算造成很大的困难。例如$x^2$将复合10次，就会得到$x^{1024}$，这会给模型带来极大的不稳定性。

什么样的激活函数是一个好的激活函数？它需要尽量满足以下几个方面：
1. 非线性。这是最基本的要求，否则深度毫无意义。
2. 几乎处处可导。因为反向传播中涉及其导数的运算。可以部分区域不可导，只需补充定义。
3. 梯度行为良好。不消失也不爆炸，最好接近于1。
4. 计算简答。因为训练中会调用上亿次。
5. 输出尽量既有正号也有负号。可以避免梯度恒为同号，给正负方向都留下余地。
6. 单调/平滑/有界。这些是加分项。

# 常见激活函数
## 阶跃函数
科学家最早选择的是阶跃函数$$H(x)=\begin{cases}
1,&x\geq0,\\
0,&x<0.
\end{cases}$$它在零点不可导，不过零点处的导数常被定义为零。
它适合表达阈值判断，但把不同大小的正输入都映射为 1、负输入都映射为 0，丢失了幅度信息。
但阶跃函数存在的问题是：
1. 梯度无法传递。导数恒为0，不能通过链式法则传递。
2. 信息失真严重。网络丧失了对“程度”的感知，变得很二极管，丢弃了大量信息。

## Sigmoid函数
1986年辛顿等人把反向传播带回神经网络，它需要个处处可导的激活函数——他们沿用了19世纪就用来描述人口增长的老朋友：$$\sigma(x)=\frac{1}{1+e^{ -x }}$$
Sigmoid函数的优势：
1. 函数可导，方便梯度训练；
2. 输出形式适合二分类概率建模；
3. 开关具有平滑过渡，不会在阈值处突然跳变。

Sigmoid存在的问题：
1. 梯度消失：Sigmoid导数的最大值也就只有$x=0$处的0.25，假如叠了五层之后很容易就变成$(0.25)^5\approx 0.001$变得特别小，链式法则的某一项变成了0，这就会让梯度消失。
2. 输出恒为正：这导致在计算反向传播的时候梯度会恒为同号，这就失去了下降灵活性。
3. 计算麻烦：因为用到了指数运算。
4. 压缩结果：对于比较大的$x$，Sigmoid的指数衰减会把$x$压缩到很小，代价就是饱和。

所以Sigmoid如今已很少使用在隐藏层，而更多是在二分类问题中使用在输出层。
## 双曲正切函数
90 年代初，杨立昆在贝尔实验室研究手写数字识别，被Sigmoid的非零中心训练震荡困扰，于是在1998年他提出了使用双曲正切函数$$\tanh(x)=\frac{e^x-e^{-x}}{e^x+e^{-x}}$$
- 双曲正切的导数最大值为1，梯度衰减更慢。
- 输出有正有负，收敛会更快。

但依然会出现饱和问题，计算也比较复杂。
