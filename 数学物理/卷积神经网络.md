# 为什么图像适合局部结构

图像中的边缘、纹理等局部模式可能出现在不同位置。全连接层对每个像素分别学习连接，既消耗参数，也没有显式利用空间邻接关系。CNN 使用局部连接和参数共享，让同一组可学习权重在不同位置执行同样的运算。

# 从一个卷积核到特征图

深度学习库中的“卷积”通常实现不翻转核的互相关。对二维单通道输入，忽略边界条件时：

$$
Y_{i,j}=b+\sum_{u=0}^{K_h-1}\sum_{v=0}^{K_w-1}W_{u,v}X_{i+u,j+v}.
$$

对输入$\begin{bmatrix}1&2&3\\4&5&6\\7&8&9\end{bmatrix}$和核$\begin{bmatrix}1&0\\0&-1\end{bmatrix}$，步长1、无填充时，四个输出都为$-4$。这个核比较相邻对角位置，负值也包含信息；特征图数值不能一概解释为概率或“越大越像”。

多通道卷积对所有输入通道求和。若输入通道数$C_{in}$、输出通道数$C_{out}$，普通卷积参数量为

$$
C_{out}(C_{in}K_hK_w+1).
$$

每个输出通道对应一组跨越全部输入通道的核，加上一个偏置。输入通道的 RGB 含义经过多层卷积后通常不再保留为简单颜色通道。

# 尺寸、步长与感受野

对单个空间维度，核大小$K$、填充$P$、步长$S$、膨胀率$D$时：

$$
H_{out}=\left\lfloor\frac{H+2P-D(K-1)-1}{S}+1\right\rfloor.
$$

步长2通常减小空间尺寸；填充用于控制边界与尺寸；膨胀卷积在不直接增加核参数的情况下扩大覆盖范围。感受野描述输出单元可能依赖的输入区域，多层堆叠会使其扩大，但有效利用范围还受参数与训练影响。

常见 PyTorch 图像张量顺序为$(B,C,H,W)$。例如32张灰度16×16图像的输入为$(32,1,16,16)$，经过8个3×3核、填充1后为$(32,8,16,16)$。

# 池化、非线性与全局汇聚

卷积后加入非线性，使网络能够组合复杂特征。最大池化保留窗口内最大响应，平均池化作局部平均；普通池化没有可训练参数。全局平均池化将每个通道压成一个数，再由线性层分类，能避免巨大展平层。

参数共享在合适边界与步长条件下提供平移等变性：输入移动，特征响应也相应移动。池化或全局汇聚可能增强对小位移的稳定性，但无法保证旋转、缩放或任意平移不变。现代 CNN 也不要求每层后都接池化。

# 适用范围

CNN 适用于具有局部结构的数据，包括图像、音频和一维信号。它依赖对局部性与共享规律的假设；需要长距离交互时，可以通过深层、大核、膨胀卷积或注意力扩展。高训练准确率仍可能来自背景或数据泄漏，需要独立评价。

### `runtime.py`

```python
"""统一处理项目路径、随机种子、CPU线程与计算设备。"""

# 标准库
from pathlib import Path
import argparse
import random

# 第三方库（由统一环境提供）
import numpy as np
import torch

# 1. 路径统一从 runtime.py 所在目录出发，复制项目后无须改绝对路径。
ROOT = Path(__file__).resolve().parent

# outputs/ 存放本项目的图像、指标与模型权重；不存在时自动创建。
OUT = ROOT / "outputs"
OUT.mkdir(exist_ok=True)


def setup():
    """初始化运行环境并返回 torch.device。

    命令行参数只有 --cpu；ROOT、OUT 是导入时建立的项目路径。
    """

    # 2. 读取命令行选项：--cpu 允许在有显卡的机器上仍强制使用 CPU。
    parser = argparse.ArgumentParser()
    parser.add_argument("--cpu", action="store_true")
    args = parser.parse_args()

    # 3. 固定 Python、NumPy 和 PyTorch 的随机种子；跨设备仍不保证逐位相同。
    random.seed(7)
    np.random.seed(7)
    torch.manual_seed(7)

    # 小型教学网络限制 CPU 线程数，避免线程调度开销过大。
    torch.set_num_threads(2)

    # 4. 仅当 CUDA 可用且没有指定 --cpu 时使用 GPU；调用方负责移动模型和数据。
    device = torch.device(
        "cuda" if torch.cuda.is_available() and not args.cpu else "cpu"
    )
    print("device:", device)

    # 返回 torch.device；各入口脚本共用相同的设备选择规则。
    return device
```

### `data.py`

```python
"""生成带噪声与位置变化的横条／竖条二分类图像。"""

# 第三方库（由统一环境提供）
import torch


def make_data(n, seed):
    """生成 n 张16×16灰度图像。

    返回 x: (n, 1, 16, 16)，y: (n,)；seed 控制噪声、标签与条纹位置。
    """

    # 1. 使用局部随机生成器；改变数据集种子不会改动模型初始化的全局随机状态。
    generator = torch.Generator().manual_seed(seed)

    # 先生成 (n, 1, 16, 16) 的灰度噪声背景；维度顺序为样本、通道、高、宽。
    x = 0.12 * torch.randn(n, 1, 16, 16, generator=generator)

    # 2. 标签0表示横条，1表示竖条；每个样本另取一个条纹位置。
    y = torch.randint(0, 2, (n,), generator=generator)
    positions = torch.randint(3, 12, (n,), generator=generator)

    # 3. 在各自的背景上叠加2像素宽条纹，位置变化让模型不能只记固定坐标。
    for i in range(n):
        p = positions[i].item()

        # 横条固定行范围、跨越多列；竖条固定列范围、跨越多行。
        if y[i] == 0:
            x[i, 0, p : p + 2, 2:14] += 1
        else:
            x[i, 0, 2:14, p : p + 2] += 1

    # 返回图像 x 与整数标签 y；此处在 CPU 生成，入口脚本再统一移动到目标设备。
    return x, y
```

### `model.py`

```python
"""定义两个卷积层、全局汇聚与分类头组成的微型 CNN。"""

# 第三方库（由统一环境提供）
from torch import nn


class CNN(nn.Module):
    """定义两个卷积层、全局汇聚与分类头组成的微型 CNN。"""

    def __init__(self):
        """创建模型组件并登记参数；本方法只定义结构，不执行训练。"""

        super().__init__()

        # 1. 特征提取：1通道变8通道，空间尺寸16×16保持；再变16通道并下采样到8×8。
        # ReLU 引入非线性；全局平均池化把每个通道压成一个数。
        self.features = nn.Sequential(
            nn.Conv2d(1, 8, 3, padding=1),
            nn.ReLU(),
            nn.Conv2d(8, 16, 3, stride=2, padding=1),
            nn.ReLU(),
            nn.AdaptiveAvgPool2d(1),
        )

        # 2. 将16个通道的汇聚结果映射为2个类别分数，保留原始 logits。
        self.classifier = nn.Linear(16, 2)

    def forward(self, x):
        """接收一批图像，返回 (B, 2) 的 logits，供交叉熵或 argmax 使用。"""

        # features: (B, 1, 16, 16) → (B, 16, 1, 1)；flatten(1) → (B, 16)；分类头 → (B, 2)。
        return self.classifier(self.features(x).flatten(1))
```

### `main.py`

```python
"""核对一个可手算的卷积，再训练 CNN 并画出测试样本。"""

# 标准库
import json

# 第三方库（由统一环境提供）
import torch
from torch import nn
import matplotlib

# 采用不弹出窗口的绘图后端；必须在导入 pyplot 之前设置。
matplotlib.use("Agg")
import matplotlib.pyplot as plt

# 本项目模块
from runtime import setup, OUT
from data import make_data
from model import CNN


def main():
    """核对一个可手算的卷积，再训练 CNN 并画出测试样本。

    按分段注释依次准备数据、执行计算并保存结果。
    """

    # 1. 初始化运行环境，后续模型与训练张量使用同一设备。
    device = setup()

    # 2. 先独立核对卷积：输入为1～9组成的3×3矩阵，批次和通道数都为1。
    matrix = torch.arange(1.0, 10.0).reshape(1, 1, 3, 3)

    # 核比较窗口左上角与右下角；步长1且无填充，输出为2×2。
    kernel = torch.tensor([[[[1.0, 0.0], [0.0, -1.0]]]])
    result = torch.nn.functional.conv2d(matrix, kernel)
    print("manual convolution:", result.flatten().tolist())

    # 四个结果都应为 -4，用断言对应正文中的手算例子。
    assert torch.equal(result, torch.full_like(result, -4))

    # 3. 用不同种子生成训练与测试数据，避免直接评价训练图片。
    x, y = make_data(384, 7)
    test_x, test_y = make_data(128, 8)

    # 模型和数据必须位于同一设备；这里按原顺序一次性移动四个张量。
    x, y, test_x, test_y = [t.to(device) for t in (x, y, test_x, test_y)]

    # 4. 建立 CNN 和 Adam 优化器；随机初始参数随后通过训练调整。
    model = CNN().to(device)
    optimizer = torch.optim.Adam(model.parameters(), lr=0.01)

    # 5. 完成45轮训练，每轮随机打乱样本并按96张图像组成小批量。
    for epoch in range(45):
        # 启用训练行为；虽然本模型没有 Dropout，保留显式模式切换便于扩展。
        model.train()
        for ids in torch.randperm(len(x), device=device).split(96):
            # 清除上一轮梯度；PyTorch 的 backward 默认会累加到 .grad。
            optimizer.zero_grad()

            # 交叉熵接收 (批量, 2) logits 与整数标签，不应先对模型输出做 Softmax。
            loss = nn.functional.cross_entropy(model(x[ids]), y[ids])

            # 沿计算图计算参数梯度；此时参数数值尚未更新。
            loss.backward()

            # 优化器根据当前梯度真正更新可训练参数。
            optimizer.step()

    # 切换到评价模式；若含 Dropout／BatchNorm，其行为随之切换。
    model.eval()

    # 不记录这一段的求导图；适用于评价、参数初始化或手动更新。
    with torch.no_grad():
        # 6. 在独立测试集上取最大 logit 对应的类别；此阶段不更新模型。
        predicted = model(test_x).argmax(1)
        accuracy = (predicted == test_y).float().mean().item()

    # 7. 保存测试准确率、输出尺寸和模型参数，供结果核对与后续加载。
    report = {
        "test_accuracy": accuracy,
        "logits_shape": list(model(test_x[:4]).shape),
    }
    print(report)
    (OUT / "metrics.json").write_text(json.dumps(report, indent=2), encoding="utf-8")
    torch.save(model.state_dict(), OUT / "cnn.pt")

    # 8. 画出8张测试图片，将真实标签和预测标签放在标题中。
    fig, axes = plt.subplots(2, 4, figsize=(8, 4))
    for i, ax in enumerate(axes.ravel()):
        # 绘图前仅把对应样本移回 CPU；训练时的设备选择不受影响。
        ax.imshow(test_x[i, 0].cpu(), cmap="gray")
        ax.set_title(f"true={test_y[i].item()}, pred={predicted[i].item()}")
        ax.axis("off")

    # 自动调整子图间距，避免标题和坐标标签被裁切。
    fig.tight_layout()
    fig.savefig(OUT / "examples.png", dpi=140)

    # 关闭已保存的图对象，避免反复运行时积累绘图资源。
    plt.close(fig)


if __name__ == "__main__":
    main()
```

## 结果与解释

卷积核算例必须输出四个 `-4.0`。分类器对4张图片输出 `(4, 2)` 的 logits，测试集通常能获得很高准确率。测试使用独立随机种子生成新图片；它只衡量相同合成机制中的位置与噪声变化，不能代表真实视觉能力。
