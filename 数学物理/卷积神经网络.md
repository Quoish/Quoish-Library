# 为什么图像适合局部结构

图像中的边缘、纹理等局部模式可能出现在不同位置。全连接层对每个像素分别学习连接，既消耗参数，也没有显式利用空间邻接关系。CNN 使用局部连接和参数共享，让同一组可学习权重在不同位置执行同样的运算。

# 从一个卷积核到特征图

深度学习库中的“卷积”通常实现不翻转核的互相关。对二维单通道输入，忽略边界条件时：

$$
Y_{i,j}=b+\sum_{u=0}^{K_h-1}\sum_{v=0}^{K_w-1}W_{u,v}X_{i+u,j+v}.
$$

对输入$\begin{bmatrix}1&2&3\\4&5&6\\7&8&9\end{bmatrix}$和核$\begin{bmatrix}1&0\\0&-1\end{bmatrix}$，步长1、无填充时，四个输出都为$-4$。这个核比较相邻对角位置，负值也包含信息；特征图数值不能一概解释为概率或“越大越像”。

多通道卷积对所有输入通道求和。若输入通道数$C_{in}$、输出通道数$C_{out}$，普通卷积参数量为

$$
C_{out}(C_{in}K_hK_w+1).
$$

每个输出通道对应一组跨越全部输入通道的核，加上一个偏置。输入通道的 RGB 含义经过多层卷积后通常不再保留为简单颜色通道。

# 尺寸、步长与感受野

对单个空间维度，核大小$K$、填充$P$、步长$S$、膨胀率$D$时：

$$
H_{out}=\left\lfloor\frac{H+2P-D(K-1)-1}{S}+1\right\rfloor.
$$

步长2通常减小空间尺寸；填充用于控制边界与尺寸；膨胀卷积在不直接增加核参数的情况下扩大覆盖范围。感受野描述输出单元可能依赖的输入区域，多层堆叠会使其扩大，但有效利用范围还受参数与训练影响。

常见 PyTorch 图像张量顺序为$(B,C,H,W)$。例如32张灰度16×16图像的输入为$(32,1,16,16)$，经过8个3×3核、填充1后为$(32,8,16,16)$。

# 池化、非线性与全局汇聚

卷积后加入非线性，使网络能够组合复杂特征。最大池化保留窗口内最大响应，平均池化作局部平均；普通池化没有可训练参数。全局平均池化将每个通道压成一个数，再由线性层分类，能避免巨大展平层。

参数共享在合适边界与步长条件下提供平移等变性：输入移动，特征响应也相应移动。池化或全局汇聚可能增强对小位移的稳定性，但无法保证旋转、缩放或任意平移不变。现代 CNN 也不要求每层后都接池化。

# 适用范围

CNN 适用于具有局部结构的数据，包括图像、音频和一维信号。它依赖对局部性与共享规律的假设；需要长距离交互时，可以通过深层、大核、膨胀卷积或注意力扩展。高训练准确率仍可能来自背景或数据泄漏，需要独立评价。

### `runtime.py`

```python
from pathlib import Path
import argparse
import random
import numpy as np
import torch

ROOT = Path(__file__).resolve().parent
OUT = ROOT / "outputs"
OUT.mkdir(exist_ok=True)

def setup():
    parser = argparse.ArgumentParser()
    parser.add_argument("--cpu", action="store_true")
    args = parser.parse_args()
    random.seed(7)
    np.random.seed(7)
    torch.manual_seed(7)
    torch.set_num_threads(2)
    device = torch.device("cuda" if torch.cuda.is_available() and not args.cpu else "cpu")
    print("device:", device)
    return device
```

### `data.py`

```python
import torch

def make_data(n, seed):
    generator = torch.Generator().manual_seed(seed)
    x = 0.12 * torch.randn(n, 1, 16, 16, generator=generator)
    y = torch.randint(0, 2, (n,), generator=generator)
    positions = torch.randint(3, 12, (n,), generator=generator)
    for i in range(n):
        p = positions[i].item()
        if y[i] == 0:
            x[i, 0, p:p + 2, 2:14] += 1
        else:
            x[i, 0, 2:14, p:p + 2] += 1
    return x, y
```

### `model.py`

```python
from torch import nn

class CNN(nn.Module):
    def __init__(self):
        super().__init__()
        self.features = nn.Sequential(nn.Conv2d(1, 8, 3, padding=1), nn.ReLU(),
            nn.Conv2d(8, 16, 3, stride=2, padding=1), nn.ReLU(),
            nn.AdaptiveAvgPool2d(1))
        self.classifier = nn.Linear(16, 2)

    def forward(self, x):
        return self.classifier(self.features(x).flatten(1))
```

### `main.py`

```python
import json
import torch
from torch import nn
import matplotlib
matplotlib.use("Agg")
import matplotlib.pyplot as plt
from runtime import setup, OUT
from data import make_data
from model import CNN

def main():
    device = setup()
    matrix = torch.arange(1., 10.).reshape(1, 1, 3, 3)
    kernel = torch.tensor([[[[1., 0.], [0., -1.]]]])
    result = torch.nn.functional.conv2d(matrix, kernel)
    print("manual convolution:", result.flatten().tolist())
    assert torch.equal(result, torch.full_like(result, -4))
    x, y = make_data(384, 7)
    test_x, test_y = make_data(128, 8)
    x, y, test_x, test_y = [t.to(device) for t in (x, y, test_x, test_y)]
    model = CNN().to(device)
    optimizer = torch.optim.Adam(model.parameters(), lr=0.01)
    for epoch in range(45):
        model.train()
        for ids in torch.randperm(len(x), device=device).split(96):
            optimizer.zero_grad()
            loss = nn.functional.cross_entropy(model(x[ids]), y[ids])
            loss.backward()
            optimizer.step()
    model.eval()
    with torch.no_grad():
        predicted = model(test_x).argmax(1)
        accuracy = (predicted == test_y).float().mean().item()
    report = {"test_accuracy": accuracy, "logits_shape": list(model(test_x[:4]).shape)}
    print(report)
    (OUT / "metrics.json").write_text(json.dumps(report, indent=2), encoding="utf-8")
    torch.save(model.state_dict(), OUT / "cnn.pt")
    fig, axes = plt.subplots(2, 4, figsize=(8, 4))
    for i, ax in enumerate(axes.ravel()):
        ax.imshow(test_x[i, 0].cpu(), cmap="gray")
        ax.set_title(f"true={test_y[i].item()}, pred={predicted[i].item()}")
        ax.axis("off")
    fig.tight_layout()
    fig.savefig(OUT / "examples.png", dpi=140)
    plt.close(fig)

if __name__ == "__main__":
    main()
```
