# 从容易定义的噪声过程开始

生成复杂数据分布很困难，但可以把真实样本逐步加噪，使它接近简单高斯分布，再训练模型反向去噪。DDPM 将这种想法写成一串概率转移。训练时可以直接抽取任意噪声强度，不必真的逐步模拟全部前向过程。

# 前向加噪

设原样本$x_0$，每一步噪声比例为$\beta_t$，定义$\alpha_t=1-\beta_t$、$\bar\alpha_t=\prod_{s=1}^t\alpha_s$。前向转移为

$$
q(x_t\mid x_{t-1})=\mathcal N(\sqrt{\alpha_t}x_{t-1},\beta_tI).
$$

由于高斯的组合性质，可以直接采样：

$$
x_t=\sqrt{\bar\alpha_t}x_0+\sqrt{1-\bar\alpha_t}\epsilon,\quad
\epsilon\sim\mathcal N(0,I).
$$

例如$\bar\alpha_t=0.25$时，信号系数为0.5，噪声系数为$\sqrt{0.75}$。模型必须接收时间$t$，因为相同观测在不同噪声强度下需要不同的去噪判断。

# 训练去预测噪声

常见简化目标为

$$
L_{simple}=\mathbb E_{x_0,t,\epsilon}\|\epsilon-\epsilon_\theta(x_t,t)\|^2.
$$

训练流程是随机取真实样本、随机取时间、生成噪声与$x_t$，再让网络预测所加噪声。预测噪声、原始样本或其他速度参数化之间可以转换，但目标权重与数值特性不同。噪声预测与得分函数存在联系，不能简单理解为保存每个训练样本的反向噪声记录。

# 反向采样

从$x_T\sim\mathcal N(0,I)$出发，使用预测均值

$$
\mu_\theta(x_t,t)=\frac1{\sqrt{\alpha_t}}
\left(x_t-\frac{\beta_t}{\sqrt{1-\bar\alpha_t}}\epsilon_\theta(x_t,t)\right).
$$

本例采用固定后验方差

$$
\tilde\beta_t=\beta_t\frac{1-\bar\alpha_{t-1}}{1-\bar\alpha_t},\quad
x_{t-1}=\mu_\theta(x_t,t)+\sqrt{\tilde\beta_t}z.
$$

最后一步不再加随机噪声。代码索引从0开始，因此公式中的第1步对应代码`t=0`，其前一累计信号系数按1处理。

# 条件生成与图像模型

条件扩散还向网络提供类别、文字或其他条件。文本生成图像常结合文本编码器、交叉注意力、U-Net 或扩散 Transformer。潜空间扩散先用自编码器压缩图像，再在潜空间执行扩散；完整系统远多于一个去噪网络。

Classifier-free guidance 组合有条件与无条件预测，提高条件遵循程度，但引导强度过大可能损害多样性或产生伪影。采样器、步数和噪声调度共同影响质量与成本。

# 评价与局限

单个噪声预测损失无法完整评价生成质量。需要观察生成分布、模式覆盖与独立评价指标。终端分布是否充分接近高斯也依赖噪声调度。下面使用二维点，便于观察完整采样链；它不具备文本生成图像的能力。

# 可复原例程

在二维八簇数据上训练100步 DDPM，保存加噪过程和从高斯噪声开始的反向采样图。所有公式在代码中直接实现，不依赖 diffusers。

### `runtime.py`

```python
from pathlib import Path
import argparse
import random
import numpy as np
import torch

ROOT = Path(__file__).resolve().parent
OUT = ROOT / "outputs"
OUT.mkdir(exist_ok=True)

def setup():
    parser = argparse.ArgumentParser()
    parser.add_argument("--cpu", action="store_true")
    args = parser.parse_args()
    random.seed(7)
    np.random.seed(7)
    torch.manual_seed(7)
    torch.set_num_threads(2)
    device = torch.device("cuda" if torch.cuda.is_available() and not args.cpu else "cpu")
    print("device:", device)
    return device
```

### `data.py`

```python
import math
import torch

def sample_data(n, device):
    group = torch.randint(0, 8, (n,), device=device)
    angle = group.float() * (2 * math.pi / 8)
    centers = 2 * torch.stack([angle.cos(), angle.sin()], dim=1)
    return centers + 0.12 * torch.randn(n, 2, device=device)
```

### `model.py`

```python
import torch
from torch import nn

class NoisePredictor(nn.Module):
    def __init__(self, steps):
        super().__init__()
        self.time = nn.Embedding(steps, 16)
        self.net = nn.Sequential(nn.Linear(18, 96), nn.SiLU(),
            nn.Linear(96, 96), nn.SiLU(), nn.Linear(96, 2))

    def forward(self, x, t):
        return self.net(torch.cat([x, self.time(t)], dim=1))
```

### `main.py`

```python
import json
import torch
import matplotlib
matplotlib.use("Agg")
import matplotlib.pyplot as plt
from model import NoisePredictor
from data import sample_data
from runtime import setup, OUT

def main():
    device = setup()
    steps = 100
    beta = torch.linspace(0.0001, 0.12, steps, device=device)
    alpha = 1-beta
    cumulative = alpha.cumprod(0)
    previous = torch.cat([torch.ones(1, device=device), cumulative[:-1]])
    posterior_variance = beta * (1-previous) / (1-cumulative)
    model = NoisePredictor(steps).to(device)
    optimizer = torch.optim.Adam(model.parameters(), lr=0.002)
    history = []
    for iteration in range(6000):
        x0 = sample_data(256, device)
        t = torch.randint(0, steps, (len(x0),), device=device)
        noise = torch.randn_like(x0)
        signal = cumulative[t, None]
        xt = signal.sqrt()*x0 + (1-signal).sqrt()*noise
        loss = (model(xt, t)-noise).square().mean()
        optimizer.zero_grad()
        loss.backward()
        optimizer.step()
        history.append(loss.item())
    model.eval()
    with torch.no_grad():
        x = torch.randn(1500, 2, device=device)
        snapshots = [x.clone()]
        for index in reversed(range(steps)):
            t = torch.full((len(x),), index, dtype=torch.long, device=device)
            mean = (x-beta[index]/(1-cumulative[index]).sqrt()*model(x, t))/alpha[index].sqrt()
            x = mean + posterior_variance[index].sqrt()*torch.randn_like(x) if index > 0 else mean
            if index in [49, 0]:
                snapshots.append(x.clone())
        truth = sample_data(1500, device)
    fig, axes = plt.subplots(1, 4, figsize=(12, 3))
    for ax, point, title in zip(axes, [truth]+snapshots, ["Data", "Initial noise", "Halfway", "Generated"]):
        point = point.cpu().numpy()
        ax.scatter(point[:, 0], point[:, 1], s=2, alpha=0.35)
        ax.set(xlim=(-3, 3), ylim=(-3, 3), title=title, aspect="equal")
    fig.tight_layout()
    fig.savefig(OUT / "diffusion.png", dpi=140)
    plt.close(fig)
    report = {"initial_loss_mean": sum(history[:100])/100,
              "final_loss_mean": sum(history[-100:])/100,
              "terminal_signal_fraction": cumulative[-1].item(),
              "finite_samples": bool(torch.isfinite(x).all().item())}
    print(report)
    (OUT / "metrics.json").write_text(json.dumps(report, indent=2), encoding="utf-8")
    torch.save(model.state_dict(), OUT / "noise_predictor.pt")

if __name__ == "__main__":
    main()
```

## 结果与解释

检查所有生成点是否有限、最后100步平均损失是否低于开始100步，以及采样是否逐渐形成多簇结构。图中“Halfway”表示反向采样的中间状态；若生成簇不够清晰，需要增加训练或改进调度，不能通过只展示训练样本代替生成结果。

## 小实验

- 将训练迭代减到100，观察采样退化。
- 改变 `steps` 与末端 beta，比较终端累计信号比例。
- 去掉时间嵌入，观察模型无法区分噪声强度的影响。
