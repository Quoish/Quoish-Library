# 从一个线性判别器开始

感知机把输入特征加权求和，再根据符号输出类别。令$x\in\mathbb R^d$、$y\in\{-1,+1\}$，判别函数为

$$
s=w^Tx+b,\quad \hat y=\operatorname{sign}(s).
$$

$w$决定分界面的方向，$b$控制位置。若$w=(1,1)^T$、$b=-1.5$，则点$(1,1)^T$判为正类，$(0,0)^T$判为负类。零分数的处理需在实现中约定。

# 感知机如何学习

对误分类或落在边界上的样本，即$y_i(w^Tx_i+b)\leq0$，进行更新：

$$
w\leftarrow w+\eta y_ix_i,\quad b\leftarrow b+\eta y_i.
$$

如果正样本被分错，更新会增大该样本的分数；负样本则相反。对应的感知机损失可写为$\max(0,-y_is_i)$，边界处选取一个更新用的次梯度。它与逻辑回归的平滑概率损失不同，感知机输出不直接提供校准概率。

有限训练集线性可分、输入有界且存在正间隔时，标准感知机算法在有限次错误更新后收敛。非线性可分或带冲突标签时可能一直振荡，通常应设置轮数上限或采用平均感知机等变体。

# XOR 为什么需要隐藏层

XOR 在$(0,0),(1,1)$输出0，在$(1,0),(0,1)$输出1。两类分布在方形的交替顶点上，单条直线无法分开。

多层感知机引入隐藏表示：

$$
h=\phi(W_1x+b_1),\quad z=W_2h+b_2.
$$

隐藏单元可以表达不同区域，再由输出层组合。例如 ReLU 网络能表达

$$
\operatorname{XOR}(x_1,x_2)=\operatorname{ReLU}(x_1-x_2)+\operatorname{ReLU}(x_2-x_1)
$$

在二进制输入上的值。学习得到的隐藏层未必采用这一具体分解。

# 非线性与网络容量

如果隐藏层不含非线性，无论堆叠多少个仿射变换，整体仍是仿射变换。ReLU、Tanh 等激活函数让网络能够表达复杂边界。宽度、深度和训练方法共同影响效果。

通用逼近结论描述某些网络族在适当条件下能够逼近连续函数；它不保证训练一定找到所需参数，也不保证少量数据上的泛化。多个隐藏层还会引入优化、梯度传播和过拟合问题，需结合[[神经网络优化与泛化]]理解。

# 可复原例程

先用 NumPy 训练线性可分数据的感知机，再用 PyTorch MLP 学习 XOR，比较两种问题的结构。

### `runtime.py`

```python
from pathlib import Path
import argparse
import random
import numpy as np
import torch

ROOT = Path(__file__).resolve().parent
OUT = ROOT / "outputs"
OUT.mkdir(exist_ok=True)

def setup():
    parser = argparse.ArgumentParser()
    parser.add_argument("--cpu", action="store_true")
    args = parser.parse_args()
    random.seed(7)
    np.random.seed(7)
    torch.manual_seed(7)
    torch.set_num_threads(2)
    device = torch.device("cuda" if torch.cuda.is_available() and not args.cpu else "cpu")
    print("device:", device)
    return device
```

### `model.py`

```python
from torch import nn

class XORNet(nn.Module):
    def __init__(self):
        super().__init__()
        self.layers = nn.Sequential(nn.Linear(2, 8), nn.Tanh(), nn.Linear(8, 1))

    def forward(self, x):
        return self.layers(x).squeeze(-1)
```

### `main.py`

```python
import json
import numpy as np
import torch
from torch import nn
from model import XORNet
from runtime import setup, OUT

def main():
    device = setup()
    x = np.array([[0., 0.], [0., 1.], [1., 0.], [1., 1.]])
    linear_y = np.array([-1, -1, -1, 1])
    w, b = np.zeros(2), 0.0
    for epoch in range(100):
        errors = 0
        for row, label in zip(x, linear_y):
            if label * (row @ w + b) <= 0:
                w += 0.2 * label * row
                b += 0.2 * label
                errors += 1
        if errors == 0:
            break
    print("perceptron AND:", np.where(x @ w + b > 0, 1, -1).tolist())
    inputs = torch.tensor(x, dtype=torch.float32, device=device)
    targets = torch.tensor([0., 1., 1., 0.], device=device)
    net = XORNet().to(device)
    optimizer = torch.optim.Adam(net.parameters(), lr=0.03)
    loss_fn = nn.BCEWithLogitsLoss()
    for step in range(800):
        optimizer.zero_grad()
        loss = loss_fn(net(inputs), targets)
        loss.backward()
        optimizer.step()
    net.eval()
    with torch.no_grad():
        probabilities = net(inputs).sigmoid().cpu().tolist()
    report = {"xor_probability": probabilities, "final_loss": loss.item()}
    print(report)
    (OUT / "metrics.json").write_text(json.dumps(report, indent=2), encoding="utf-8")
    torch.save(net.state_dict(), OUT / "xor.pt")

if __name__ == "__main__":
    main()
```

## 结果与解释

AND 感知机应输出 `[-1, -1, -1, 1]`；MLP 对 XOR 的四个概率应分别接近0、1、1、0。本例仅有四个训练输入，展示可表达性与优化过程，不能用于衡量对一般真实数据的泛化。

## 小实验

- 把感知机标签换成 XOR，观察有上限的迭代仍不能全部分对。
- 将 MLP 的 Tanh 换成 Identity，观察线性层堆叠的限制。
- 减少训练轮数，比较“能够表示”和“训练已经成功”的区别。
