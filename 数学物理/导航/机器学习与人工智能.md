# 阅读路线

这一组专题从学习问题、经典模型与训练方法开始，逐步进入图像和序列架构、语言表示、生成模型与决策。每篇先解释机制与关键公式，再给出可按文件复制复原的项目。

建议先读基础和神经网络训练，再选一条应用路线：

- 图像：[[卷积神经网络]] → [[残差网络]] → [[变分自编码器与生成对抗网络]] → [[扩散模型]]。
- 语言：[[循环神经网络]] → [[LSTM与GRU]] → [[词元化与向量嵌入]] → [[注意力机制]] → [[Transformer]] → [[大语言模型的训练与生成]]。
- 知识应用：语言路线基础 → [[检索增强生成]]，再结合[[模型微调与LoRA]]比较检索、提示与参数适配。
- 决策：学习基础与训练机制 → [[强化学习基础]]。

# 技术关系

| 技术 | 处于什么层次 | 与其他技术的关系 |
|---|---|---|
| 感知机、MLP、CNN、RNN | 模型及架构 | 使用损失与优化算法学习参数 |
| 残差连接 | 网络结构组件 | 可用于 CNN、Transformer 和扩散网络 |
| 嵌入 | 数值表示与编码方法 | 为语言模型输入及语义检索提供向量 |
| 注意力 | 信息交互组件 | Transformer 的核心，也可结合 RNN、CNN |
| Transformer | 模型架构族 | 可构成语言模型、检索编码器和视觉模型 |
| 自监督学习 | 构造学习信号的方式 | 下一词元、遮盖预测与对比学习均可采用 |
| LoRA | 参数适配方法 | 可对 Transformer 的线性投影进行微调 |
| RAG | 检索与生成组成的系统 | 可组合嵌入模型、索引与语言模型 |
| VAE、GAN、扩散 | 生成建模方法 | 可以使用 MLP、CNN、注意力或 Transformer |
| 强化学习 | 交互式学习范式 | 可使用表格、神经网络和语言模型作为策略或价值模型 |

# 统一运行环境

全部项目使用下列固定环境。环境文件面向 Windows 64位，并固定 PyTorch 的 Python 3.10／CUDA 11.8构建，避免求解器混入 CPU 构建。`pytorch-cuda` 是 Conda 中的 CUDA 运行时配套包，并非 PyTorch 版本号；本组固定 PyTorch 2.2.2 与 torchvision 0.17.2。OpenCV 4.7.0 使用 Conda 包，避免将它误写成无法对应同一来源的 pip 安装命令。

## 环境文件

在任意工作目录创建以下三个文件。环境只需创建一次，之后各专题项目共用。基础科学计算库由 Conda 管理；模型工具在激活后通过受约束的 pip 命令补充。

## 安装与选择解释器

在能使用 Conda 的终端进入上述文件所在目录，执行：

```powershell
$env:CONDA_CHANNEL_PRIORITY = "flexible"
conda env create -f environment.yml
conda activate ml-ai-notes
python -m pip install -c constraints.txt -r requirements-models.txt
python -m pip check
```

环境名已存在时，可用 `conda env list` 查看位置；避免直接覆盖已有同名环境。网络或求解失败时，应检查具体包与渠道，保留固定版本，不通过整体升级规避验证。

在 VS Code 中打开专题项目目录，使用“Python: Select Interpreter”选择 `ml-ai-notes`。新建终端后确认 `python` 对应这个环境。若 PowerShell 尚未初始化 Conda，可以先使用 Anaconda Prompt 激活环境，再执行 `code .` 打开项目。

### `check_env.py`

把以下检查程序保存在工作目录，执行 `python check_env.py`：

```python
import sys
import os
from pathlib import Path
import json
import importlib.metadata as metadata

# Windows 的 DLL 目录句柄需要保持存活；同时包含 Conda 的 MinGW 运行库。
_dll_handles = []
if os.name == "nt":
    for folder in ["Library/bin", "Library/mingw-w64/bin", "Library/usr/bin"]:
        directory = Path(sys.prefix) / folder
        if directory.is_dir():
            _dll_handles.append(os.add_dll_directory(str(directory)))

import numpy as np
import scipy
import skimage
import matplotlib
import pywt
import cv2
import sklearn
import torch
import torchvision

def main():
    expected = {
        "numpy": "1.23.5", "scipy": "1.10.1", "scikit-image": "0.20.0",
        "matplotlib": "3.7.1", "PyWavelets": "1.4.1", "scikit-learn": "1.3.2",
        "torch": "2.2.2", "torchvision": "0.17.2", "transformers": "4.44.2",
        "sentence-transformers": "3.0.1", "huggingface-hub": "0.24.7",
        "tokenizers": "0.19.1", "safetensors": "0.4.5"}
    actual = {name: metadata.version(name) for name in expected}
    assert sys.version_info[:3] == (3, 10, 0), sys.version
    for name, version in expected.items():
        assert actual[name].split("+")[0] == version, (name, actual[name], version)
    assert cv2.__version__ == "4.7.0", cv2.__version__
    assert torch.version.cuda == "11.8", torch.version.cuda
    assert torch.isfinite(torch.randn(3, 3) @ torch.randn(3, 3)).all()
    gpu = torch.cuda.is_available()
    if gpu:
        x = torch.randn(3, 3, device="cuda")
        assert torch.isfinite(x @ x.T).all()
    print(json.dumps({"python": sys.version.split()[0], "packages": actual,
        "opencv": cv2.__version__, "cuda_runtime": torch.version.cuda,
        "gpu_available": gpu, "gpu": torch.cuda.get_device_name(0) if gpu else None}, indent=2))

if __name__ == "__main__":
    main()
```

检查程序会在版本不符时立即指出。OpenCV 的 Qt 依赖需要带16位接口的 PCRE2，因此固定使用 Conda-forge 的10.42版本，避免混入同版本但仅含部分接口的其他渠道构建。检查程序还显式注册 Windows DLL 目录；其他单独使用 `cv2` 的程序遇到搜索路径问题时，可复用开头的目录注册代码。

CUDA 可用性还取决于显卡与驱动；没有可用 GPU 时，例程使用 CPU。配置文件包含 GPU 版 PyTorch，并不意味着每次运行都必须使用 GPU。

## 项目复原约定

1. 为每篇创建独立文件夹，按目录树创建手写文件。
2. 将标有文件路径的代码块完整复制到对应文件，保留缩进，保存为 UTF-8。
3. 激活统一环境，按该篇的运行命令执行；不需要把其他篇的辅助文件复制过来。
4. `outputs/` 由程序生成，模型检查点、指标和图片都保存在其中。
5. 神经网络项目支持 `--cpu`；只有 NumPy／scikit-learn 的项目直接运行，不接收该选项。

基础数据由代码生成或由 scikit-learn 内置提供。句向量检索、Qwen 推理与 RAG 首次需要下载公开模型；模型缓存由 Hugging Face 管理，同一账户后续运行可以复用。网络不可达时应保留原始错误，不能将下载失败解释为模型推理失败。

### 两个预训练模型

| 用途 | 模型 | 运行特点 |
|---|---|---|
| 中文嵌入与检索 | `BAAI/bge-small-zh-v1.5` | 句检索可使用 CPU，RAG 固定嵌入在 CPU |
| 中文生成 | `Qwen/Qwen2.5-0.5B-Instruct` | CUDA 用 float16，CPU 用 float32；短上下文与短输出 |

项目不依赖 API 密钥或付费接口。RAG 的资料为内置虚构数据，可替换成自己的少量公开文本。增加资料规模前应重新考虑切分、权限、索引与评价。
