# 狭义相对论的Lagrange力学
在经典力学里，[[运动方程#Hamilton原理]]是物理世界的最高法则，但可惜作用量的定义，即$$S=\int_{t_{1}}^{t_{2}}L(q,\dot{q},t)\mathrm{d}t$$并不满足Lorentz协变性（此处给经典Lagrange量加上副标$*$，以区分我们随后要提出的相对论Lagrange量）。
为了将这一强有力的工具加以改造，变为能适配相对论框架的理论工具，我们需要重新定义Lagrange量。
## 协变Lagrange量
在经典力学中，一个物理系统的状态由时间$t$，三维坐标$q$，三维速度$\dot{q}$确定，那么在四维时空中，一个物理系统的状态应该由四维坐标$x^a$（包括时间空间）和四维速度$U^a$确定。所以Lagrange量应该是一个关于$x^a$和$\dot{x}^a$的函数（这里的$\dot{x}^a=U^a$，代表对固有时$\tau$求导）。
传统的坐标时间$t$会因为惯性系的变换而发生改变，如果要做到Lorentz协变性，应该用满足Lorentz不变的固有时间$\tau$来代替$t$，所以我们有以下定义：
>四维时空中的作用量定义为$$S=\int_{p}^{q}L^*(x^a,\dot{x}^a)\mathrm{d}\tau$$其中$p,q$是时空中的两个点，代表始末态。
>其中$L^*$被称为*协变Lagrange量*。
>若将作用量定义为$$S=\int_{p}^{q}L(x^a,\dot{x}^a)\mathrm{d}t$$则其中$L$被称为*动力学Lagrange量*。
>两个Lagrange量之间的关系为$$L^*=\gamma L$$

在一些注重于挪用分析力学结论的教材中，使用动力学Lagrange量能无缝衔接经典结论。而在一些注重相对论理论的教材中，更注重协变Lagrange量才是物质本身的属性，不随参考系变化而变化。今后，Lagrange量默认指动力学Lagrange量，协变Lagrange量会专门说明。
本段我们只讨论协变Lagrange量的分析力学。
基于协变Lagrange量的分析力学虽然能够自然地将经典力学中$L=T-V$的经验迁移到相对论中来，但是在广义相对论中将寸步难行。
- 协变Lagrange量根据[[变分法]]可推得，满足协变形式的Euler-Lagrange方程$$\frac{ \mathrm{d}   }{ \mathrm{d}  \tau} \left( \frac{ \partial  L ^*}{ \partial  \dot{x}^a}  \right)-\frac{ \partial  L^* }{ \partial  x^a} =0$$其中上标点是对固有时$\tau$求导。
- 普通Lagrange量满足普通形式的Euler-Lagrange方程$$\frac{ \mathrm{d}   }{ \mathrm{d}  t} \left( \frac{ \partial  L }{ \partial  \dot{q}^a}  \right)-\frac{ \partial  L }{ \partial  q^a} =0$$其中上标点是对坐标时$t$求导。
## 自由粒子的运动方程
先考虑最简单的情况，即自由粒子的运动。我们可以仿照经典力学的$L=\dfrac{1}{2}mv^2$，直接写出狭义相对论下的自由粒子Lagrange量。
- Lagrange量：$$L=\frac{1}{2}m\eta_{ab}U^aU^b$$
- 正则动量：$$P_{a}=\frac{ \partial  L }{ \partial  U^a} =mU_{b}$$
- 运动方程：$$\frac{ \mathrm{d}   P_{a}}{ \mathrm{d}  \tau} =m\frac{ \mathrm{d}  U_{a} }{ \mathrm{d}  \tau} =U^b\partial_{b}P^a=0$$这就是惯性运动方程。
## 带电粒子的运动方程
下面我们考虑带电粒子在电磁场中的运动。我们也可以仿照经典力学的$L=\dfrac{1}{2}mv^2-q(\phi-\vec{v}\cdot \vec{A})$，直
‘’‘接写出狭义相对论下的自由粒子Lagrange量。
- Lagrange量：$$L=\frac{1}{2}\eta_{ab}U^aU^b+q\eta_{ab}U^aA^b$$其中$A^b$是四维电磁势，只与$x^a$有关而与$U^a$无关。
- 正则动量：$$P_{a}=\frac{ \partial  L }{ \partial  U^a} =mU_{a}+qA_{a}$$
- 运动方程：$$\frac{ \mathrm{d}   }{ \mathrm{d}  \tau} (m\eta_{ab}U^{b}+q\eta_{ab}A^{b})=q\eta_{bc}U^{b}\frac{ \partial   A^{c}}{ \partial  x^a} $$分析式子，它可以变为$$左=mU^b\partial_{b}U_{a}+qU^b\partial_{b}A_{a}$$$$右=q\eta_{bc}U^b\partial_{a}A^c=qU^b\partial_{a}A_{b}$$进而$$mU^b\partial_{b}U_{a}=qU^b(\partial_{a}A_{b}-\partial_{b}A_{a})=qU^bF_{ab}$$这与[[时空电磁场#4Lorentz力]]作用下的运动方程是一致的。
# 场的Lagrange力学
以上我们的分析都是针对质点的，现在我们要将这种方法推广到质点系、乃至连续场的分布。
在此之前我们先研究经典场。
## 经典场的连续极限
何谓场？经典场常常被想像成一个巨大的床垫，床垫上的每一个点上都系有一个弹簧（也就是谐振子），这些谐振子之间是相互耦合的。
先考虑一维的情况，假设一条线上等间距地放置着这样的弹簧，它们之间的距离间隔为$\mathscr{l}$，上系一个质量为$m$的小球，线上的质量密度则为$\rho=m/\mathscr{l}$，在时间$t$时，第$j$个弹簧的位移记为$q_{j}(t)$（横向的位移），劲度系数为$K$。如果弹簧非常非常的密，振动的振幅就不应该用$q_{j}(t)$来记录了，而是应该用坐标$x$代替$j$，变成$\phi(x,t)$。
这时的图景就如同[[晶格振动模型#一维单原子链振动模型]]一样。这样的弹簧有无数个，因此我们说**场具有无穷个自由度**。
此时的Lagrange量为$$L=\sum_{j} \frac{1}{2}m\left( \frac{ \partial  q_{j} }{ \partial  t}  \right)^2- \frac{1}{2}K(q_{j+1}-q_{j})^2$$而Hamilton量为$$H=\sum_{j} \frac{1}{2}m\left( \frac{ \partial  q_{j} }{ \partial  t}  \right)^2+ \frac{1}{2}K(q_{j+1}-q_{j})^2$$
现在，我们让$\mathscr{l}\to 0$，弹簧排列地非常非常密，这时$$\sum\to \int \mathrm{d}x,\quad j\to \frac{1}{\mathscr{l}},\quad \frac{ \partial  q_{j} }{ \partial  t} \to \frac{ \partial  \phi }{ \partial  t} $$故$$\sum_{j} \frac{1}{2}m\left( \frac{ \partial  q_{j} }{ \partial  t}  \right)^2\to \frac{1}{\mathscr{l}}\int \frac{1}{2}m\left( \frac{ \partial  \phi }{ \partial  t}  \right)^2\mathrm{d}x\to \int \frac{1}{2}\rho\left( \frac{ \partial  \phi }{ \partial  t}  \right)^2\mathrm{d}x$$然后$$\frac{q_{j+1}-q_{j}}{\mathscr{l}}\to \frac{ \partial  \phi }{ \partial  x}$$令$\mathcal{T}=K\mathscr{l}$为应力系数，则$$\sum_{j} \frac{1}{2}K(q_{j+1}-q_{j})^2\to \frac{1}{\mathscr{l}}\int \frac{1}{2}K\mathscr{l}^2 \left( \frac{ \partial  \phi }{ \partial  x}  \right)^2\mathrm{d}x\to \int \frac{1}{2}\mathcal{T}\left( \frac{ \partial  \phi }{ \partial  x}  \right)^2\mathrm{d}x$$最后
$$L=\int \left[ \frac{1}{2}\rho\left( \frac{ \partial  \phi }{ \partial  t}  \right)^2- \frac{1}{2}\mathcal{T}\left( \frac{ \partial  \phi }{ \partial  x}  \right)^2 \right]\mathrm{d}x$$
拓展到三维情形便是:
- Lagrange量：$$L=\int \left[ \frac{1}{2}\rho\left( \frac{ \partial  \phi }{ \partial  t}  \right)^2- \frac{1}{2}\mathcal{T}\left( \nabla \phi\right)^2 \right]\mathrm{d}^3x$$
- Hamilton量：$$H=\int \left[ \frac{1}{2}\rho\left( \frac{ \partial  \phi }{ \partial  t}  \right)^2+ \frac{1}{2}\mathcal{T}\left( \nabla \phi\right)^2 \right]\mathrm{d}^3x$$

它们都是对全空间的积分，所以我们不妨定义：
>*Lagrange密度*$\mathcal{L}$定义为$$L=\int \mathcal{L}\mathrm{d}^3x$$*Hamilton密度*$\mathcal{H}$定义为$$H=\int \mathcal{H}\mathrm{d}^3x$$除此之外还能定义共轭动量$$\pi(\vec{x})=\frac{ \partial  \mathcal{L} }{ \partial  \dot{\phi}} $$

- Hamilton量密度和Lagrange密度之间的关系为$$\mathcal{H}=\pi \dot{\phi}-\mathcal{L}$$可以与质点力学中的$H=\sum_{i} p_{i}\dot{q}_{i}$对比。
- 质点量与场量之间的对应关系为$$(q,p)\to(\phi,\pi)$$
## 相对论场的E-L方程
引入Lagrange密度后，再回想四维空间中动力学Lagrange量的定义$$S=\int L(x^\mu,\dot{x}^\mu)\mathrm{d}t\to S=\int \mathcal{L}(\phi,\partial_{\mu}\phi)\mathrm{d}^3x\mathrm{d}t$$同样对$S$使用变分法，我们将得到$$\frac{ \partial  \mathcal{L} }{ \partial  \phi} -\partial_{\mu}\left( \frac{ \partial  \mathcal{L} }{ \partial  (\partial_{\mu}\phi)}  \right)=0$$这就是场的Euler-Lagrange方程。
