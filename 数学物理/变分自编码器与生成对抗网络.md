# 核心图景：怎样让一个网络产生新的样本

分类器把输入变成类别，生成模型尝试描述或采样数据分布。VAE 和 GAN 都可以先抽取简单随机变量，再通过网络产生复杂样本，但训练反馈来自不同地方。

可以先记住：**VAE 同时学习编码与概率解码，通过重建和分布约束训练；GAN 让生成器接受判别器的反馈，通过对抗目标训练。**

# 问题域与发展背景

普通自编码器能够把样本压缩再重建，但未必能从任意随机潜变量生成合理结果：编码得到的点可能在潜空间中散布成不规则区域。

2013年提交的[VAE 工作](https://arxiv.org/abs/1312.6114)将潜变量概率模型、近似推断与可反向传播的随机采样结合。它不仅要求“重建得像”，还安排从简单先验抽样的生成途径。

2014年的[GAN](https://arxiv.org/abs/1406.2661)提供另一种反馈：不直接计算数据的显式似然或完整后验，而训练一个判别器帮助生成器改进分布。这也引出了交替优化不稳定、模式覆盖不足等新问题。

# 自编码器为什么还不等于随机生成器

普通自编码器先由编码器$x\mapsto z$，再由解码器$z\mapsto\hat x$，最小化重建误差。若训练样本的编码只落在少数零散位置，随意抽一个$z$可能落在从未训练过的区域。

因此，需要说明潜变量从什么分布抽、解码后代表什么概率模型，以及训练如何使这些安排协调起来。

# VAE 中的几个概率对象

| 对象 | 含义 |
|---|---|
| $x$ | 可见数据，例如图像或二维点 |
| $z$ | 描述生成变化的潜变量 |
| $p(z)$ | 先验，本例为标准高斯 |
| $p_\theta(x\mid z)$ | 解码器给出的数据条件分布 |
| $q_\phi(z\mid x)$ | 编码器给出的近似后验 |

$\theta,\phi$分别是解码器和编码器的参数。真实数据概率为

$$
p_\theta(x)=\int p_\theta(x\mid z)p(z)\,dz.
$$

许多潜变量都可能解释同一个$x$，积分要汇总所有可能，常难以直接计算。由贝叶斯公式得到的真实后验$p_\theta(z\mid x)$也包含这个难算的分母，所以用可计算的$q_\phi$近似。

# ELBO 的两部分分别约束什么

证据下界写成

$$
\mathrm{ELBO}=
\mathbb E_{q_\phi(z\mid x)}[\log p_\theta(x\mid z)]
-D_{KL}(q_\phi(z\mid x)\|p(z)).
$$

第一项要求从编码后的潜变量能够较好解释原数据；第二项限制每个样本的编码分布过度偏离统一先验。期望可以用抽样近似，训练时通常最小化负 ELBO。

它之所以是下界，可由下式理解：

$$
\log p_\theta(x)=\mathrm{ELBO}
+D_{KL}(q_\phi(z\mid x)\|p_\theta(z\mid x)).
$$

最后一项非负，表示近似后验与真实后验的差异。优化下界提供一条可操作的训练路线，但不等于已经精确计算所有样本似然。

# 重参数化怎样让随机采样也能训练

设编码器输出对角高斯的均值$\mu$与方差$\sigma^2$。直接说“从这个分布抽样”不容易看出梯度路径，改写为

$$
\epsilon\sim\mathcal N(0,I),\quad z=\mu+\sigma\odot\epsilon.
$$

随机性来自独立的$\epsilon$，而$z$对$\mu,\sigma$有明确的可微表达。例如$\mu=0.4,\sigma=0.2,\epsilon=-1.5$，得到$z=0.1$。梯度可以沿这次确定的计算回到编码器。

实现常输出$\log\sigma^2$，再用$\exp(\tfrac12\log\sigma^2)$得到标准差，保证其为正。

# KL 与重建项怎样落到数值

对角高斯后验到标准高斯的 KL 为

$$
D_{KL}=\frac12\sum_j(\mu_j^2+\sigma_j^2-1-\log\sigma_j^2).
$$

单维$\mu=0,\sigma=1$时为0；$\mu=1,\sigma=1$时为0.5，说明偏离先验的均值受到代价。

若解码分布采用固定方差高斯，负对数似然与$\|x-\hat x\|^2/(2\sigma_{obs}^2)$成比例；若方差也训练，还要保留相应对数方差项。伯努利解码器则会对应不同的重建目标。

本例固定观测方差0.04。调整 KL 的相对权重会改变重建与潜空间约束的平衡，也会改变相对于原始 ELBO 的目标。过强约束或过强解码器等条件下，还可能出现模型很少使用潜变量的后验坍塌。

# GAN 怎样从判别反馈学习

生成器$G(z)$把随机噪声变成样本；判别器$D(x)$估计真实来源概率。原始目标为

$$
\min_G\max_D\mathbb E_{x\sim p_{data}}\log D(x)
+\mathbb E_{z\sim p(z)}\log(1-D(G(z))).
$$

可以把每轮拆成两件事：先让判别器区分真实与当前假样本，再让生成器使假样本更容易被判成真实。

实际常给生成器用非饱和损失$L_G=-\mathbb E\log D(G(z))$。若某假样本被判真实的概率从0.1升到0.8，其生成损失从约2.303降到0.223。数学中的$D$是概率，程序可以输出 logits，由稳定的二元交叉熵内部完成变换。

判别器步骤使用 `fake.detach()`，不更新生成器；生成器步骤要保留“经过判别器、回到假样本”的梯度，即使暂时冻结判别器权重，也不能把整个判别计算放进无梯度区。

# 为什么 GAN 损失低不一定生成得好

判别器很容易识别假样本时，它自己的损失可能很低，却恰好说明生成器还不好。生成器还可能只覆盖几个模式，例如八簇数据只生成其中一簇，这叫模式坍塌的一种表现。

VAE 的重建、潜空间约束和 GAN 的对抗反馈，各自改善不同方面，也各有优化与分布假设。下方图中应同时观察样本是否像、模式是否覆盖、是否出现不应有的簇间过渡。

生成方法也可以组合：潜空间扩散就先借助自编码器表示，再学习去噪模型。技术发展并非只有一种生成方法彻底替代另一种方法。

from pathlib import Path
import argparse
import random

# 1. 路径统一从 runtime.py 所在目录出发，复制项目后无须改绝对路径。

# outputs/ 存放本项目的图像、指标与模型权重；不存在时自动创建。

OUT.mkdir(exist_ok=True)


def setup():
    """初始化运行环境并返回 torch.device。

    命令行参数只有 --cpu；ROOT、OUT 是导入时建立的项目路径。
    """

    # 2. 读取命令行选项：--cpu 允许在有显卡的机器上仍强制使用 CPU。

    parser.add_argument("--cpu", action="store_true")
    args = parser.parse_args()

    random.seed(7)
    np.random.seed(7)
    torch.manual_seed(7)

    # 小型教学网络限制 CPU 线程数，避免线程调度开销过大。
    torch.set_num_threads(2)

    # 4. 仅当 CUDA 可用且没有指定 --cpu 时使用 GPU；调用方负责移动模型和数据。
    device = torch.device(
        "cuda" if torch.cuda.is_available() and not args.cpu else "cpu"
    )
    print("device:", device)

    # 返回 torch.device；各入口脚本共用相同的设备选择规则。
    return device

### `data.py`

```python
"""生成圆周上八簇二维高斯数据，作为生成模型的目标分布。"""

# 标准库
import math

# 第三方库（由统一环境提供）
import torch


def sample_data(n, device):
    """返回 (n, 2) 的浮点张量，直接放在 device 指定的计算设备上。"""

    # 1. 从8个簇中等概率选择类别，类别仅用于构造训练分布。
    group = torch.randint(0, 8, (n,), device=device)

    # 2. 将类别映射为圆周上的8个角度，圆的半径为2。
    angle = group.float() * (2 * math.pi / 8)

    # 各样本的二维簇中心形状为 (n, 2)。
    centers = 2 * torch.stack([angle.cos(), angle.sin()], dim=1)

    # 3. 在中心附近加入标准差0.12的二维高斯扰动；每次调用生成新样本。
    return centers + 0.12 * torch.randn(n, 2, device=device)
```

### `model.py`

```python
"""定义 VAE 编码／解码器，以及 GAN 可复用的多层感知机。"""

# 第三方库（由统一环境提供）
import torch
from torch import nn


def mlp(cin, cout):
    """创建 cin 维输入到 cout 维输出的网络；用于编码器、解码器和 GAN。"""

    # 两层64维隐藏层，LeakyReLU 保留负半轴梯度；输出层不施加激活。
    return nn.Sequential(
        nn.Linear(cin, 64),
        nn.LeakyReLU(0.2),
        nn.Linear(64, 64),
        nn.LeakyReLU(0.2),
        nn.Linear(64, cout),
    )


class VAE(nn.Module):
    """定义 VAE 编码／解码器，以及 GAN 可复用的多层感知机。"""

    def __init__(self):
        """创建模型组件并登记参数；本方法只定义结构，不执行训练。"""

        super().__init__()

        # 1. 二维输入编码为4个数，随后分成二维均值和二维 log-variance。
        self.encoder = mlp(2, 4)

        # 解码器把二维潜变量映射回二维数据空间。
        self.decoder = mlp(2, 2)

    def forward(self, x):
        """输入 (B, 2)，返回二维重建均值、潜在均值和潜在对数方差。"""

        # 2. 按特征维一分为二；每个样本的均值、对数方差均为 (B, 2)。
        mu, logvar = self.encoder(x).chunk(2, dim=1)

        # 限制对数方差范围，避免指数计算得到极端值。
        logvar = logvar.clamp(-10, 10)

        # 3. 重参数化：标准差为 exp(0.5*logvar)，独立噪声不依赖编码器参数。
        z = mu + (0.5 * logvar).exp() * torch.randn_like(mu)

        # 4. 返回重建均值与后验参数，入口脚本据此计算重建项和 KL 项。
        return self.decoder(z), mu, logvar
```

### `main.py`

```python
"""在同一八簇分布上分别训练 VAE 和 GAN，并对照先验生成结果。"""

# 标准库
import json

# 第三方库（由统一环境提供）
import torch
from torch import nn
import matplotlib

# 采用不弹出窗口的绘图后端；必须在导入 pyplot 之前设置。
matplotlib.use("Agg")
import matplotlib.pyplot as plt

# 本项目模块
from data import sample_data
from model import VAE, mlp
from runtime import setup, OUT


def main():
    """在同一八簇分布上分别训练 VAE 和 GAN，并对照先验生成结果。

    按分段注释依次准备数据、执行计算并保存结果。
    """

    # 1. 初始化设备与 VAE；两种生成方法顺序训练，数据分布保持相同。
    device = setup()
    vae = VAE().to(device)
    optimizer = torch.optim.Adam(vae.parameters(), lr=0.002)

    # 2. 训练 VAE：每次采样128个真实点，优化重建项与 KL 项的和。
    for step in range(1000):
        x = sample_data(128, device)
        reconstructed, mu, logvar = vae(x)

        # 固定观测方差0.04的高斯似然：先对2个坐标求和，再对批次平均。
        reconstruction = (reconstructed - x).square().sum(1).mean() / (2 * 0.04)

        # 对角高斯后验到标准高斯先验的 KL；按潜变量维求和后对样本平均。
        kl = 0.5 * (mu.square() + logvar.exp() - 1 - logvar).sum(1).mean()

        # 构造当前批次的标量训练目标，反向传播将从这里开始。
        loss = reconstruction + kl

        # 清除上一轮梯度；PyTorch 的 backward 默认会累加到 .grad。
        optimizer.zero_grad()

        # 沿计算图计算参数梯度；此时参数数值尚未更新。
        loss.backward()

        # 优化器根据当前梯度真正更新可训练参数。
        optimizer.step()

    # 3. 建立 GAN：生成器2维噪声→2维样本，判别器2维样本→1个 logit。
    generator, discriminator = mlp(2, 2).to(device), mlp(2, 1).to(device)

    # 生成器与判别器使用各自的优化器，不能共享更新状态。
    opt_g = torch.optim.Adam(generator.parameters(), lr=0.001, betas=(0.5, 0.999))
    opt_d = torch.optim.Adam(discriminator.parameters(), lr=0.001, betas=(0.5, 0.999))

    # 判别器输出未经 Sigmoid 的分数，BCEWithLogitsLoss 在内部稳定计算。
    bce = nn.BCEWithLogitsLoss()

    # 4. 对抗训练：每轮先更新判别器，再更新生成器。
    for step in range(1400):
        # 取真实点与当前生成器的假样本，分别赋予真实／虚假标签。
        real = sample_data(128, device)
        fake = generator(torch.randn(128, 2, device=device))

        # 4a. 清空判别器梯度，准备学习辨别真实样本和假样本。
        opt_d.zero_grad()

        # fake.detach() 切断到生成器的梯度；判别器步骤不训练生成器。
        real_logits, fake_logits = discriminator(real), discriminator(fake.detach())

        # 真实样本目标为1，假样本目标为0；两部分损失相加。
        loss_d = bce(real_logits, torch.ones_like(real_logits)) + bce(
            fake_logits, torch.zeros_like(fake_logits)
        )

        # 只计算并更新判别器的参数。
        loss_d.backward()
        opt_d.step()
        for p in discriminator.parameters():
            # 4b. 暂时冻结判别器参数，但保留其输出对输入的导数，供生成器反传。
            p.requires_grad_(False)

        # 清空生成器梯度，再使用一批新的噪声生成样本。
        opt_g.zero_grad()
        generated_logits = discriminator(generator(torch.randn(128, 2, device=device)))

        # 非饱和生成器目标：希望假样本被判为真实，所以目标标签为1。
        loss_g = bce(generated_logits, torch.ones_like(generated_logits))

        # 梯度经过判别器回到生成器；只有生成器优化器执行此次更新。
        loss_g.backward()
        opt_g.step()
        for p in discriminator.parameters():
            # 恢复判别器的可训练状态，供下一轮判别器步骤使用。
            p.requires_grad_(True)

    # 5. 训练结束后，从标准高斯先验独立采样，比较生成分布而非训练重建。
    vae.eval()
    generator.eval()

    # 不记录这一段的求导图；适用于评价、参数初始化或手动更新。
    with torch.no_grad():
        # VAE 画的是解码器均值，没有再加入高斯观测噪声；GAN 直接给出生成点。
        points = [
            sample_data(1500, device),
            vae.decoder(torch.randn(1500, 2, device=device)),
            generator(torch.randn(1500, 2, device=device)),
        ]

    # 6. 真实数据、VAE、GAN 使用相同坐标范围，观察模式覆盖与簇间过渡。
    fig, axes = plt.subplots(1, 3, figsize=(10, 3))
    for ax, point, title in zip(axes, points, ["Data", "VAE decoder means", "GAN"]):
        point = point.cpu().numpy()
        ax.scatter(point[:, 0], point[:, 1], s=2, alpha=0.4)
        ax.set(xlim=(-3, 3), ylim=(-3, 3), title=title, aspect="equal")

    # 自动调整子图间距，避免标题和坐标标签被裁切。
    fig.tight_layout()
    fig.savefig(OUT / "samples.png", dpi=140)

    # 关闭已保存的图对象，避免反复运行时积累绘图资源。
    plt.close(fig)

    # 7. 保存末次损失和模型状态；损失有限不等于生成分布已经完全匹配。
    report = {
        "vae_reconstruction": reconstruction.item(),
        "vae_kl": kl.item(),
        "gan_discriminator_loss": loss_d.item(),
        "gan_generator_loss": loss_g.item(),
    }
    print(report)
    (OUT / "metrics.json").write_text(json.dumps(report, indent=2), encoding="utf-8")
    torch.save(
        {
            "vae": vae.state_dict(),
            "generator": generator.state_dict(),
        },
        OUT / "models.pt",
    )


if __name__ == "__main__":
    main()
```
