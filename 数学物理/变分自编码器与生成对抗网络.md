# 从判别到生成

分类器学习输入到标签的关系，生成模型尝试描述或采样数据分布。它可以合成新样本、学习潜在表示，或作为其他任务的一部分。VAE 和 GAN 都从简单潜变量出发，但训练原则不同。

# 自编码器与潜变量

普通自编码器用编码器把$x$压成$z$，再由解码器重建$x$。仅有低重建误差，不保证从任意标准高斯潜变量采样都能生成合理数据，因为编码分布可能只占潜空间的零散区域。

VAE 明确规定先验$p(z)$，并用$q_\phi(z\mid x)$近似难以直接计算的后验。边缘似然为$p_\theta(x)=\int p_\theta(x\mid z)p(z)\,dz$，通过证据下界训练：

$$
\log p_\theta(x)\geq
\mathbb E_{q_\phi(z\mid x)}[\log p_\theta(x\mid z)]
-D_{KL}(q_\phi(z\mid x)\|p(z)).
$$

第一项鼓励重建，第二项限制后验偏离先验。若$q$为对角高斯、先验为标准高斯，KL 为

$$
D_{KL}=\frac12\sum_j(\mu_j^2+\sigma_j^2-1-\log\sigma_j^2).
$$

重参数化$z=\mu+\sigma\odot\epsilon$、$\epsilon\sim\mathcal N(0,I)$，将随机性移入独立噪声，使梯度可以经过$\mu,\sigma$传播。实现常预测$\log\sigma^2$以保持方差为正。

# 重建损失隐含什么分布

固定方差高斯解码器的负对数似然与平方误差成比例，伯努利解码器对应二元交叉熵。损失形式要与数据和分布假设一致。调整 KL 权重会改变重建与潜空间约束的平衡，但偏离标准权重后通常不再是原始同一模型的严格 ELBO。

VAE 可能出现后验坍塌，即解码器很少依赖潜变量；固定高斯似然也可能使多解重建趋于平均。不能把“图像模糊”归结为所有 VAE 的必然性质。

# GAN 的对抗学习

生成器$G(z)$把噪声映射为数据，判别器$D(x)$估计真实来源。原始极小极大目标为

$$
\min_G\max_D\mathbb E_{x\sim p_{data}}\log D(x)
+\mathbb E_{z\sim p(z)}\log(1-D(G(z))).
$$

实际常对生成器使用非饱和目标$-\mathbb E\log D(G(z))$，在判别器较强时提供更有用的梯度。训练判别器时要将生成样本 `detach`，训练生成器时则保留通过判别器回到生成器的梯度。

GAN 可能发生模式坍塌，只生成分布的一小部分；也可能训练震荡。判别器损失接近某个值不自动说明样本质量好。评价应同时考虑质量、覆盖度与多样性。

# 两类方法如何比较

VAE 通过潜变量模型与变分推断建立训练目标，GAN 通过判别反馈匹配分布。下面在二维八簇分布上对照，可以直接看见模式覆盖与平滑程度；它不等同于图像生成基准。

# 可复原例程

同一项目分别训练 VAE 与 GAN，在二维八簇高斯数据上生成新点，保存真实与两种生成分布的并排图。无需外部数据和额外生成框架。

from pathlib import Path
import argparse
import random
import numpy as np
import torch

ROOT = Path(__file__).resolve().parent
OUT = ROOT / "outputs"
OUT.mkdir(exist_ok=True)

def setup():
    parser = argparse.ArgumentParser()
    parser.add_argument("--cpu", action="store_true")
    args = parser.parse_args()
    random.seed(7)
    np.random.seed(7)
    torch.manual_seed(7)
    torch.set_num_threads(2)
    device = torch.device("cuda" if torch.cuda.is_available() and not args.cpu else "cpu")
    print("device:", device)
    return device

### `data.py`

```python
import math
import torch

def sample_data(n, device):
    group = torch.randint(0, 8, (n,), device=device)
    angle = group.float() * (2 * math.pi / 8)
    centers = 2 * torch.stack([angle.cos(), angle.sin()], dim=1)
    return centers + 0.12 * torch.randn(n, 2, device=device)
```

### `model.py`

```python
import torch
from torch import nn

def mlp(cin, cout):
    return nn.Sequential(nn.Linear(cin, 64), nn.LeakyReLU(0.2),
        nn.Linear(64, 64), nn.LeakyReLU(0.2), nn.Linear(64, cout))

class VAE(nn.Module):
    def __init__(self):
        super().__init__()
        self.encoder = mlp(2, 4)
        self.decoder = mlp(2, 2)

    def forward(self, x):
        mu, logvar = self.encoder(x).chunk(2, dim=1)
        logvar = logvar.clamp(-10, 10)
        z = mu + (0.5 * logvar).exp() * torch.randn_like(mu)
        return self.decoder(z), mu, logvar
```

### `main.py`

```python
import json
import torch
from torch import nn
import matplotlib
matplotlib.use("Agg")
import matplotlib.pyplot as plt
from data import sample_data
from model import VAE, mlp
from runtime import setup, OUT

def main():
    device = setup()
    vae = VAE().to(device)
    optimizer = torch.optim.Adam(vae.parameters(), lr=0.002)
    for step in range(1000):
        x = sample_data(128, device)
        reconstructed, mu, logvar = vae(x)
        reconstruction = (reconstructed-x).square().sum(1).mean() / (2 * 0.04)
        kl = 0.5 * (mu.square()+logvar.exp()-1-logvar).sum(1).mean()
        loss = reconstruction + kl
        optimizer.zero_grad()
        loss.backward()
        optimizer.step()
    generator, discriminator = mlp(2, 2).to(device), mlp(2, 1).to(device)
    opt_g = torch.optim.Adam(generator.parameters(), lr=0.001, betas=(0.5, 0.999))
    opt_d = torch.optim.Adam(discriminator.parameters(), lr=0.001, betas=(0.5, 0.999))
    bce = nn.BCEWithLogitsLoss()
    for step in range(1400):
        real = sample_data(128, device)
        fake = generator(torch.randn(128, 2, device=device))
        opt_d.zero_grad()
        real_logits, fake_logits = discriminator(real), discriminator(fake.detach())
        loss_d = bce(real_logits, torch.ones_like(real_logits)) + bce(fake_logits, torch.zeros_like(fake_logits))
        loss_d.backward()
        opt_d.step()
        for p in discriminator.parameters():
            p.requires_grad_(False)
        opt_g.zero_grad()
        generated_logits = discriminator(generator(torch.randn(128, 2, device=device)))
        loss_g = bce(generated_logits, torch.ones_like(generated_logits))
        loss_g.backward()
        opt_g.step()
        for p in discriminator.parameters():
            p.requires_grad_(True)
    vae.eval()
    generator.eval()
    with torch.no_grad():
        points = [sample_data(1500, device), vae.decoder(torch.randn(1500, 2, device=device)),
                  generator(torch.randn(1500, 2, device=device))]
    fig, axes = plt.subplots(1, 3, figsize=(10, 3))
    for ax, point, title in zip(axes, points, ["Data", "VAE decoder means", "GAN"]):
        point = point.cpu().numpy()
        ax.scatter(point[:, 0], point[:, 1], s=2, alpha=0.4)
        ax.set(xlim=(-3, 3), ylim=(-3, 3), title=title, aspect="equal")
    fig.tight_layout()
    fig.savefig(OUT / "samples.png", dpi=140)
    plt.close(fig)
    report = {"vae_reconstruction": reconstruction.item(), "vae_kl": kl.item(),
              "gan_discriminator_loss": loss_d.item(), "gan_generator_loss": loss_g.item()}
    print(report)
    (OUT / "metrics.json").write_text(json.dumps(report, indent=2), encoding="utf-8")
    torch.save({"vae": vae.state_dict(), "generator": generator.state_dict()}, OUT / "models.pt")

if __name__ == "__main__":
    main()
```
