# 动作会改变未来数据

强化学习研究智能体在环境中通过交互学习策略。智能体观察状态，选择动作，获得奖励并进入新状态。与固定数据监督学习相比，动作会改变后续访问的状态，奖励也可能延迟出现，因此需要在探索和利用之间权衡。

马尔可夫决策过程常表示为$(\mathcal S,\mathcal A,P,R,\gamma)$：状态空间、动作空间、转移规律、奖励与折扣因子。马尔可夫性要求当前状态包含预测下一步所需的信息；真实观测若不满足这一条件，可能需要记忆或部分可观测建模。

# 策略、回报与价值

策略$\pi(a\mid s)$描述在状态$s$选择动作$a$的概率。折扣回报为

$$
G_t=\sum_{k=0}^\infty\gamma^kr_{t+k+1},\quad 0\leq\gamma<1.
$$

有限回合任务也可使用$\gamma=1$，但需满足终止与回报条件。状态价值$V^\pi(s)=\mathbb E_\pi[G_t\mid s_t=s]$；动作价值$Q^\pi(s,a)$额外指定当前动作。奖励是环境提供的即时信号，价值是未来累计收益的估计，两者不能混用。

# Bellman 关系与 Q-learning

最优动作价值满足

$$
Q^*(s,a)=\mathbb E[r+\gamma\max_{a'}Q^*(s',a')\mid s,a].
$$

Q-learning 根据单次转移更新：

$$
Q(s,a)\leftarrow Q(s,a)+\alpha\bigl[r+\gamma\max_{a'}Q(s',a')-Q(s,a)\bigr].
$$

方括号是时序差分误差。真正终止时目标不再包含下一状态价值；训练因步数限制而截断，与环境真实终止通常应区别处理。表格法在适当探索、步长等条件下有收敛结论，不能直接推广到任意神经网络逼近。

例如$Q(s,a)=0$、即时奖励为$-1$、下一状态最大价值为5、$\gamma=0.9$、$\alpha=0.2$，目标为3.5，更新后为0.7。当前负奖励仍可能通向长期正收益。

# 探索、DQN 与策略梯度

$\epsilon$-greedy 以概率$\epsilon$随机行动，其余时间选择当前最高 Q 值动作。探索不足会错过更好的路线，探索过多会降低当前回报。奖励设计不当可能诱使模型钻评价目标的空子。

DQN 使用神经网络表示 Q 值，并通过经验回放、目标网络等方式改善训练稳定性。策略梯度直接优化参数化策略，常用形式为

$$
\nabla J(\theta)=\mathbb E[\nabla_\theta\log\pi_\theta(a_t\mid s_t)A_t],
$$

$A_t$衡量动作相对基准的优势。Actor–Critic 同时学习策略和价值。PPO 等算法进一步控制策略更新，但不意味着对所有任务都稳定收敛。

# 如何评价

训练时带探索的平均回报，与评价时固定策略的回报不同。应使用多回合、多个随机种子，并检查成功率、步数与失败轨迹。仿真环境成功也不直接证明真实硬件安全可用。本例只验证离散网格中的表格 Q-learning。

### `environment.py`

```python
class GridWorld:
    def __init__(self):
        self.size = 5
        self.start, self.goal = (0, 0), (4, 4)
        self.walls = {(1, 1), (2, 1), (3, 3)}
        self.position = self.start

    def state(self):
        return self.position[0] * self.size + self.position[1]

    def reset(self):
        self.position = self.start
        return self.state()

    def step(self, action):
        dr, dc = [(-1, 0), (0, 1), (1, 0), (0, -1)][action]
        r, c = self.position
        candidate = (r+dr, c+dc)
        if 0 <= candidate[0] < self.size and 0 <= candidate[1] < self.size and candidate not in self.walls:
            self.position = candidate
        terminated = self.position == self.goal
        return self.state(), 10.0 if terminated else -1.0, terminated
```

### `main.py`

```python
from pathlib import Path
import json
import numpy as np
from environment import GridWorld

def main():
    out = Path(__file__).resolve().parent / "outputs"
    out.mkdir(exist_ok=True)
    rng = np.random.default_rng(7)
    env = GridWorld()
    q = np.zeros((25, 4))
    returns = []
    for episode in range(1500):
        state = env.reset()
        total = 0
        epsilon = max(0.05, 0.9 * (0.995 ** episode))
        for step in range(80):
            action = int(rng.integers(4)) if rng.random() < epsilon else int(q[state].argmax())
            next_state, reward, terminated = env.step(action)
            target = reward if terminated else reward + 0.95 * q[next_state].max()
            q[state, action] += 0.2 * (target-q[state, action])
            total += reward
            state = next_state
            if terminated:
                break
        returns.append(total)
    state = env.reset()
    path = [env.position]
    total, success = 0, False
    for step in range(40):
        state, reward, success = env.step(int(q[state].argmax()))
        total += reward
        path.append(env.position)
        if success:
            break
    report = {"success": success, "steps": len(path)-1, "return": total,
              "path": path, "last_100_training_return": float(np.mean(returns[-100:]))}
    print(json.dumps(report, indent=2))
    np.save(out / "q_table.npy", q)
    (out / "result.json").write_text(json.dumps(report, indent=2), encoding="utf-8")
    arrows = np.array(["↑", "→", "↓", "←"])
    rows = []
    for r in range(5):
        row = []
        for c in range(5):
            row.append("#" if (r, c) in env.walls else "G" if (r, c) == env.goal else arrows[q[r*5+c].argmax()])
        rows.append(" ".join(row))
    (out / "policy.txt").write_text("\n".join(rows), encoding="utf-8")

if __name__ == "__main__":
    main()
```

## 结果与解释

评价时关闭随机探索。成功路径应从 `(0,0)` 到 `(4,4)`，避开障碍；最短路径为8步，对应7次负奖励与终点奖励10，回报为3。`policy.txt` 中少访问的离路状态可能仍有不可靠动作，单条成功路径不能证明全状态最优。

## 小实验

- 修改障碍布局后重新训练，观察路径。
- 将每步奖励改成0，比较学习速度与路线长度。
- 使用多个种子统计成功率，而不只查看一条轨迹。
