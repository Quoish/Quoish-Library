# 核心图景：根据行动后的结果，学习怎样选择下一步

强化学习中的智能体观察环境、采取动作、接收奖励，并进入下一状态。动作不仅产生一个输出，还会改变后续遇到的数据；某个动作的好处，也可能很久之后才体现。

因此它同时处理**序列决策、延迟收益和探索**。监督学习中直接提供某条输入的目标答案，通常不能完整表达这些交互关系。

# 问题域与发展背景

控制与动态规划研究怎样根据未来收益作决策。如果转移和奖励规律已知，可以通过模型规划；当规律未知或难以直接建模时，需要从交互经验估计行动的后果。

[Q-learning，1992论文](https://link.springer.com/article/10.1007/BF00992698)是表格动作价值学习的代表性工作。后来高维观测使“为每个状态存一行表”难以扩展，[2013年的深度 Q 学习工作](https://arxiv.org/abs/1312.5602)用神经网络从游戏像素估计动作价值，连接了深层表示与交互式学习。

策略梯度与 Actor–Critic 则从另一条路线直接调整动作选择概率。价值学习、策略学习与基于模型的规划长期并存，对应不同的状态、动作和资源条件。

# 用一轮交互认识基本对象

以网格行走为例：

| 对象 | 记号 | 网格中的对应 |
|---|---|---|
| 状态 | $s_t$ | 当前所在位置，及任务所需的其他信息 |
| 动作 | $a_t$ | 上、右、下、左 |
| 奖励 | $r_{t+1}$ | 每步代价、到达终点的收益 |
| 转移 | $P(s_{t+1}\mid s_t,a_t)$ | 行动后到哪里，是否受随机性影响 |
| 策略 | $\pi(a\mid s)$ | 当前状态下怎样选择动作 |

马尔可夫决策过程要求状态已经包含预测下一步所需的信息。若只看到局部画面、看不到隐藏位置，可能要维护记忆或使用部分可观测模型，不能直接假定一帧观测就是完整状态。

# 奖励与回报的区别

奖励是一次转移的即时反馈，回报汇总此后的奖励：

$$
G_t=\sum_{k=0}^{\infty}\gamma^k r_{t+k+1}.
$$

$\gamma$是折扣因子，常取0到1之间。它降低较远奖励在当前的权重，并在适当条件下帮助无限期回报保持有限。有限、会终止的任务也可以使用$\gamma=1$。

若之后奖励为$-1,-1,10$，取$\gamma=0.9$，当前回报为$-1-0.9+0.9^2\times10=6.2$，无折扣累计值则为8。一步负奖励可能是在付出代价以获得更大的后续收益。

# 价值函数在估计什么

状态价值$V^\pi(s)$估计从状态$s$出发、之后遵循策略$\pi$的期望回报。动作价值$Q^\pi(s,a)$则先指定当前动作，再按策略继续。

价值不是即时奖励，也不是保证得到的结果；它是对未来随机轨迹的期望。Q 表因此可以把“眼前看起来都付出一步代价”的动作，按远期效果区分开。

# Bellman 关系怎样把未来连接到现在

最优动作价值满足

$$
Q^*(s,a)=\mathbb E\left[r+\gamma\max_{a'}Q^*(s',a')\mid s,a\right].
$$

把它读成：当前动作的价值等于即时奖励，加上下一状态最优后续行动的折扣价值，再对可能的转移结果取平均。

Q-learning 用一条实际转移构造目标，并修正当前估计：

$$
\delta=r+\gamma\max_{a'}Q(s',a')-Q(s,a),\quad
Q(s,a)\leftarrow Q(s,a)+\alpha\delta.
$$

$\delta$是时序差分误差，$\alpha$是学习率。当前$Q=0$、奖励$-1$、下一状态最大估计5，取$\gamma=0.9,\alpha=0.2$，目标为3.5，更新后当前Q值为0.7。

这样较远终点的收益会通过反复访问，逐渐传回前面的状态。表格收敛结论需要充分探索、合适步长等条件；固定步长的教学实验不应直接套用完整理论保证。

# 真正终止与人为截断

到达终点后没有本回合的未来收益，更新目标只用即时奖励。若只是训练程序达到最大步数，环境未必真正结束；是否继续自举估值，需要按任务定义处理。

本例将“到达目标”作为终止，80步上限仅是防止单回合无限运行。分清这两种情况，能避免把人为计时规则误写进价值目标。

# 为什么还需要探索

若一直只选目前Q值最高的动作，可能永远不知道另一条路线更好。$\epsilon$-greedy 以概率$\epsilon$随机行动，其余时间按当前估计选最大值。

训练时的动作可以带探索，而 Q-learning 的目标使用下一状态最大Q值，即面向贪心目标策略，这体现了离策略学习的特点。评价时通常关闭探索，另行统计贪心表现。

奖励设计也会改变行为：只奖励某个代理指标，智能体可能学会提高该指标，却偏离真正任务目的。奖励需要与成功条件一起审查。

# 从 Q 表到神经网络，再到直接学习策略

状态太多时，DQN 用$Q_\theta(s,a)$代替表。经验回放将过去转移打散抽样，减轻连续数据的相关性；目标网络暂时固定一份估计，缓解目标随当前参数不停变化的问题。它们改善训练条件，却不自动给任意网络和任务带来收敛保证。

策略梯度直接提高有利动作的概率。常见采样估计具有

$$
\widehat{\nabla J}=\frac1B\sum_{b=1}^B
\nabla_\theta\log\pi_\theta(a_b\mid s_b)\hat A_b
$$

这样的形式，$\hat A_b$衡量该动作相对基准有多好。Actor–Critic 同时学习策略与价值估计，后者帮助形成较低方差的训练信号。

# 如何解释例程结果

如果地图和规则已知，网格最短路可以直接用搜索求解。本例使用交互学习，是为了观察Q值怎样从经验更新，不表示所有寻路任务都需要强化学习。

测试关闭随机探索，检查是否到达目标、是否撞墙、走了几步。代码输出的回报是未折扣的奖励总和，而学习目标使用折扣因子；两者数值不应直接混用。成功的一条路径，也不能证明所有未充分访问的状态都已经学到最优策略。

### `environment.py`

```python
"""定义5×5有障碍网格：智能体行动、获取奖励，并判断是否到达终点。"""


class GridWorld:
    """定义5×5有障碍网格：智能体行动、获取奖励，并判断是否到达终点。"""

    def __init__(self):
        """设置网格尺寸、起点、终点与障碍，并将智能体放到起点。"""

        # 1. 网格坐标为 (行, 列)，起点在左上，终点在右下，障碍位置不可进入。
        self.size = 5
        self.start, self.goal = (0, 0), (4, 4)
        self.walls = {(1, 1), (2, 1), (3, 3)}

        # 开始时或 reset 时回到起点；每回合不继承上回合的位置。
        self.position = self.start

    def state(self):
        """把当前位置转换为一个整数状态编号。"""

        # 2. 将二维坐标编码成0～24的整数，作为 Q 表的行号。
        return self.position[0] * self.size + self.position[1]

    def reset(self):
        """重置环境并返回起始状态编号。"""

        # 开始时或 reset 时回到起点；每回合不继承上回合的位置。
        self.position = self.start
        return self.state()

    def step(self, action):
        """执行一个动作，返回 (下一状态编号, 即时奖励, 是否到达终点)。"""

        # 3. 动作0/1/2/3依次为上／右／下／左，转换成行列增量。
        dr, dc = [(-1, 0), (0, 1), (1, 0), (0, -1)][action]
        r, c = self.position

        # 先计算候选位置，再检查边界和障碍；无效动作使智能体留在原位。
        candidate = (r + dr, c + dc)

        # 只有合法坐标才更新实际位置，避免数组越界或穿过墙壁。
        if (
            0 <= candidate[0] < self.size
            and 0 <= candidate[1] < self.size
            and candidate not in self.walls
        ):
            self.position = candidate

        # 4. 只有到达终点才是真正终止；训练入口另行设置最大交互步数。
        terminated = self.position == self.goal

        # 每步代价为-1，进入终点奖励为10；返回新状态、奖励和终止标志。
        return self.state(), 10.0 if terminated else -1.0, terminated
```

### `main.py`

```python
"""用表格 Q-learning 学习避障路线，并在关闭探索后评价策略。"""

# 标准库
from pathlib import Path
import json

# 第三方库（由统一环境提供）
import numpy as np

# 本项目模块
from environment import GridWorld


def main():
    """用表格 Q-learning 学习避障路线，并在关闭探索后评价策略。

    按分段注释依次准备数据、执行计算并保存结果。
    """

    # 1. 建立输出目录，并固定用于探索动作的 NumPy 随机生成器。
    out = Path(__file__).resolve().parent / "outputs"
    out.mkdir(exist_ok=True)
    rng = np.random.default_rng(7)
    env = GridWorld()

    # 2. Q 表有25个状态、每个状态4个动作；初值全为0，不代表真实价值已知。
    q = np.zeros((25, 4))
    returns = []

    # 3. 训练1500个回合，每回合先重置环境并逐渐减小探索概率。
    for episode in range(1500):
        # 重置位置，准备开始当前阶段的交互。
        state = env.reset()
        total = 0

        # epsilon-greedy 的随机探索概率最低保留0.05，避免完全停止探索。
        epsilon = max(0.05, 0.9 * (0.995**episode))

        # 每回合最多交互80步；这是人为截断，不等同于环境真正终止。
        for step in range(80):
            # 以 epsilon 概率随机行动，其余时间取当前 Q 最大的动作。
            action = (
                int(rng.integers(4))
                if rng.random() < epsilon
                else int(q[state].argmax())
            )
            next_state, reward, terminated = env.step(action)

            # 4. 到达终点时只用即时奖励；其他情况加入折扣后的下一状态最大 Q 值。
            target = reward if terminated else reward + 0.95 * q[next_state].max()

            # 用学习率0.2按时序差分误差更新当前单元，不改动整张 Q 表。
            q[state, action] += 0.2 * (target - q[state, action])
            total += reward

            # 进入下一状态；只有环境终止才提前结束本回合。
            state = next_state
            if terminated:
                break
        returns.append(total)

    # 重置位置，准备开始当前阶段的交互。
    state = env.reset()

    # 5. 单独评价贪心策略：不再随机探索，也不再更新 Q 表。
    path = [env.position]
    total, success = 0, False

    # 最多走40步，防止未学好的贪心策略在无效动作或环路中无限停留。
    for step in range(40):
        state, reward, success = env.step(int(q[state].argmax()))
        total += reward
        path.append(env.position)
        if success:
            break

    # 6. 记录成功与否、路径长度、回报；训练平均回报仍包含探索，不能混为评价回报。
    report = {
        "success": success,
        "steps": len(path) - 1,
        "return": total,
        "path": path,
        "last_100_training_return": float(np.mean(returns[-100:])),
    }
    print(json.dumps(report, indent=2))
    np.save(out / "q_table.npy", q)
    (out / "result.json").write_text(json.dumps(report, indent=2), encoding="utf-8")

    # 7. 将每个状态的贪心动作画成文本箭头；墙与终点分别用 #、G 标注。
    arrows = np.array(["↑", "→", "↓", "←"])
    rows = []
    for r in range(5):
        row = []
        for c in range(5):
            row.append(
                "#"
                if (r, c) in env.walls
                else "G" if (r, c) == env.goal else arrows[q[r * 5 + c].argmax()]
            )
        rows.append(" ".join(row))

    # 写入 UTF-8 策略图，以免 Windows 默认编码无法正确显示箭头。
    (out / "policy.txt").write_text("\n".join(rows), encoding="utf-8")


if __name__ == "__main__":
    main()
```

## 结果与解释

评价时关闭随机探索。成功路径应从 `(0,0)` 到 `(4,4)`，避开障碍；最短路径为8步，对应7次负奖励与终点奖励10，回报为3。`policy.txt` 中少访问的离路状态可能仍有不可靠动作，单条成功路径不能证明全状态最优。
