# 根据当前需要选择信息

序列中的不同位置对当前计算的重要性不同。翻译一个代词时，模型可能需要关注远处的人名；回答问题时，需要关注与问题相关的片段。注意力通过可计算的匹配分数，为可访问的信息分配权重，再作加权汇总。

这是一种数据依赖的信息交互方式，不要求权重具有人的主观注意含义。注意力图可用于检查模型行为，但单看权重无法充分解释因果贡献。

# Query、Key、Value 与维度

用行向量组织输入，$X\in\mathbb R^{T\times d}$。自注意力对同一输入作三种投影：

$$
Q=XW_Q,\quad K=XW_K,\quad V=XW_V.
$$

若$Q\in\mathbb R^{T_q\times d_k}$、$K\in\mathbb R^{T_k\times d_k}$、$V\in\mathbb R^{T_k\times d_v}$，则

$$
S=\frac{QK^T}{\sqrt{d_k}}+M,\quad
A=\operatorname{softmax}_{\text{行}}(S),\quad O=AV.
$$

$S,A$的形状为$T_q\times T_k$，输出为$T_q\times d_v$。每个查询行给所有键分配权重，并汇总对应的值。键和值必须有相同的位置数，查询位置数可以不同。缩放缓解点积方差随维度增大造成的 Softmax 饱和，并不保证任意输入下的数值稳定。

# 一个可手算的例子

设一条查询对两个键的缩放分数为$[0,\log3]$，则 Softmax 权重为$[0.25,0.75]$。若两个值为$[2,0]$和$[0,4]$，输出就是$[0.5,3]$。信息匹配使用$Q,K$，被混合的内容来自$V$。

# 三种常用形式

自注意力中三者来自同一序列。交叉注意力中查询来自一段序列，键和值来自另一段，例如解码器查询编码器输出。因果自注意力只允许位置$t$访问不晚于$t$的输入，用于自回归生成。

掩码$M_{ij}$对允许访问的位置为0，对禁止位置为$-\infty$，必须在 Softmax 之前加入。自回归训练若错误地让模型看到未来词元，损失可能很低，但无法用于真实逐步生成。填充掩码还负责忽略无效位置；若一行全部被掩码，Softmax 可能产生 NaN。

# 多头注意力与位置

多个头使用不同投影并行计算，再拼接并投影：

$$
\operatorname{MHA}(X)=\operatorname{Concat}(O_1,\ldots,O_H)W_O.
$$

它允许不同子空间采用不同的交互模式，但不能预先给每个头指定唯一的语法职责。标准自注意力本身缺乏序列位置信息，通常要加入位置编码或使用相对位置机制。标准全注意力的权重矩阵规模随长度平方增长，长上下文会增加计算与内存成本。

### `attention.py`

```python
import math
import torch

def attention(q, k, v, causal=False):
    scores = q @ k.transpose(-2, -1) / math.sqrt(q.shape[-1])
    if causal:
        if q.shape[-2] != k.shape[-2]:
            raise ValueError("本例因果掩码要求等长自注意力")
        mask = torch.ones(scores.shape[-2:], device=q.device, dtype=torch.bool).triu(1)
        scores = scores.masked_fill(mask, float("-inf"))
    weights = scores.softmax(dim=-1)
    return weights @ v, weights
```

### `main.py`

```python
import math
import json
import torch
import matplotlib
matplotlib.use("Agg")
import matplotlib.pyplot as plt
from attention import attention
from runtime import setup, OUT

def main():
    device = setup()
    q = torch.tensor([[1.]], device=device)
    k = torch.tensor([[0.], [math.log(3)]], device=device)
    v = torch.tensor([[2., 0.], [0., 4.]], device=device)
    output, weights = attention(q, k, v)
    assert torch.allclose(output, torch.tensor([[0.5, 3.]], device=device))
    print("manual weights:", weights.tolist(), "output:", output.tolist())
    x = torch.randn(1, 5, 4, device=device)
    changed = x.clone()
    changed[:, 3:] += 20
    before, a = attention(x, x, x, causal=True)
    after, _ = attention(changed, changed, changed, causal=True)
    difference = (before[:, :3] - after[:, :3]).abs().max().item()
    assert difference < 1e-5
    assert torch.allclose(a.sum(-1), torch.ones_like(a.sum(-1)))
    report = {"manual_output": output.tolist(), "prefix_difference": difference}
    (OUT / "metrics.json").write_text(json.dumps(report, indent=2), encoding="utf-8")
    fig, ax = plt.subplots(figsize=(4, 3))
    image = ax.imshow(a[0].cpu(), vmin=0, vmax=1)
    ax.set(xlabel="key position", ylabel="query position")
    fig.colorbar(image, ax=ax)
    fig.tight_layout()
    fig.savefig(OUT / "attention.png", dpi=140)
    plt.close(fig)

if __name__ == "__main__":
    main()
```
