# 核心图景：先决定该看哪些信息，再决定汇总多少

注意力可以拆成“匹配”与“汇总”两件事。当前位置提出一个查询，拿它与可访问位置的键比较，得到权重，再按权重混合那些位置的内容向量。

用查阅资料作类比：当前需要对应 Query，可供匹配的索引对应 Key，最终取出的内容对应 Value。网络中三者通常都是学习得到的向量，不要求它们是字面上的问题、标题和段落。

# 问题域与发展背景

早期常见的序列到序列模型先把源句编码为一个固定长度状态，再让解码器生成译文。句子越长，所有细节都经由同一个压缩入口，就越容易形成信息瓶颈。

2014年提交、发表于 ICLR 2015的[Bahdanau 等注意力工作](https://arxiv.org/abs/1409.0473)，让解码器在生成不同词时，对不同源位置分配权重并形成不同上下文。例如生成某个译词时，可以更侧重源句中相关的几个位置，而不必始终依赖同一份句子摘要。

这类早期注意力仍可结合 RNN。2017年[Transformer](https://arxiv.org/abs/1706.03762)将多头自注意力用于更广泛的位置交互，并采用缩放点积这一具体形式。因此，注意力这个思路、缩放点积公式和 Transformer 整体架构，需要分层理解。

# 从一个查询的计算开始

设有查询$q$，候选键$k_1,\ldots,k_n$和对应内容$v_1,\ldots,v_n$。先计算匹配分数，再归一化：

$$
s_j=\frac{q^Tk_j}{\sqrt{d_k}},\quad
\alpha_j=\frac{e^{s_j}}{\sum_\ell e^{s_\ell}},\quad
o=\sum_j\alpha_jv_j.
$$

$d_k$是查询和键的维度；Value 的维度可以不同。每个$\alpha_j$非负，且总和为1，所以这一层输出是 Value 的加权平均。后续网络还会继续变换它。

Query／Key 决定从哪里获取信息，Value 决定被混合的内容。使用独立投影，给模型留下“匹配依据”与“传递内容”可以不同的自由度。

# 一次完整手算

令查询维度为1，$q=1$，两个键为$k_1=0,k_2=\log3$，对应 Value 为$v_1=(2,0)^T,v_2=(0,4)^T$。

1. 点积分数为$[0,\log3]$，缩放因子$\sqrt1=1$。
2. 指数变为$[1,3]$，归一化后权重为$[0.25,0.75]$。
3. 加权输出为$0.25(2,0)^T+0.75(0,4)^T=(0.5,3)^T$。

模型在这里同时利用两个位置，只是第二个贡献更多。注意力不一定硬选出一个位置，也不要求训练标签直接标出“应该关注哪里”。

# 为什么要除以维度的平方根

若$q,k$各分量近似独立、零均值且方差为1，点积是$d_k$项乘积之和，其方差随$d_k$增长，典型尺度随$\sqrt{d_k}$增长。维度越高，未经缩放的分数越容易把 Softmax 推到极端尖锐区域。

除以$\sqrt{d_k}$用于缓解这种尺度效应。上述分析依赖简化统计假设，不能保证任意训练状态下分数都完美稳定。实现还常从每行分数减去最大值，再求指数，以避免数值溢出；这不会改变 Softmax 权重。

# 多个位置如何一次算完

这一节将每个位置的向量按行排列。自注意力输入$X\in\mathbb R^{T\times d}$，三组可训练投影为

$$
Q=XW_Q,\quad K=XW_K,\quad V=XW_V.
$$

更一般地，查询有$T_q$个位置，键值有$T_k$个位置：

$$
S=\frac{QK^T}{\sqrt{d_k}}+M,\quad
A=\operatorname{softmax}_{\mathrm{行}}(S),\quad O=AV.
$$

| 张量 | 形状 | 每行表示什么 |
|---|---|---|
| $Q$ | $T_q\times d_k$ | 一个查询位置 |
| $K$ | $T_k\times d_k$ | 一个可匹配位置 |
| $V$ | $T_k\times d_v$ | 该位置可传出的内容 |
| $S,A$ | $T_q\times T_k$ | 一次查询对全部键的分数／权重 |
| $O$ | $T_q\times d_v$ | 各查询汇总得到的向量 |

Softmax 沿键位置归一化，故每个查询行分别和为1。键和值的位置数必须一致，查询的位置数可以不同。

# 自注意力、交叉注意力和因果注意力

自注意力的 Q/K/V 来自同一序列，它让各位置相互交流。交叉注意力的查询来自一段序列，键值来自另一段，例如译文解码状态查询源句表示。

因果自注意力另外限制可见范围。三个位置的加性掩码可以写成

$$
M=\begin{bmatrix}
0&-\infty&-\infty\\
0&0&-\infty\\
0&0&0
\end{bmatrix}.
$$

第$i$行只能使用不晚于$i$的输入。掩码必须在 Softmax 之前加入，禁止位置的指数权重才会归零。

下一词元训练中，当前位置的输入词元已经知道，目标是后一个词元，因此对角线可以保留。如果把未来目标也放进可访问范围，模型会得到训练时才有的答案线索。

填充掩码处理无效位置，与因果掩码的目的不同。若一整行全被屏蔽，就没有可归一化的有效候选，可能产生 NaN，需要专门处理。

# 多头注意力为什么不只计算一次

不同头使用不同 Q/K/V 投影，可以在不同子空间形成不同交互：

$$
\operatorname{MHA}(X)=\operatorname{Concat}(O_1,\ldots,O_H)W_O.
$$

拼接之后再线性混合，恢复下游需要的维度。它增加了多种信息联系并存的可能性，但不能预先断言“第一个头专门理解主语，第二个头专门理解指代”。

标准自注意力本身不提供完整的位置顺序信息，通常需要位置编码或相对位置机制。普通密集注意力还要计算位置两两关系，长序列的计算和内存代价会增加。

# 权重能说明什么

一张注意力热图显示某层、某头如何在候选位置间分配权重。它有助于检查掩码和行为，却不足以单独证明某词对最终答案的因果作用：Value、后续层及其他路径都可能改变结果。

下方例程分开核对两件事：手算结果是否一致，以及改动未来词元后前缀输出是否保持不变。先把这两点掌握，再阅读[[Transformer]]中的整块网络。

# 可复原例程

实现单头缩放点积注意力，核对手算权重；再改变未来词元，验证因果掩码保护前缀输出。保存注意力热图。

```python
"""统一处理项目路径、随机种子、CPU线程与计算设备。"""

# 标准库
from pathlib import Path
import argparse
import random

# 第三方库（由统一环境提供）
import numpy as np
import torch

# 1. 路径统一从 runtime.py 所在目录出发，复制项目后无须改绝对路径。
ROOT = Path(__file__).resolve().parent

# outputs/ 存放本项目的图像、指标与模型权重；不存在时自动创建。
OUT = ROOT / "outputs"
OUT.mkdir(exist_ok=True)


def setup():
    """初始化运行环境并返回 torch.device。

    命令行参数只有 --cpu；ROOT、OUT 是导入时建立的项目路径。
    """

    # 2. 读取命令行选项：--cpu 允许在有显卡的机器上仍强制使用 CPU。
    parser = argparse.ArgumentParser()
    parser.add_argument("--cpu", action="store_true")
    args = parser.parse_args()

    # 3. 固定 Python、NumPy 和 PyTorch 的随机种子；跨设备仍不保证逐位相同。
    random.seed(7)
    np.random.seed(7)
    torch.manual_seed(7)

    # 小型教学网络限制 CPU 线程数，避免线程调度开销过大。
    torch.set_num_threads(2)

    # 4. 仅当 CUDA 可用且没有指定 --cpu 时使用 GPU；调用方负责移动模型和数据。
    device = torch.device(
        "cuda" if torch.cuda.is_available() and not args.cpu else "cpu"
    )
    print("device:", device)

    # 返回 torch.device；各入口脚本共用相同的设备选择规则。
    return device
```

### `attention.py`

```python
"""实现缩放点积注意力及等长自注意力的因果掩码。"""

# 标准库
import math

# 第三方库（由统一环境提供）
import torch


def attention(q, k, v, causal=False):
    """返回加权结果和注意力矩阵。

    q、k 的末维相同，k、v 的序列长度相同；causal=True 禁止读取未来位置。
    """

    # 1. q: (..., Tq, dk)，k: (..., Tk, dk)；末两维相乘后得到 (..., Tq, Tk)。
    # 除以 sqrt(dk) 缓解点积尺度随键维度增大而增加的问题。
    scores = q @ k.transpose(-2, -1) / math.sqrt(q.shape[-1])

    # 2. 本例因果掩码只实现等长自注意力，提前检查 Tq=Tk。
    if causal:
        if q.shape[-2] != k.shape[-2]:
            raise ValueError("本例因果掩码要求等长自注意力")

        # 严格上三角为 True，对应“查询位置尚不可见的未来键位置”。
        mask = torch.ones(scores.shape[-2:], device=q.device, dtype=torch.bool).triu(1)

        # 1. q: (..., Tq, dk)，k: (..., Tk, dk)；末两维相乘后得到 (..., Tq, Tk)。
        # 除以 sqrt(dk) 缓解点积尺度随键维度增大而增加的问题。

        # 必须在 Softmax 之前屏蔽，让未来位置获得零权重。
        scores = scores.masked_fill(mask, float("-inf"))

    # 3. 沿键位置归一化：每个查询行的权重和为1。
    weights = scores.softmax(dim=-1)

    # 4. 用注意力权重混合 Value；v 为 (..., Tk, dv)，输出为 (..., Tq, dv)。
    return weights @ v, weights
```

### `main.py`

```python
"""核对可手算的注意力权重，并检验未来输入不会影响因果前缀。"""

# 标准库
import math
import json

# 第三方库（由统一环境提供）
import torch
import matplotlib

# 采用不弹出窗口的绘图后端；必须在导入 pyplot 之前设置。
matplotlib.use("Agg")
import matplotlib.pyplot as plt

# 本项目模块
from attention import attention
from runtime import setup, OUT


def main():
    """核对可手算的注意力权重，并检验未来输入不会影响因果前缀。

    按分段注释依次准备数据、执行计算并保存结果。
    """

    # 1. 初始化设备，创建一个查询、两个键和两个二维 Value。
    device = setup()

    # 键维度为1，故缩放因子也为1；两项分数为0和 log(3)。
    q = torch.tensor([[1.0]], device=device)
    k = torch.tensor([[0.0], [math.log(3)]], device=device)
    v = torch.tensor([[2.0, 0.0], [0.0, 4.0]], device=device)

    # 2. Softmax 应得到 [1/4, 3/4]，加权 Value 应得到 [0.5, 3.0]。
    output, weights = attention(q, k, v)

    # 先验证正文中可手算的结果，排除运算方向或归一化轴错误。
    assert torch.allclose(output, torch.tensor([[0.5, 3.0]], device=device))
    print("manual weights:", weights.tolist(), "output:", output.tolist())

    # 3. 再建立5个位置、每个位置4维的随机序列，用同一张量充当 Q/K/V。
    x = torch.randn(1, 5, 4, device=device)

    # 只改变最后两个位置，前3个输入保持不变。
    changed = x.clone()
    changed[:, 3:] += 20

    # 4. 对原输入和改动输入分别做因果注意力；前3个输出应完全不依赖后2个位置。
    before, a = attention(x, x, x, causal=True)
    after, _ = attention(changed, changed, changed, causal=True)

    # 只比较前三个查询位置；数值误差上限用断言控制。
    difference = (before[:, :3] - after[:, :3]).abs().max().item()
    assert difference < 1e-5

    # 同时检查每个注意力行是否规范地归一化为1。
    assert torch.allclose(a.sum(-1), torch.ones_like(a.sum(-1)))

    # 5. 保存手算核对与因果性检查结果。
    report = {
        "manual_output": output.tolist(),
        "prefix_difference": difference,
    }
    (OUT / "metrics.json").write_text(json.dumps(report, indent=2), encoding="utf-8")

    # 6. 将第一批样本的注意力权重画成热图，横轴是键，纵轴是查询。
    fig, ax = plt.subplots(figsize=(4, 3))
    image = ax.imshow(a[0].cpu(), vmin=0, vmax=1)
    ax.set(xlabel="key position", ylabel="query position")
    fig.colorbar(image, ax=ax)

    # 自动调整子图间距，避免标题和坐标标签被裁切。
    fig.tight_layout()
    fig.savefig(OUT / "attention.png", dpi=140)

    # 关闭已保存的图对象，避免反复运行时积累绘图资源。
    plt.close(fig)


if __name__ == "__main__":
    main()
```
