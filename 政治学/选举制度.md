选举制度（Electoral System）是国家政治制度的重要组成部分，通常指关于选举国家代表机关代表和国家公职人员的原则、程序和方法的总称。
狭义上，它主要指投票、计票和当选规则；广义上，还包括选举原则、选民资格、候选人提名、选区划分、选举组织、竞选活动、监督与救济等一整套制度安排。
概括来说，选举制度可以被描述为以下六大结构。![[选举制度六大构成维度.png]]
# 单一选区制度
单一选区指一个选区只产生一名代表。
单一选区制度可以选择的胜选规则有：简单多数制、两轮投票制、排序投票制等。
## 简单多数制
*简单多数制*（First-past-the-post, FPTP），指得票最多者当选的选举制度，不要求获得绝对多数（超过50%），代表国家有**英国下议院选举**。
“迪韦尔热法则”（Duverger's Law）描述了单一选区相对多数制倾向于形成两党竞争的现象，比如一次选举结果为

| 候选人 |   得票 |  比例 | 简单多数结果 |
| --- | ---: | --: | ------ |
| A   | 4500 | 45% | 当选     |
| B   | 4000 | 40% | 落选     |
| C   | 1500 | 15% | 落选     |
虽然A党只有45%的选票，却获得该选区唯一的议席。B党和C党合计获得55%的选票，却没有任何人当选。
如果这种情况在全国反复出现，小党就可能长期得不到与得票率相称的席位。
因此，选民可能逐渐放弃自己最喜欢、但难以胜选的小党，转而支持两个主要政党中的一个。这被称为策略性投票。
简单多数制的问题在于，即便A党仅仅比B党高出很小一部分优势，也只能A党当选而B党不能，这意味着选给B党和其他政党的许多票数代表的那些民意相当于被忽视了，会加剧社会的割裂。
## 两轮投票制
*两轮投票制*（Two-round system, TRS）指，若第一轮投票中无候选人获得法定多数（如超过50%），则对得票最高的前两名候选人进行第二轮投票，以决出胜者，代表国家有**法国国民议会选举**。
法国的两轮投票制容易形成政党联盟，原因是：
第一轮允许各党独立竞争，第二轮却鼓励意识形态相近或具有共同政治目标的政党协调合作。
这使法国的选举制度同时具有两种特征：
- 第一轮促进多党竞争：各党可以展示自己的实力，不必立即放弃独立候选人。
- 第二轮促进政党结盟：各党为了避免选票分散，可能撤回候选人、相互背书，集中支持某一候选人。

而且，法国国民议会的两轮投票制有一个非常重要的特点：第二轮不一定只有两名候选人，可能有三名甚至四名候选人。
假如第一轮选举结果是：

| 候选人 |  比例 |
| --- | --: |
| A   | 40% |
| B   | 35% |
| C   | 25% |
假设C党支持者中20个百分点转投B党，其余5个百分点投给其他候选人或有效选项，则B党取得55%的选票。

| 候选人 |  比例 | 第二轮结果 |
| --- | --: | ----- |
| A   | 40% | 落选    |
| B   | 55% | 当选    |
| 其他  |  5% | 落选    |
这说明：对于B党和C党而言，即使它们在第一轮是竞争对手，在第二轮也可能因为反对A党当选，而产生共同利益。
## 排序选择投票制
*排序选择投票制*（Instant-Runoff Voting, IRV）指的是可以让选民在一张选票上对各个候选人进行排序，可以减少因支持弱势候选人而浪费选票的风险，典型代表是**澳大利亚众议院选举**。
一般的流程可以概括为：
1. 每张有效选票先计给其最高、且仍在竞争中的偏好。
2. 如某候选人获得有效票绝对多数，则结束。
3. 否则排除当前最低票者，把这些选票转给票上下一名仍在竞争的候选人。
4. 重复检查和转移。

这里的“下一偏好”可能是原选票上的第三、第四名，因为排在中间的人也可能已经被排除。
不过，在澳大利亚，因为法律要求所有公民必须参与选举，很多对选举并不关心或不了解的人也会参与到选举中，他们不知道如何排序这些选举人，往往就是按照政党在投票处发放的**如何投票卡**（How to Vote Card）做，按照卡上的候选人排序挨个填上后敷衍了事，所以政党颁发的如何投票卡有时也会影响选举结果。
# 复数选举区制度
复数选区只说明一个选区产生多名代表，为多元代表提供了空间，它配合不同的投票与席位分配规则。
