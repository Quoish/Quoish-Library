《小逻辑》导言首先面对一个困难：**哲学要求说明对象、方法和前提的*必然性*（Notwendigkeit），但开端本身看起来恰恰是一个尚未得到证明的前提。** 围绕这一困难，黑格尔逐步说明哲学的*思维*（Denken）形式、它与经验科学的关系，以及哲学何以必须形成一个能够返回自身的体系。

以下按导言的论述顺序整理，主体对应§1—§17；§18的体系划分作为补充。

# 一、哲学为什么有开端的困难（§1）

## 1. 哲学的对象

哲学以*真理*（Wahrheit）为对象，并研究自然界、人的*精神*（Geist）及其相互关系。在黑格尔的表述中，哲学与宗教具有共同的最高对象，即上帝或绝对真理；两者在把握这一内容的形式上存在差别。

人通常先以*表象*（Vorstellung）的方式熟悉这些对象，随后才尝试在*思想*（Gedanke）中理解它们。因而，哲学可以以人们对对象已有的熟悉和兴趣作为进入研究的条件。

但**熟悉一个对象，不等于已经在*概念*（Begriff）上认识了它**。随着*反思*（Nachdenken）开始，哲学还必须追问：这个对象为什么*存在*（Sein）？它的*规定*（Bestimmung）为什么如此？把握它的方法凭什么有效？

## 2. 其他科学可以暂时接受的前提

一般科学可以在自身研究的起点，接受一些尚未由本学科证明的条件：

- 根据日常意识或表象，承认研究对象已经存在。
- 采用已经习惯或公认的认识方法。
- 以既定概念、定义或基本命题作为研究的出发点。

哲学则必须把这些前提也纳入考察。仅仅说“这是大家都知道的”“这个方法一直如此使用”，还不能满足哲学的要求。

## 3. 开端的两难

如果开端需要先被证明，它似乎就不再是最初的开端；如果开端可以不经证明地接受，哲学又似乎保留了一个独断的假设。

问题由此形成：**怎样开始一种不能把未经考察的前提当作最终根据的认识？**

导言后续关于反思、经验、*思辨*（spekulatives Denken）和体系的讨论，都与这一问题有关；§17将重新回到它。

# 二、哲学的形式：从表象到概念（§2—§5）

## 1. 一般思维与反思

黑格尔把思维看作人的*本质*（Wesen）规定。人的宗教、法律、道德等活动，即使以情感、信仰或表象的形式出现，也已经包含思维的作用。

但需要区分两个层次：

| 层次                | 特点                          |
| ----------------- | --------------------------- |
| 一般思维              | 渗透在人的各种意识活动中，不一定作为独立的对象被意识到 |
| 反思或*后思*（Nachdenken） | 把原有的意识内容重新带入思想，考察其中的*思想规定*（Denkbestimmung）    |
|                   |                             |

拥有经过思维塑造的情感和表象，与自觉地思考这些情感和表象，是不同的活动。哲学属于后一层次，并进一步要求以概念进行认识。

这也说明，情感与思维不必被设为互相排斥的两端。例如，道德情感具有思想内容，但产生道德情感并不以事先学习一套道德哲学为条件。

## 2. 内容可以相同，意识形式可以不同

意识中的内容，可以表现为情感、*直观*（Anschauung）、表象、目的、*意志*（Wille），也可以表现为思想和概念。

同一内容在不同形式中出现时，形式的特点会与内容结合，使它看起来像是不同的对象。例如，对正义的情感、有关正义的故事形象和正义的概念，在表达方式上不同，却可能涉及同一思想内容。

因此，可以分别考察：

- **内容**：意识所把握的是什么。
- **形式**：这一内容以怎样的方式被意识到。

哲学的工作，是将原来在情感、直观和表象中把握的内容，提升为思想和概念，并说明其中的联系。

## 3. 表象与概念

表象常借助熟悉的形象、事件或叙述来呈现内容。黑格尔把表象称为思想和概念的譬喻：表象能够承载思想，却未必已经揭示它所承载的思想规定。

由此需要区分两种认识：

1. 知道某个表象，并理解它所包含的思想意义。
2. 把握某个概念，并理解与它相应的情感、直观或表象。

两者都需要具体的认识工作，不能相互自动替代。

哲学之所以显得难懂，部分原因在于缺乏*抽象*（abstrakt）思维的训练；另一部分原因则在于，读者总想立即把概念还原为某个熟悉的形象。当概念不能马上对应一个可想象的画面时，便感到失去了立足点。

学习哲学因此需要逐渐习惯：把思想规定本身作为对象，考察其含义及其与其他规定的关系。

## 4. 哲学需要说明自身的必要性

面对日常意识，哲学需要唤起人们对概念认识的需要；面对宗教内容，哲学则需要说明自己如何凭借思想来把握真理。如果概念认识与宗教表象存在差别，也必须说明这种差别的根据。

把内容转入概念形式，并不意味着内容因此丧失真实性。经过反思，内容反而可能得到更充分、更明确的认识。

同时，“人人具有思维能力”不能直接推出“人人无需学习就能评价哲学”。哲学以思维为形式，但概念的运用、区别和论证仍需要训练。

# 三、哲学的内容：现实与经验（§6—§7）

## 1. 哲学与其他认识方式共同面对现实

哲学的形式是思想和概念，其内容则是*现实*（Wirklichkeit），包括意识所面对的外部世界和内部世界。人最初通过经验接触这一内容。

哲学必须与现实和经验相符合。这种符合可以构成检验哲学的一个外在标准。它的更高目标，是使自觉的*理性*（Vernunft）认识到世界中的理性，从而理解思想与现实之间的统一。

## 2. “现实”与一切现存之物的区别

黑格尔重申《法哲学原理》中的命题：

> 凡是合乎理性的都是现实的；凡是现实的都是合乎理性的。

这里的“现实”（Wirklichkeit）具有特定的哲学含义。日常语言可以把偶然事件、错误、恶以及短暂的*现象*（Erscheinung）统称为“现实”，黑格尔却要求区分这些现存之物与严格意义上的*现实性*（Wirklichkeit）。

因此，不能把这一命题直接改写为“凡是已经存在的事物都合理”，再据此为任何既存状况辩护。理解它的关键，在于考察事物的理性内容及其现实性。

与此相联系，黑格尔反对把*理念*（Idee）理解为两种东西：

- 脱离现实的幻想，哲学因而只是幻想的体系。
- 过于高远、只能停留在“*应当*（Sollen）”中的理想，永远无力实现自身。

哲学研究理念，也研究现实性；在黑格尔的体系中，这两方面具有内在联系。

## 3. 反思包含哲学的原则

反思把个别经验带入思想，寻找其中的*普遍性*（Allgemeinheit）和规律，这已经包含哲学的原则。

近代以来，独立的反思精神广泛转向现象世界，从大量个别、偶然的经验中寻找普遍规定。因此，一些以经验为出发点的学科，也曾被称为“哲学”，如牛顿的“自然哲学”。

这里的经验既包括外部感官经验，也包括人的内在意识生活。经验科学也并非单纯堆积材料：它们通过思维形成分类、一般命题、规律和理论。

# 四、经验知识为什么进一步要求思辨（§8—§9）

## 1. 对象范围上的限度（§8）

黑格尔认为，经验知识还不能充分把握*自由*（Freiheit）、精神、上帝等具有无限内容的对象。

这些对象也进入人的意识生活，因而不能简单说它们与一切经验无关。这里需要区分广义的意识经验与感官经验：一个内容可以被意识到，却不能因此就被当作有限的感官对象来处理。

对于“思想中的内容都曾在感觉中出现”这一命题，黑格尔同时强调反向关系：人的感觉和经验本身也已经受到思维的规定。尤其在法律、道德和宗教领域，情感中已经包含着思想内容。

## 2. 必然性形式上的不足（§9）

经验科学能够发现*一般性*（Allgemeinheit），理性还会进一步追问其中的必然性。黑格尔指出两个问题：

| 问题 | 含义 |
| --- | --- |
| 普遍与*特殊*（das Besondere）的联系仍显外在 | 一般原理、种类和个别事实被联系在一起，却未充分说明为什么这个普遍规定必然包含这些特殊规定，以及特殊规定彼此为何如此联系 |
| 开端仍是既定的 | 事实、定义、假设或基本规定被直接接受，其根据和必然性尚未在该科学内部得到说明 |

反复观察到某种情形，可以支持经验概括；但“已经多次如此”与“必然如此”之间，仍有需要说明的*环节*（Moment）。

当反思进一步要求克服这些不足时，就转入哲学所特有的思辨思维。

## 3. 思辨对经验科学的吸收与改造

思辨思维承认经验科学的事实，也吸收其规律和分类，同时考察它们所使用的*范畴*（Kategorie），揭示其限度，并把这些规定纳入更充分的概念联系。

可以把这一关系概括为：

**经验材料 → 科学的规律与分类 → 对这些规定的概念考察及其必然联系。**

因此，思辨研究仍须面对经验科学的具体内容。任意空想无法承担说明必然性的任务。

这里的“概念”还需要与通常的*知性*（Verstand）概念相区别。知性把规定固定在彼此外在的界限中；思辨则要求理解规定之间的内在关系及其转化。以有限的知性概念为标准断言“概念不能把握无限”，尚未触及黑格尔所说的思辨概念。

# 五、认识能力的考察也必须在认识中进行（§10）

哲学既然以思维把握自由、精神等对象，就必须说明思维为何有能力完成这一任务。但这种说明本身已经属于哲学研究。

黑格尔由此批评一种程序性的要求：在实际认识真理之前，先把认识能力完全检查清楚，确认工具可靠之后再开始认识。

这一要求的困难在于：**考察认识能力本身也是认识活动。** 对其他工具，可以在使用它完成特定工作之前，采用别的方式进行检验；对认识能力，却无法在一切认识之外完成这种检验。

“先学会游泳，然后才下水”的比喻指出了这个困难。对认识的批判需要在认识活动内部展开，并在展开中检验自身。

另一种办法是先作试探性的哲学研究，以暂定假设出发，期待后来达到原始真理。但如果这些假设始终没有得到说明，开端仍然只是一个假设；承认其暂定性，还不足以消除它在根据上的问题。

# 六、哲学的需要：思维返回自身并克服矛盾（§11—§12）

## 1. 精神在不同活动中面对不同对象（§11）

| 精神活动 | 所面对的对象形式 |
| --- | --- |
| 感觉、直观 | *感性*（Sinnlichkeit）事物 |
| 想象、表象 | 形象 |
| 意志 | 目的 |
| 思维对自身的认识 | 思想本身 |

精神还要求把思维自身作为对象，从而回到自身最内在的活动之中。这种需要构成哲学产生的内在动力。

但思维一开始会把自己的规定固定起来，使它们彼此对立，陷入矛盾。精神原本希望在思想中找到自身，却又在这些对立中失去安定。

## 2. 思维具有辩证的本性

黑格尔认为，思维作为知性，会由于自身规定的固定化而陷入矛盾。理解这一过程，是逻辑学的重要任务。

哲学需要坚持思想对自身的要求，在思想内部考察并解决矛盾。如果把矛盾视为理性彻底失败的证据，转而只向情感、信仰或所谓*直接知识*（unmittelbares Wissen）寻求安慰，就可能形成对理性的厌恶，即“*理性恨*（Misologie）”。

*辩证*（dialektisch）思维由此要求追问：矛盾如何产生？相对立的规定各有什么根据和限度？它们如何在更充分的联系中得到理解？

## 3. 经验是出发点，思维须超出其直接形式（§12）

哲学的内在需要来自思维，其发生的出发点则是经验。这里的经验包括直接意识，也包括从经验中作出的推论。

经验刺激思维，使它超出直接感受和表象，进入普遍思想的领域。但如果思想只获得一个抽象的普遍原则，便可能停留在空泛的满足中，不能展开特殊内容。

例如，只反复用一个统一公式解释所有具体事物，容易使具体差别失去意义。早期哲学中，爱利亚学派以“存在”为原则，赫拉克利特以“*变易*（Werden）”为原则。问题在于普遍原则能否继续展开为丰富的规定。

## 4. 直接性与间接性

*直接性*（Unmittelbarkeit）指内容被直接把握、仿佛无需经过其他环节；*间接性*（Vermittlung）或“*中介*（Vermittlung）”指通过其他规定、否定和过渡而达到某个内容。

二者可以区别，却不能被绝对分离：

- 从经验出发并超出经验的直接形式，已经包含中介。
- 通过中介得到的思想规定，又可以作为一个直接的结果被把握。
- 思维的*先天性*（das Apriorische），也包含其自身内部的中介活动，不能简单等同于毫无中介。

所以，哲学从经验发生，与哲学要求在思想内部说明必然联系，可以同时成立。前者着眼于认识的发生，后者着眼于认识的根据。

## 5. 经验科学推动哲学的具体发展

经验科学对哲学的作用主要有两个方面：

1. **准备内容**：把个别材料整理为规律和分类，使哲学获得已经经过思维加工的内容。
2. **推动展开**：丰富的特殊内容迫使思想超出抽象的普遍性，发展自身的具体规定。

哲学吸收这些内容时，还要改变其仅仅“如此被发现”的形式，使之进入概念的必然联系。相应地，经验科学获得的内容也在哲学中取得新的理解。

# 七、哲学史：同一哲学的不同发展阶段（§13）

## 1. 哲学史的表面与内在联系

从外部看，哲学史呈现为不同时代、不同人物提出的众多体系，它们似乎各有原则、彼此冲突。

黑格尔则把这一历史理解为思维认识自身的过程：精神把自己已有的规定作为对象，在认识这些规定时超出原来的阶段，从而达到新的高度。

不同哲学因而可以被理解为同一哲学发展的不同阶段，其特殊原则是一个思想整体中的不同环节。

## 2. “水果”与具体哲学的例子

一个人想吃水果，却拒绝樱桃、葡萄和梨，理由是它们各自只是樱桃、葡萄和梨，没有哪一个是“水果本身”。这种要求把*普遍者*（das Allgemeine）放到了特殊者之外，并把普遍者也当成了一个并列的特殊事物。

同样，仅仅因为存在不同哲学，就断言它们都只是“某一种哲学”，因而没有哲学，也混淆了普遍与特殊的关系。

哲学的普遍性，需要在其具体的发展形态中理解。

## 3. 后出的哲学如何包含先前哲学

在黑格尔的发展观点中，一个充分发展的哲学应当吸收先前哲学的原则，认识这些原则的限度，并把它们作为自身的环节保存下来。

因此，“最后的哲学最丰富”有一个重要条件：它确实承担并实现了此前思想发展的成果。单凭出现得较晚，不能证明一个学说更充分。

这里所说的包含，也要求各原则之间形成有根据的联系；把相互无关的主张汇集起来，还不能形成哲学体系。

# 八、哲学的体系：圆圈与圆圈组成的圆圈（§14—§16）

## 1. 真理要求成为体系（§14）

哲学史在时间中呈现的思想发展，在哲学体系中表现为思想规定自身的内在联系。

黑格尔说真理是*具体*（konkret）的，意指真理包含差别、联系和发展的环节。只有在这些环节的有机联系中，个别规定的意义与根据才得到充分说明。

孤立命题即使表达了某种洞见，脱离整体之后，仍可能只是个人确信或未经说明的假设。哲学因此要求说明：各个规定怎样彼此联系、怎样过渡，以及为什么共同构成一个整体。

## 2. 每一部分本身也是整体（§15）

哲学的每一个部分，都以某种特殊规定表现整个哲学理念，因而本身也形成一个相对完整的圆圈。

但这种特殊规定同时又具有界限。随着内容展开，这个部分会超出自身的限制，过渡到更广的联系中。整个哲学因此可被称为“圆圈组成的圆圈”。

这一比喻包含两层意义：

- 每一部分具有自身的完整联系。
- 每一部分又是整个体系的必要环节，并通过过渡与其他部分相联系。

## 3. 哲学全书与一般百科全书（§16）

| 比较方面 | 一般百科全书 | 哲学全书 |
| --- | --- | --- |
| 内容的组织 | 按外部需要汇集知识、学科和材料 | 按理念的内在联系展开 |
| 学科之间的联系 | 可以只是排列、并列或汇编 | 要求说明各部分的必然联系 |
| 整体的统一 | 主要依赖编辑安排 | 来自内容本身的有机联系 |
| 阐述的范围 | 可以收入大量专门知识 | 侧重各部分的开端与基本概念 |

哲学全书篇幅有限，不以详尽收录全部特殊知识为目标。对特殊科学，需要区分其理性内容与其依赖既定材料、规定或权威的实证成分。

## 4. 特殊学科中的实证成分

这里的“*实证性*（positiv；名词化为 das Positive）”不宜直接按今天“有实验验证”的意思理解。它涉及内容或形式依赖既定事实、外在规定和未经进一步说明的前提。

§16首先区分了单纯的知识汇集、完全依赖任意规定的学问，以及具有理性基础但仍包含实证成分的科学。对于后一类，可进一步分辨三种情况：

1. **内容上的*偶然性*（Zufälligkeit）**：一般原则应用到具体事物时，需要接受不能由概念唯一确定的事实或安排。例如，法制和税制中的某些具体规定。
2. **形式上的*有限性*（Endlichkeit）**：把有限范畴直接作为最终有效的规定，未说明其界限及其向更高联系的过渡。
3. **根据上的不足**：结论依赖偶然推论、情感、信仰、权威或直接知觉，尚未形成充分的概念论证。

这些区分也意味着，应当具体考察各门学科内部的认识方式，不能只凭学科名称就把它的所有内容一并排除。哲学所吸收的是其中能够在概念上得到把握的理性环节。

经验形式的研究也可能深刻地把握对象的内在次序。因而，经验研究的价值与概念论证是否充分，是需要分别考察的问题。

# 九、回到开端：起点必须成为结果（§17）

## 1. 哲学也从一个尚未展开的立场进入

哲学似乎也需要像其他科学一样预设自己的对象。例如，数学可以以数或空间为对象，哲学似乎就预设思维的存在。

但在哲学中，思维自由地把自己作为对象，所研究的正是自身的活动和规定。它所采取的最初立场，也必须在研究中得到说明。

## 2. 开端的根据在整个过程中得到说明

哲学的开端在最初尚未充分展开，因而看起来只是一个直接接受的立场。随着体系发展，这个立场必须转化为结果：哲学通过整个认识过程，返回并理解自身的开端。

可以把这一结构表示为：

**最初进入的立场 → 思想规定的展开 → 对整个过程及其开端的理解。**

返回开端时，开端已经包含了展开过程所获得的规定。它的意义因而不同于最初未经说明的状态。

## 3. 学习的起点与体系的根据

对于开始学习哲学的人，必须从某处进入；但对于充分展开的哲学体系，其根据不能永远停留在一个外在的、未经说明的前提上。

所以，体系呈现为一个返回自身的圆圈。§1提出的困难，在§17获得了一个体系性的回应：**开端所缺少的说明，需要通过哲学自身的展开来完成；哲学也必须认识自己何以能够成为哲学。**

# 十、补充：哲学体系的三个部分（§18）

本节据[导言§18原文](https://www.marxists.org/reference/archive/hegel/works/sl/slintro.htm)补充。

| 部分 | 研究的内容 |
| --- | --- |
| 逻辑学 | *自在自为*（an und für sich）的理念 |
| 自然哲学 | 处于*他在*（Anderssein）形式中的理念 |
| 精神哲学 | 从他在返回自身的理念 |

这一区分只是进入体系前的预先提示，其根据需要由体系本身展开。三个部分各自研究其内容，同时也说明自身如何向其他环节过渡，不能仅按三个并列学科来理解。

# 论述线索

1. **开端的困难**：哲学要求说明前提，又必须有所开始。
2. **认识的形式**：把经验和表象的内容提升到思想与概念。
3. **思辨的需要**：进一步说明对象及其规定之间的必然联系。
4. **发展的动力**：思维的内在需要与经验科学的丰富内容共同推动哲学展开。
5. **体系的要求**：各个规定构成有机整体，开端最终在整个过程中得到理解。
