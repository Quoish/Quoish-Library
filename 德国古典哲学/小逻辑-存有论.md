本篇承接[[小逻辑-逻辑学的初步规定]]，整理《小逻辑》§84—§111的*存有论*（Die Lehre vom Sein）。这一部分从最初尚无具体内容的*存有*（Sein，亦译“存在”或“有”）出发，考察它如何取得*规定性*（Bestimmtheit），并通过这些规定自身的展开，过渡到*本质*（Wesen）。

# 一、存有论的地位与三个阶段（§84—§85）

## 1. 存有是自在的概念（§84）

黑格尔把存有称为*自在的概念*（der Begriff an sich）。这里的*概念*（Begriff）不能只按事物名称或分类标签来理解；“自在”表示它的规定尚未充分展开、自觉呈现。

存有领域的特点是*直接性*（Unmittelbarkeit）：各个规定首先直接呈现为“是”，彼此有别时，又表现为各自独立的东西。

这些规定进一步展开时，呈现为从一个规定*过渡*（Übergehen）到另一个规定。这个过程具有两个相互联系的方向：

- **向外展开**：原先尚未展开的内容取得明确的规定。
- **向内深入**：最初的直接性逐渐被*扬弃*（Aufheben），各个规定的内在联系逐渐显露。

因此，存有论的终点也就是对存有的直接形式的超出，进入本质领域。

## 2. 质、量与尺度（§85）

| 阶段 | 基本规定 | 理解要点 |
| --- | --- | --- |
| *质*（Qualität） | 与事物的存有直接同一的规定性 | 失去这种质，事物就不再是原来的事物 |
| *量*（Quantität） | 对事物的存有相对外在、无差别的规定性 | 在一定范围内增减，事物仍保持原来的质 |
| *尺度*（Maß，亦译“度”） | 质与量的统一，即具有质的定量 | 量的变化具有保持某种质的界限，越过界限便涉及质的改变 |

“房屋更大或更小，仍然是房屋”，可以帮助理解量相对于质的外在性。但这一无差别关系有其范围，尺度将进一步揭示其界限。

这些规定可以被看作对*绝对者*（das Absolute）的逐步说明。黑格尔同时提醒：如果仅仅把“绝对者”作为现成主词，再从外部为它添加谓词，主词本身仍然没有得到说明。真正需要理解的是规定自身的内容及其发展。

逻辑展开经常包含直接规定、区别与对立、返回统一等环节。其根据需要从具体内容中展示，不能只套用“正—反—合”的固定格式。

# 二、质的开端：纯有、纯无与变易（§86—§89）

## 1. 为什么从纯有开始（§86）

*纯有*（reines Sein，亦称“纯粹存有”）是一切具体规定尚未展开时的单纯直接性。最初的开端尚不能以另一个已经得到规定的对象作为前提，否则还需要追问那个对象的根据。

因此，纯有不能被直接理解为：

- 某一种具体物质。
- 眼前某个感性对象。
- 一个已经包含各种属性的上帝观念。
- 具有丰富心理内容的“我”。

这些内容都已经包含差别、联系和*中介*（Vermittlung），超出了最初开端的单纯性。

即使以 $A=A$ 或 $I=I$ 为开端，也不能仅凭它们看起来确定，就认为它们毫无前提。只要其中已经包含两个环节及其联系，就需要说明这种联系；若只取其完全没有差别的直接内容，则仍然只是纯有。

这里的“没有规定”首先指最初尚未展开规定的状态，须与经过复杂认识之后再抽去各种内容所得的空泛概括加以区别。

## 2. 纯有为什么过渡为纯无（§87）

思考纯有时，不能再给它添上某种质、某种大小、某种位置或某种用途。否则，所思考的就已经是一个确定的事物。

但如果完全没有任何规定，在纯有中也就找不到能够将它与*纯无*（reines Nichts）区别开的内容。

这里所说的无，同样没有具体内容。它不等于某个事物的缺席，也不等于空房间、真空等已经具有确定规定的状态。

纯有与纯无因而都表现为没有规定的空洞直接性。试图用某个确定属性把纯有固定下来，恰恰会使它失去“纯有”的最初含义。

这也说明，不能把纯有理解为“全部丰富内容的总和”，把纯无理解为“全部内容的丧失”。一旦只说“一切都是”，却不再说它们是什么，丰富的区别也就被抽去了。

## 3. 变易是有与无的统一（§88）

纯有不能停留为与纯无完全隔绝的一端，纯无也不能保持为一个与有完全隔绝的空无。二者的*真理*（Wahrheit），即能够包含并说明这两个片面规定的更充分规定，是*变易*（Werden，亦译“变”或“生成”）。

变易包含有与无的相互过渡：

| 方向 | 表现 |
| --- | --- |
| 从无到有 | *发生*（Entstehen） |
| 从有到无 | *消逝*（Vergehen） |

这种统一保留着差别。只说“有与无是同一个东西”，容易漏掉二者的对立和过渡；只坚持二者完全不同，又无法把握它们在纯粹无规定性中的联系。

变易因此具有内在的不安定性。有与无在其中既有区别，又不断失去各自孤立的直接状态。

黑格尔称变易为第一个*具体的*（konkret）思想。这里的“具体”指一个规定内部包含着差别及其统一，并不以能够画出感性图像为条件。

## 4. 为什么不能用日常的“有无”直接反驳

“有房屋与没有房屋当然不同”，说的是具有具体内容和现实关系的事物；纯有与纯无则尚未包含房屋的用途、结构、所有权等规定。

如果用“我的财产是否存在”来代替纯有与纯无的问题，讨论的内容就已经改变了。因此，在分析这一开端时，需要保持思想规定自身的层次。

同样，“无中不能生有”若被当作绝对原则，只允许某物始终从同样的某物中出现，就可能把真正的发生与消逝排除掉，只留下抽象的*同一性*（Identität）。

## 5. 扬弃为什么同时包含否定与保存

德文 aufheben 同时具有取消、废除和保存等含义。逻辑中的扬弃也包含这两个方向：

1. 一个规定作为孤立、最终真理的地位受到否定。
2. 它有根据的内容被保存为更充分整体中的*环节*（Moment）。

例如，有与无在变易中不再各自独立，却仍构成变易的内容。这里的否定不等于把它们彻底抹去。

这也可以帮助理解哲学史上的发展：一个原则被后来哲学超出时，可以失去其独占真理的地位，同时仍被保存。相关关系见[[小逻辑-哲学的开端]]中关于哲学史与体系的讨论。

## 6. 变易为什么形成定在（§89）

变易中的有与无都只是不断消失的环节。当它们的相互消失也被把握为一个结果时，便得到一个包含否定的存有，即*定在*（Dasein，亦译“实有”“此有”）。

定在可以初步理解为：有了规定的存有，或者“是某种东西”。它已经经过变易，却以一种直接统一的形式呈现。

从变易得到的结果仍有确定内容：有与无被保存于其中，原先的孤立形式则被取消。若一发现矛盾，就断言“所以什么都没有”，便只抓住了否定方面，遗漏了结果的内容。

# 三、定在：实在性、界限与无限（§90—§95）

## 1. 定在的规定性就是质（§90）

定在具有一个与其存有直接统一的规定，这就是质。定在作为这样一个有规定的东西，是*某物*（Etwas）。

因此，质在这里不能只按优劣程度来理解。它首先回答：某物是什么，凭什么区别于别的东西。

一种事物的质被取消时，它就不再以原来的规定存在。量的增减则可以暂时不改变这一点。这是质与量的初步差别。

## 2. 实在性与否定性（§91）

质作为一个存在着的规定，具有肯定方面，称为*实在性*（Realität）。同时，成为这个东西，也意味着不成为另一个东西，其中包含*否定*（Negation）。

由否定所表达的*否定性*（Negativität），在这里已经不能只理解为外部的否认。它进入事物自己的规定之中，使某物具有明确的区别。

例如，某块土地是草地，就包含它在这一规定下不是树林或池塘。这样的否定具有内容，不能等同于开端处毫无规定的纯无。

这里的 Realität 也须与*现实性*（Wirklichkeit）区别。实在性在本节首先指质作为存在着的规定；现实性则是之后在本质论中展开的更充分范畴，不能仅因二者在日常语言中相近就混同。

## 3. 自在存在与为他存在

某物具有自身的规定，又因其规定而与别的东西发生区别和联系：

| 规定 | 含义 |
| --- | --- |
| *自在存在*（Ansichsein） | 相对于与他物的关系，把握某物自身的存有和规定 |
| *为他存在*（Sein-für-Anderes） | 某物的规定包含着与他物的关系 |
| *他在*（Anderssein） | 否定以另一个定在、另一个某物的形式表现出来 |

如果把自在存在从一切规定和关系中抽离出来，就又只剩空洞的存有。反过来，与他物的关系也不是无缘无故附加于某物之外的东西，因为这种关系已经与某物自身的规定相联系。

## 4. 界限构成某物自身（§92）

定在的规定性，同时就是它的*界限*（Grenze）。界限使某物成为它自己，也把它与他物区别开来。

需要分别考察质的界限和量的界限：

- “这块土地有多大”首先涉及量的界限。
- “这块土地是草地”涉及它是什么，即质的界限。

质的界限贯穿某物的整个规定，不能只理解为围在它外面的边线。

某物具有界限，就具有*有限性*（Endlichkeit）。它的规定包含着与他物的关系，因而也具有*可变性*（Veränderlichkeit）。有限事物的变化，可以从其自身的规定和关系中理解，不能只看作从外部偶然加上的遭遇。

## 5. 某物与他物的无穷递进（§93—§94）

某物变成另一个东西，这个他物自身也是某物，因而还会变成另一个东西。若只把这些阶段看作彼此外在，就得到：

**某物 → 他物 → 又一个他物 → 再一个他物 → ……**

每次似乎超出了前一个有限者，实际又到达另一个有限者。这样的超出反复发生，却没有改变有限者与他物彼此对立的结构。

黑格尔称之为*恶无限*（schlechte Unendlichkeit，亦称“坏无限”或“否定的无限”）。这里的“恶”指其概念上的片面性，并非道德评价。

如果把无限放在有限者永远达不到的彼岸，那么这个无限本身又被有限者限制着：它只是与有限者并列的另一端。

## 6. 真无限：在他物中返回自身（§95）

*真无限*（wahrhafte Unendlichkeit）的要点，在于某物在向他物的过渡中与自身发生关系。

某物是他物的他物，而他物本身也是某物。若把握的是这一整个关系，过渡就不再只是离开自身、到达一个毫不相关的外部对象。

这种在他物中与自身相联系，可以称为*否定之否定*（Negation der Negation）：有限者的孤立独立性受到否定，彼此对立的规定进入一个返回自身的关系。

这并不意味着两个具体事物的一切性质相同，也不意味着所有差别都被取消。这里考察的是“某物—他物”这一规定关系自身的结构。

真无限由此引出*自为存在*（Fürsichsein）：存有通过否定之否定而与自身相联系。

| 对比 | 恶无限 | 真无限 |
| --- | --- | --- |
| 对有限者的处理 | 越出一个界限，重新遇到另一个界限 | 把握有限规定之间的过渡及返回自身的联系 |
| 无限的位置 | 永远在尚未到达的彼岸 | 在他物中与自身相联系 |
| 基本形式 | 无穷的外在递进 | 包含差别的自我关系 |

# 四、自为存在、一与多（§96—§98）

## 1. 自为存在是质的完成（§96）

自为存在仍包含存有和定在，却把它们保存在返回自身的联系中。它的规定不再只是某物与一个外在他物的有限区别。

“我”可以作为理解这种关系的一个例子：意识面对不同内容，同时又把这些内容把握为“我的”，从差别中返回统一的自我关系。这个例子所说明的是自我关系，不能用一个人的全部心理特征直接替代逻辑规定。

自为存在所体现的*观念性*（Idealität，亦译“理想性”），表示有限定在不再被当作最终独立的东西，而作为被扬弃的环节获得意义。

因此，观念性不是与实在性并列的另一种现成东西，也不是日常所说的理想生活或主观幻想。它以实在性为自己的内容，表达实在性的孤立直接形式被超出的关系。

## 2. 从一到多：排斥（§97）

自为存在以直接的形式出现时，是排斥他物、与自身相同的*一*（das Eins）。

但“一”并非完全没有关系。它通过排除来规定自身，这种否定的自我关系表现为*排斥*（Repulsion）：一把自己规定为许多个一。

这里所讨论的是“一”这一规定如何包含多，不能只预先摆好许多个对象，再把其中一个称为“一”。每个被排斥出来的一，又具有同样的一的规定，由此形成*多*（die Vielen）。

## 3. 多个一的联系：吸引（§98）

多个一彼此排斥，但它们都具有相同的“一”的规定。排斥同时也是它们彼此之间的联系，因此包含其另一环节——*吸引*（Attraktion）。

排斥与吸引在这里是逻辑规定。只把它们列为两种现成的物理力，还没有说明它们为何具有内在联系。

黑格尔据此批评古代原子论：它肯定彼此排斥的许多个一，却容易把它们的结合交给偶然性。即使研究从原子出发，也仍然使用了关于一、多、空无及联系的思想规定。

## 4. 质为什么过渡为量

当多个一既被区别、又作为相同的一而相联系时，一的排他独立性便受到扬弃。规定性开始表现为对存有相对无差别的规定，即量。

**量是被扬弃的质。** 这里保留着有规定的存有，但这个规定的增减不再立即取消事物原有的质。

这说明质与量的联系来自前面规定的展开；仅仅说“任何东西都有质，也都有量”，还没有说明两者之间的过渡。
