本篇承接[[小逻辑-逻辑学的初步规定]]，整理《小逻辑》§84—§111的*存有论*（Die Lehre vom Sein）。这一部分从最初尚无具体内容的*存有*（Sein，亦译“存在”或“有”）出发，考察它如何取得*规定性*（Bestimmtheit），并通过这些规定自身的展开，过渡到*本质*（Wesen）。

# 一、存有论的地位与三个阶段（§84—§85）

## 1. 存有是自在的概念（§84）

黑格尔把存有称为*自在的概念*（der Begriff an sich）。这里的*概念*（Begriff）不能只按事物名称或分类标签来理解；“自在”表示它的规定尚未充分展开、明确呈现。

存有领域的特点是*直接性*（Unmittelbarkeit）：各个规定首先直接呈现为“是”，彼此有别时，又表现为各自独立的东西。

这些规定进一步展开时，呈现为从一个规定*过渡*（Übergehen）到另一个规定。这个过程具有两个相互联系的方向：

- **向外展开**：原先尚未展开的内容取得明确的规定。
- **向内深入**：最初的直接性逐渐被*扬弃*（Aufheben），各个规定的内在联系逐渐显露。

因此，存有论的终点也就是对存有的直接形式的超出，进入本质领域。

## 2. *质*（Qualität）、*量*（Quantität）与*尺度*（Maß，亦译“度”）（§85）

| 阶段  | 基本规定                               | 理解要点                                 |
| --- | ---------------------------------- | ------------------------------------ |
| 质   | 与事物的存有直接同一的规定性                     | 失去这种质，事物就不再是原来的事物                    |
| 量   | 对事物的存有相对外在、*无差别*（gleichgültig）的规定性 | 在一定范围内增减，事物仍保持原来的质                   |
| 尺度  | 质与量的统一，即具有质的*定量*（Quantum）          | 量的变化具有保持某种质的*界限*（Grenze），越过界限便涉及质的改变 |

“房屋更大或更小，仍然是房屋”，可以帮助理解量相对于质的*外在性*（Äußerlichkeit）。但这一无差别关系有其范围，尺度将进一步揭示其界限。

这些规定可以被看作对*绝对者*（das Absolute）的逐步说明。黑格尔同时提醒：如果仅仅把“绝对者”作为现成主词，再从外部为它添加谓词，主词本身仍然没有得到说明。真正需要理解的是规定自身的内容及其发展。

逻辑展开经常包含直接规定、区别与对立、返回统一等环节。其根据需要从具体内容中展示，不能只套用“正—反—合”的固定格式。

# 二、质的开端：*纯有*（reines Sein，亦称“纯粹存有”）、*纯无*（reines Nichts）与*变易*（Werden，亦译“变”或“生成”）（§86—§89）

## 1. 为什么从纯有开始（§86）

纯有是一切具体规定尚未展开时的单纯直接性。最初的开端尚不能以另一个已经得到规定的对象作为前提，否则还需要追问那个对象的根据。

因此，纯有不能被直接理解为：

- 某一种具体物质。
- 眼前某个感性对象。
- 一个已经包含各种属性的上帝观念。
- 具有丰富心理内容的“我”。

这些内容都已经包含差别、联系和*中介*（Vermittlung），超出了最初开端的*单纯性*（Einfachheit）。

即使以 $A=A$ 或 $I=I$ 为开端，也不能仅凭它们看起来确定，就认为它们毫无前提。只要其中已经包含两个环节及其联系，就需要说明这种联系；若只取其完全没有差别的直接内容，则仍然只是纯有。

这里的“没有规定”首先指最初尚未展开规定的状态，须与经过复杂认识之后再抽去各种内容所得的空泛概括加以区别。

## 2. 纯有为什么过渡为纯无（§87）

思考纯有时，不能再给它添上某种质、某种大小、某种位置或某种用途。否则，所思考的就已经是一个确定的事物。

但如果完全没有任何规定，在纯有中也就找不到能够将它与纯无区别开的内容。

这里所说的无，同样没有具体内容。它不等于某个事物的缺席，也不等于空房间、真空等已经具有确定规定的状态。

纯有与纯无因而都表现为没有规定的空洞直接性。试图用某个确定属性把纯有固定下来，恰恰会使它失去“纯有”的最初含义。

这也说明，不能把纯有理解为“全部丰富内容的总和”，把纯无理解为“全部内容的丧失”。一旦只说“一切都是”，却不再说它们是什么，丰富的区别也就被抽去了。

## 3. 变易是有与无的统一（§88）

纯有不能停留为与纯无完全隔绝的一端，纯无也不能保持为一个与有完全隔绝的空无。二者的*真理*（Wahrheit），即能够包含并说明这两个片面规定的更充分规定，是变易。

变易包含有与无的相互过渡：

| 方向 | 表现 |
| --- | --- |
| 从无到有 | *发生*（Entstehen） |
| 从有到无 | *消逝*（Vergehen） |

这种统一保留着差别。只说“有与无是同一个东西”，容易漏掉二者的对立和过渡；只坚持二者完全不同，又无法把握它们在纯粹无规定性中的联系。

变易因此具有内在的不安定性。有与无在其中既有区别，又不断失去各自孤立的直接状态。

黑格尔称变易为第一个*具体*（konkret）的思想。这里的“具体”指一个规定内部包含着差别及其统一，并不以能够画出感性图像为条件。

## 4. 为什么不能用日常的“有无”直接反驳

“有房屋与没有房屋当然不同”，说的是具有具体内容和现实关系的事物；纯有与纯无则尚未包含房屋的用途、结构、所有权等规定。

如果用“我的财产是否存在”来代替纯有与纯无的问题，讨论的内容就已经改变了。因此，在分析这一开端时，需要保持*思想规定*（Denkbestimmung）自身的层次。

同样，“无中不能生有”若被当作绝对原则，只允许某物始终从同样的某物中出现，就可能把真正的发生与消逝排除掉，只留下*抽象*（abstrakt）的*同一性*（Identität）。

## 5. 扬弃为什么同时包含*否定*（Negation）与保存

德文 aufheben 同时具有取消、废除和保存等含义。逻辑中的扬弃也包含这两个方向：

1. 一个规定作为孤立、最终真理的地位受到否定。
2. 它有根据的内容被保存为更充分整体中的*环节*（Moment）。

例如，有与无在变易中不再各自独立，却仍构成变易的内容。这里的否定不等于把它们彻底抹去。

这也可以帮助理解哲学史上的发展：一个原则被后来哲学超出时，可以失去其独占真理的地位，同时仍被保存。相关关系见[[小逻辑-哲学的开端]]中关于哲学史与体系的讨论。

## 6. 变易为什么形成*定在*（Dasein，亦译“实有”“此有”）（§89）

变易中的有与无都只是不断消失的环节。当它们的相互消失也被把握为一个结果时，便得到一个包含否定的存有，即定在。

定在可以初步理解为：有了规定的存有，或者“是某种东西”。它已经经过变易，却以一种直接统一的形式呈现。

从变易得到的结果仍有确定内容：有与无被保存于其中，原先的孤立形式则被取消。若一发现矛盾，就断言“所以什么都没有”，便只抓住了否定方面，遗漏了结果的内容。

# 三、定在：*实在性*（Realität）、界限与无限（§90—§95）

## 1. 定在的规定性就是质（§90）

定在具有一个与其存有直接统一的规定，这就是质。定在作为这样一个有规定的东西，是*某物*（Etwas）。

因此，质在这里不能只按优劣程度来理解。它首先回答：某物是什么，凭什么区别于别的东西。

一种事物的质被取消时，它就不再以原来的规定存在。量的增减则可以暂时不改变这一点。这是质与量的初步差别。

## 2. 实在性与*否定性*（Negativität）（§91）

质作为一个存在着的规定，具有肯定方面，称为实在性。同时，成为这个东西，也意味着不成为另一个东西，其中包含否定。

由否定所表达的否定性，在这里已经不能只理解为外部的否认。它进入事物自己的规定之中，使某物具有明确的区别。

例如，某块土地是草地，就包含它在这一规定下不是树林或池塘。这样的否定具有内容，不能等同于开端处毫无规定的纯无。

这里的 Realität 也须与*现实性*（Wirklichkeit）区别。实在性在本节首先指质作为存在着的规定；现实性则是之后在本质论中展开的更充分*范畴*（Kategorie），不能仅因二者在日常语言中相近就混同。

## 3. *自在存在*（Ansichsein）与*为他存在*（Sein-für-Anderes）

某物具有自身的规定，又因其规定而与别的东西发生区别和联系：

| 规定 | 含义 |
| --- | --- |
| 自在存在 | 相对于与他物的关系，把握某物自身的存有和规定 |
| 为他存在 | 某物的规定包含着与他物的关系 |
| *他在*（Anderssein） | 否定以另一个定在、另一个某物的形式表现出来 |

如果把自在存在从一切规定和关系中抽离出来，就又只剩空洞的存有。反过来，与他物的关系也不是无缘无故附加于某物之外的东西，因为这种关系已经与某物自身的规定相联系。

## 4. 界限构成某物自身（§92）

定在的规定性，同时就是它的界限。界限使某物成为它自己，也把它与他物区别开来。

需要分别考察质的界限和量的界限：

- “这块土地有多大”首先涉及量的界限。
- “这块土地是草地”涉及它是什么，即质的界限。

质的界限贯穿某物的整个规定，不能只理解为围在它外面的边线。

某物具有界限，就具有*有限性*（Endlichkeit）。它的规定包含着与他物的关系，因而也具有*可变性*（Veränderlichkeit）。有限事物的变化，可以从其自身的规定和关系中理解，不能只看作从外部偶然加上的遭遇。

## 5. 某物与他物的无穷递进（§93—§94）

某物变成另一个东西，这个他物自身也是某物，因而还会变成另一个东西。若只把这些阶段看作彼此外在，就得到：

**某物 → 他物 → 又一个他物 → 再一个他物 → ……**

每次似乎超出了前一个有限者，实际又到达另一个有限者。这样的超出反复发生，却没有改变有限者与他物彼此对立的结构。

黑格尔称之为*恶无限*（schlechte Unendlichkeit，亦称“坏无限”或“否定的无限”）。这里的“恶”指其概念上的*片面性*（Einseitigkeit），并非道德评价。

如果把无限放在有限者永远达不到的彼岸，那么这个无限本身又被有限者限制着：它只是与有限者并列的另一端。

## 6. *真无限*（wahrhafte Unendlichkeit）：在他物中返回自身（§95）

真无限的要点，在于某物在向他物的过渡中与自身发生关系。

某物是他物的他物，而他物本身也是某物。若把握的是这一整个关系，过渡就不再只是离开自身、到达一个毫不相关的外部对象。

这种在他物中与自身相联系，可以称为*否定之否定*（Negation der Negation）：有限者的孤立*独立性*（Selbständigkeit）受到否定，彼此对立的规定进入一个返回自身的关系。

这并不意味着两个具体事物的一切性质相同，也不意味着所有差别都被取消。这里考察的是“某物—他物”这一规定关系自身的结构。

真无限由此引出*自为存在*（Fürsichsein）：存有通过否定之否定而与自身相联系。

| 对比 | 恶无限 | 真无限 |
| --- | --- | --- |
| 对有限者的处理 | 越出一个界限，重新遇到另一个界限 | 把握有限规定之间的过渡及返回自身的联系 |
| 无限的位置 | 永远在尚未到达的彼岸 | 在他物中与自身相联系 |
| 基本形式 | 无穷的外在递进 | 包含差别的自我关系 |

# 四、自为存在、*一*（das Eins）与*多*（die Vielen）（§96—§98）

## 1. 自为存在是质的完成（§96）

自为存在仍包含存有和定在，却把它们保存在返回自身的联系中。它的规定不再只是某物与一个外在他物的有限区别。

“我”可以作为理解这种关系的一个例子：意识面对不同内容，同时又把这些内容把握为“我的”，从差别中返回统一的自我关系。这个例子所说明的是自我关系，不能用一个人的全部心理特征直接替代逻辑规定。

自为存在所体现的*观念性*（Idealität，亦译“理想性”），表示有限定在不再被当作最终独立的东西，而作为被扬弃的环节获得意义。

因此，观念性不是与实在性并列的另一种现成东西，也不是日常所说的理想生活或主观幻想。它以实在性为自己的内容，表达实在性的孤立直接形式被超出的关系。

## 2. 从一到多：*排斥*（Repulsion）（§97）

自为存在以直接的形式出现时，是排斥他物、与自身相同的一。

但“一”并非完全没有关系。它通过排除来规定自身，这种否定的自我关系表现为排斥：一把自己规定为许多个一。

这里所讨论的是“一”这一规定如何包含多，不能只预先摆好许多个对象，再把其中一个称为“一”。每个被排斥出来的一，又具有同样的一的规定，由此形成多。

## 3. 多个一的联系：*吸引*（Attraktion）（§98）

多个一彼此排斥，但它们都具有相同的“一”的规定。排斥同时也是它们彼此之间的联系，因此包含其另一环节——吸引。

排斥与吸引在这里是逻辑规定。只把它们列为两种现成的物理力，还没有说明它们为何具有内在联系。

黑格尔据此批评古代原子论：它肯定彼此排斥的许多个一，却容易把它们的结合交给偶然性。即使研究从原子出发，也仍然使用了关于一、多、空无及联系的思想规定。

## 4. 质为什么过渡为量

当多个一既被区别、又作为相同的一而相联系时，一的排他独立性便受到扬弃。规定性开始表现为对存有相对无差别的规定，即量。

**量是被扬弃的质。** 这里保留着有规定的存有，但这个规定的增减不再立即取消事物原有的质。

这说明质与量的联系来自前面规定的展开；仅仅说“任何东西都有质，也都有量”，还没有说明两者之间的过渡。

# 五、量：*纯量*（reine Quantität）、定量与*度*（Grad）（§99—§106）

## 1. 纯量：对规定性的无差别（§99）

纯量是规定性已不再与存有直接同一的存有。某物的量可以变化，而它在一定范围内仍保持原有的质。

因此，“大小可以增加或减少”能够提示量的一个特点，但还没有说明量从何而来。增减本身已经预设了量的概念，哲学还需要说明这一规定在前面发展中的根据及其*必然性*（Notwendigkeit）。

量也不能被提升为解释一切区别的唯一原则。自然和*精神*（Geist）中的对象，都可以有数量方面，但把握它们还需要认识各自的质及其联系。

“更大”“更多”“更强”并不自动等同于对对象本身的充分认识。

## 2. *连续量*（kontinuierliche Größe）与*离散量*（diskrete Größe）（§100）

量包含相互区别又相互联系的两个环节：

| 环节                 | 基本意义              | 理解例子            |
| ------------------ | ----------------- | --------------- |
| *连续性*（Kontinuität） | 多个一具有相同规定，在其中保持联系 | 一段空间可以被看作一个连续整体 |
| *离散性*（Diskretion）  | 一彼此区别，表现为可以分别计数的多 | 一群人可以按人数来计数     |

侧重前者时，量表现为连续量；侧重后者时，则表现为离散量。

二者不能被理解为两类完全不具有对方环节的量。连续的空间可以划分为不同长度单位；计数的一群人又以同一种*单位*（Einheit）或共同规定被联系起来。

连续性中已经包含多，离散性中也已经包含同一的单位。这一关系承接前面吸引与排斥的统一。

## 3. 定量与*数*（Zahl）（§101—§102）

量取得明确的界限时，成为定量。定量回答“有多少”，是量的有规定的形式。

定量在数中获得充分的规定。数包含两个可以区别的环节：

- *数目*（Anzahl）：有多少个一，体现离散方面。
- 单位：这些一作为同一单位被计数，体现连续方面。

例如，“五个单位”同时包含每一个单位的同一规定，以及这些单位的数目。数是两个方面的统一。

黑格尔据此尝试从单位与数目的关系理解不同运算：

| 运算 | 对数的处理方式 | 简例 |
| --- | --- | --- |
| 加法 | 把已经形成的、一般而言不同的数相加 | $2+3=5$ |
| 乘法 | 把相等的数作为一个单位，计算这样的单位有多少个 | $3+3+3+3=4\times3$ |
| 平方与乘方 | 在平方中，所取单位与其数目相等；进一步重复自身相乘，形成乘方 | $3\times3=3^2$ |

减法、除法和开方则分别从相应的逆向关系理解。

这里着重考察数的逻辑构成及运算之间的联系。它与现代数学按公理定义运算的方式，具有不同的阐述任务。

数也可以规定连续量，例如用一定数目的长度单位表示一条线段。不能因为一种量具有连续方面，就认为它不能以数来表示。

## 4. *广延量*（extensive Größe）、*内包量*（intensive Größe）与度（§103）

定量的界限可以按不同方式来把握：

| 形式           | 特点                   |
| ------------ | -------------------- |
| 广延量（亦译“外延量”） | 通过其内部的多和单位的汇集来呈现量的规定 |
| 内包量（亦译“强度量”） | 把量的规定表现为一个单纯的程度，即度   |

例如，温度可以作为一个程度被把握；温度计液柱的伸长，则可以作为相应的广延表现。

广延量与内包量可以区别，却并非互不关联的两种世界。同一个量的规定，可以从不同方面呈现；区别在于其界限和规定方式如何被把握。

还需要区分两组问题：

- **连续与离散**：涉及量的一般构成。
- **广延与内包**：涉及定量的界限怎样表现。

本节的“度”是 Grad，表示程度；前面“尺度”的 Maß 则表示质与量的统一，不能因中文译名相同而混淆。

## 5. 定量的无穷递进（§104）

某个定量的规定，通过它与其他定量的区别被表达出来：一个程度处于其他程度之间，某个数可以比另一个数更大或更小。

如果把这一关系只理解为不断越过当前的数，就得到量的无穷递进：

$$
1\to2\to3\to4\to\cdots
$$

或者向更小的数量不断推进。每次都超过一个已经给定的定量，又重新落到一个新的定量上。

它与前面恶无限的结构相似：界限不断被提出，又不断被取消，但“由另一个量来规定这个量”的形式始终没有改变。

这里的哲学问题，是这种外在递进能否充分说明无限。数学中对无穷过程的研究，还可以通过明确的关系和极限把握其结果，两者需要按各自的问题来理解。

例如：

$$
\lim_{n\to\infty}\left(1+\frac{1}{n}\right)^n=e.
$$

这个数学例子以确定的关系刻画整个过程及其极限，能帮助区分“不断列出下一项”与“把握过程的关系”。它作为理解上的补充，不承担逻辑范畴过渡的证明。

## 6. 从外在递进到*量的比率*（quantitatives Verhältnis）（§105）

继续考察上述过程，会发现：量通过另一个量被规定，因而这种外在联系也构成量自己的规定。

这一关系明确表现为量的比率。例如：

$$
2:4=3:6.
$$

两项的直接大小发生了改变，比例关系却保持不变。这里所把握的已经包括两项之间的关系。

黑格尔把确定这一关系的数称为比的 Exponent。这里的意思是比的规定数或比值，不是乘方的指数。按前项除以后项来表示，上述两组数的比值均为 $1/2$。

一个比之所以是这个比，取决于这一确定关系。因此，量的关系已经表现出质的一面：改变关系的规定数，也就改变了这个比。

## 7. 量返回质：引出尺度（§106）

量最初被把握为与质相对无差别的外在规定。但随着定量、度和比率的发展，这种外在性本身也取得确定内容。

从而，量的变化与质的规定开始被理解为相关联的环节，过渡到尺度。

这一结果保存着量的内容，并说明它与质的关系。它不只是重新退回最初的质，也不意味着量可以被取消而不再考察。

# 六、尺度：质与量的统一（§107—§110）

## 1. 尺度是具有质的定量（§107）

尺度首先是一个与确定的质相联系的定量。某种量的范围，与某物维持某种质的条件结合在一起。

因此，尺度不能只理解为人从外部拿来比较事物的尺子。它还涉及事物自己的质与量之间的关系。

质与量在尺度中取得统一，存有也由最初空泛的直接性发展到较充分的规定。

## 2. 量的变化与质的界限（§108）

尺度中的质与量最初只是直接统一，因而还表现出两个方面：

1. 某一范围内，量的增减不改变事物的质。
2. 量越过相应界限时，质发生改变。

例如，在既定压强等条件下，液态水的温度可以在一定范围内改变而维持液态；达到相应相变条件时，其状态便发生变化。

这表明，量最初表现出的无差别并非没有界限。某次变化的幅度很小，也不能据此断定持续积累后仍不会触及质的改变。

伦理生活中的“适度”也可以提供理解线索：同一种行为在一定范围内保持某种性质，过度或不足时可能呈现不同性质。但其具体界限仍需结合对象和条件来说明。

## 3. *无尺度*（das Maßlose，亦译“无度”）与新的尺度（§109）

量越过某个尺度的界限，使原有的质不再维持时，便表现为无尺度。

无尺度首先是相对于原有尺度而言的。原有的质被取消，并不意味着一切质和量的联系都消失了；新出现的质又与某种量的规定相联系，形成新的尺度。

因此，可以把这一过程表示为：

**某一尺度 → 越出界限 → 原有质的改变 → 新的尺度。**

黑格尔以*节线*（Knotenlinie，亦译“节点线”）来描述量的连续变化与质的转变交替出现的过程。节点表示质发生转变的环节，节点之间则可以保持同一种质而发生量的变化。

## 4. 从相对同一到内在联系（§110）

最初的尺度只是质与量的*相对同一性*（relative Identität）：二者已经结合，却还像两个各自直接存在的规定。

尺度经过无尺度而进入新尺度，说明这种直接统一自身也会消解；但它的消解又形成质与量的新统一。

在这个过程中，尺度所面对的并非毫不相干的外物。它在过渡中仍然与自身的规定相联系，由此逐渐超出最初仅仅直接的统一。

# 七、从存有过渡到本质（§111）

## 1. 质与量互相中介

质过渡到量，量又在尺度中返回质。二者的联系不再只是我们从外部观察到的并列关系：各自的规定已经通过另一方得到说明。

从最初的有与无，到某物与他物，再到质与量，思想不断获得更丰富的内容，同时也改变着规定之间相联系的形式。

最初，各个规定仿佛都直接“是”；到尺度的过程，其直接独立性已经受到扬弃。存有通过自身的否定，形成与自身的中介关系，这就是向本质的过渡。

## 2. 存有领域与本质领域的区别

| 方面 | 存有领域 | 本质领域 |
| --- | --- | --- |
| 规定的最初呈现方式 | 各自直接呈现为“是” | 明确包含与另一规定的关系 |
| 运动的主要形式 | 一个规定过渡为另一个规定 | 规定在与另一方的联系中得到规定 |
| 理解重点 | 直接性及其逐步扬弃 | 中介与*反思*（Reflexion）关系 |
| 对比线索 | 有与无首先作为直接规定出现 | 正与负离开彼此就不能保持其规定意义 |

本质不能只理解为藏在表面之后、永远不被表现的内核。它首先是存有自身发展所达到的结果，包含着被扬弃的存有规定及其联系。

因此，“存有—本质”的区别，也不能直接用日常的“表面—深层”来替代。关键在于规定的关系形式发生了改变：直接性被揭示为通过中介而成立。

# 论述线索

1. **§84—§85**：存有的直接规定通过自身展开，形成质、量与尺度的关系。
2. **§86—§89**：纯有与纯无过渡为变易，变易取得包含规定性的结果，即定在。
3. **§90—§95**：定在具有质与界限，其有限性推动变化；真无限把握在他物中返回自身的联系。
4. **§96—§98**：自为存在表现为一，一与多的排斥、吸引引出量。
5. **§99—§106**：量通过连续与离散、定量、数、度和比率取得规定，重新显示与质的联系。
6. **§107—§111**：尺度经过自身的界限和转变，揭示质与量的相互中介，进入本质。
